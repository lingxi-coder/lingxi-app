# Bashism rule provenance

`bashism_rules.json` was adapted from OpenMinis commit `9cf3a855`:

`src/shared/bashism/bashism_rules.json`

The OpenMinis rule engine and rule data are distributed under GPL-3.0. LingXi
retains that license and the original contributor copyright. The only textual
change in the rule data is replacing the OpenMinis product name with LingXi.
This checked-in asset is the single Android runtime source for rule patterns,
behavior notes, and repair hints; Kotlin code must not duplicate the table.
