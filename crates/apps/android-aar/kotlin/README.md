# Historical Kotlin wrapper example

This module is an M8 scaffold retained as a historical example. It is not
maintained or used by the active Android app, and its former `VoiceRecorder` /
`PlatformImpls` API is not the current FFI contract.

Use the active Android application in [`clients/android`](../../../../clients/android).
The Rust wrapper entry points live in [`android-aar/src/lib.rs`](../src/lib.rs):
`build_android_engine_with_mobile_linux` accepts the app-scoped
`AndroidAudioService` callback. The callback provides `capabilities`,
`execute(request)`, and targeted `cancel(identity)`; its UniFFI types are
generated by `clients/android/scripts/build-jni.sh`.

Do not copy or hand-edit generated bindings from this scaffold. Edit the active
client and the corresponding Rust wrapper contract instead.
