## Byte-clean (no gaps found)

- **Write** — tool name `"Write"`, schema `{file_path, content}` (both required, `strictObject`, descriptions), short desc `"Write a file to the local filesystem."`, LONG and SHORT prompts all match (both prompt variants present in binary, count 2). `Gbn` not-read error matches `FILE_NOT_READ_ERROR`. Success-suffix `Ybn` matches `FILE_STATE_CURRENT_SUFFIX`.
- **Edit** — schema `{file_path, old_string, new_string, replace_all(default false)}`, required `[file_path,old_string,new_string]`, all field descriptions, name `"Edit"`, short desc `"A tool for editing files"`, LONG `EDIT_DESCRIPTION` and SHORT prompt, coerceInput aliases (`replace_name/path/old_str/new_str`), 1 GiB cap (`fnl=1073741824`), and errorCodes 1/3/4/5/8/9/10 strings + Unicode-swap note all match byte-for-byte. (Only the secondary `Vbn` stale variant is missing — #5.)
- **NotebookEdit** — full `Fq` registration verified @ off ~ (Uut module): schema `{notebook_path, cell_id?, new_source, cell_type?(enum code|markdown), edit_mode?(enum replace|insert|delete)}`, required `[notebook_path,new_source]`, every field description, enums + defaults, name `"NotebookEdit"`, short desc, prompt (single, not model-gated), and all validateInput error strings (errorCode 2/4/5/6/7/8 incl. `"Cell ID must be specified when not inserting a new cell."`, `"Cell with index … does not exist"`, `"Cell with ID … not found"`, `"For editing other file types, use the FileEdit tool."`) match byte-for-byte. 1-space ipynb indent matches (`Oe(f,null,1)`).
- **Glob** — schema `{pattern, path?}`, required `[pattern]`, descriptions (incl. the long `path` "DO NOT enter undefined or null" note), name `"Glob"`, LONG `j$r` and SHORT `tEi` (both present, count 2), 100-result default all match.
- **Grep** — schema fully matches: `{pattern, path?, glob?, output_mode?(enum content|files_with_matches|count, default files_with_matches), -A, -B, -C, context, -n(default true), -i, -o, type, head_limit(default 250), offset(default 0), multiline}` with exact field source order and every description string; name `"Grep"`; LONG `gVr` and SHORT prompts (both present, count 2); VCS-exclude list `[.git,.svn,.hg,.bzr,.jj,.sl]` matches. SHORT-prompt `${Lo}` interpolates to "Bash" — LingXi's literal "Bash" renders identically (not a gap).

## Needs-deeper-check (NOT counted as confirmed gaps)

- **#1 MultiEdit advertisement**: confirmed in the built-in tool-names const + dispatch shim, but I did not confirm whether the oracle still lists MultiEdit in the tool schema array *sent to the model* in v2.1.186 (it may be name-routed-only / legacy). If unadvertised, #1 is lower severity (back-compat acceptance only).
- **`Vbn` reachability (#5)**: the richer stale string exists in the binary; its call-site path (vs the errorCode-7 path LingXi already matches) was not traced. Confirm it is reachable before treating as a true behavioral gap.
- **Read `maxResultSizeChars`**: oracle Read registration reports `maxResultSizeChars` = Infinity (`1/0`); LingXi caps text reads via `DEFAULT_MAX_OUTPUT_TOKENS=25_000` token budget (read.rs:55 documents the GrowthBook/env tiers as intentionally unported "3P default"). Different mechanism, plausibly equivalent under defaults — not scored.
- **Read device-file blocklist** (`/dev/zero`, `/dev/random`, `/dev/urandom`, `/dev/full`, `/dev/stdin`, `/dev/tty`, `/dev/console`, `/dev/stdout`, `/dev/stderr`, `/dev/fd/0,1,2`) present in oracle (errorCode 9). LingXi's read.rs was not confirmed to enforce this exact list — flagged for a dedicated read-behavior check, not scored here.
- **Read supported-image set**: oracle `Lal=Set(["png","jpg","jpeg","gif","webp"])`; LingXi image handling is behind the `image-read` cargo feature (off by default). Feature-gated divergence, not scored.
