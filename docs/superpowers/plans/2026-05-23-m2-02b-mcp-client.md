# LingXi Core M2 · Plan 02b · MCP Client over `lingxi-jsonrpc`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the existing bespoke `crates/mcp/` transport surface with a real `McpClient` built on top of `lingxi_jsonrpc::Connection` (delivered by sibling plan M2-02a) — wiring the literal claude-code identity (`name: "claude-code"`), the literal capability shape `{roots:{}, elicitation:{}}`, inbound handlers for `roots/list` (returns `file://<cwd>`) and `elicitation/create` (default `{"action":"cancel"}`), and the full MCP protocol surface (`initialize`, `tools/list`, `tools/call`, `prompts/list`, `prompts/get`, `resources/list`, `resources/read`, `ping`).

**Architecture:** A new `client` submodule inside `crates/mcp/` wraps a `lingxi_jsonrpc::Connection` instance produced by the platform-specific transports (M2-02c/d) and exposes a synchronous-feeling async API to callers. Three new submodules — `identity.rs` (constants + `ClientInfo` serde struct), `initialize_params.rs` (capabilities/params builder), `inbound.rs` (roots + elicitation handlers) — isolate wire-fidelity literals from RPC plumbing. The existing `connection.rs` / `registry.rs` state machine stays unchanged; this plan only adds the `client` layer that the state machine and platform glue will call into next plan.

**Tech Stack:** Rust 2021 · `lingxi-jsonrpc` (workspace path dep, from plan M2-02a) · `serde` / `serde_json` · `async-trait` · `tokio` (`sync`, `time`, `macros`) · `thiserror` (existing). No new external crates beyond `lingxi-jsonrpc`.

## Critical 1:1 fidelity items (locked specifics)

These strings/JSON shapes are non-negotiable. Tests assert against them LITERALLY (not via a constant indirection — the goal is to catch refactors that drift the wire). Sourced from `claude-code/src/services/mcp/client.ts`:

- **`clientInfo.name`** — exactly `"claude-code"` (TS line 987). Used as the `name` field inside the `initialize` request's `clientInfo`.
- **`clientInfo.title`** — exactly `"Claude Code"` (TS line 988). Included as a non-required field per spec §6.2.
- **`clientInfo.version`** — `env!("CARGO_PKG_VERSION")` of the `lingxi-mcp` crate. **Not** a hardcoded string; the test asserts the field is present and parses as `x.y.z`.
- **`protocolVersion`** — exactly `"2024-11-05"` (the MCP wire protocol date the claude-code reference targets).
- **`capabilities`** — JSON shape EXACTLY `{"roots": {}, "elicitation": {}}` — both keys present, both values empty objects, no nesting (TS lines 994-1000; the inline TS comment explicitly forbids `{form:{},url:{}}` because Java MCP SDK rejects unknown elicitation properties). Serde must emit `{}` for empty maps, not `null` and not omit-the-key.
- **`roots/list` response** — `{"roots": [{"uri": "file://<cwd>"}]}` where `<cwd>` is the absolute path of the constructor-supplied cwd, prefixed exactly `file://` (TS lines 1011-1017). The outer JSON is `{"roots": [...]}`, NOT a bare array.
- **`elicitation/create` default response** — JSON EXACTLY `{"action": "cancel"}` (TS line 1196). No extra fields. No null. No nesting.
- **Tool full-name prefix** — `mcp__<server>__<tool>` with double-underscores on BOTH sides of the server name (e.g. `mcp__filesystem__read_file`). Server name comes from `McpClient::new`'s `server_name` argument; tool name comes from the JSON-RPC `tools/list` result.
- **Timeout error string** — `format!("MCP server \"{}\" tool \"{}\" timed out after {}s", server, tool, secs)`. The double-quotes around server/tool names are LITERAL. Default timeout is 60 seconds → secs is `60` (unless caller overrides). Integration tests in M2-07 will grep for this exact string.

//! Integration tests for `McpClient` against an in-process mock server.
//!
//! The mock plays the role of a real MCP server: it reads JSON-RPC requests
//! from one end of a duplex pipe, captures them for assertion, and responds
//! with scripted payloads. Tests lock the literal wire bytes claude-code

use tokio::io::{duplex, AsyncRead, AsyncWrite, DuplexStream};
use tokio::sync::Mutex;

use lingxi_mcp::McpClient;

/// Records every outgoing JSON-RPC payload received from the client end.
/// Tests inspect this to assert literal byte content.
#[derive(Default, Clone)]
struct CapturedFrames {
    inner: Arc<Mutex<Vec<Vec<u8>>>>,
}

impl CapturedFrames {
    async fn push(&self, bytes: Vec<u8>) {
        self.inner.lock().await.push(bytes);
    }
    async fn snapshot(&self) -> Vec<Vec<u8>> {
        self.inner.lock().await.clone()
    }

/// Spawns a mock server task that:
///   1. Reads JSON-RPC frames from `server_read` (line-delimited).
///   2. For each request, records the frame bytes in `captured` and
///      dispatches to `responder`, writing the response back on
///      `server_write`.
///
/// The mock supports synchronous request/response only (one in → one out).
/// Notifications are echoed verbatim into `captured` and ignored.
fn spawn_mock_server<F>(
    server_read: DuplexStream,
    server_write: DuplexStream,
    captured: CapturedFrames,
    responder: F,
) -> tokio::task::JoinHandle<()>
where
    F: Fn(&Value) -> Option<Value> + Send + Sync + 'static,
{
    use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
    let responder = Arc::new(responder);
    tokio::spawn(async move {
        let mut reader = BufReader::new(server_read);
        let mut writer = server_write;
        let mut line = String::new();
        loop {
            line.clear();
            let n = reader.read_line(&mut line).await.unwrap_or(0);
            if n == 0 { break; }
            captured.push(line.as_bytes().to_vec()).await;
            let req: Value = match serde_json::from_str(&line) {
                Ok(v) => v,
                Err(_) => continue,
            };
            if let Some(resp) = (responder)(&req) {
                let mut out = serde_json::to_vec(&resp).unwrap();
                out.push(b'\n');
                writer.write_all(&out).await.unwrap();
                writer.flush().await.unwrap();
            }
        }
    })
}

/// Build a client + capture handle bound to a duplex pair.
///
/// Returns (client, captured_frames, mock_handle). The platform layer
/// (M2-02c) wraps this same `Connection` constructor for stdio; here we
/// bypass `tokio::process` and feed the raw read/write halves directly.
async fn make_client_against_mock<F>(
    server_name: &str,
    cwd: std::path::PathBuf,
    responder: F,
) -> (McpClient, CapturedFrames, tokio::task::JoinHandle<()>)
where
    F: Fn(&Value) -> Option<Value> + Send + Sync + 'static,
{
    // Two duplex pipes: client_write → server_read, server_write → client_read.
    let (client_read, server_write) = duplex(64 * 1024);
    let (server_read, client_write) = duplex(64 * 1024);
    let captured = CapturedFrames::default();
    let handle = spawn_mock_server(server_read, server_write, captured.clone(), responder);

    let connection = lingxi_jsonrpc::Connection::new_line_delimited(
        Box::new(client_read) as Box<dyn AsyncRead + Send + Unpin>,
        Box::new(client_write) as Box<dyn AsyncWrite + Send + Unpin>,
    );
    let client = McpClient::new(server_name, cwd, Arc::new(connection));
    (client, captured, handle)
}

#[derive(Debug, Deserialize)]
struct InitializeResponse {
    #[serde(default)]
    capabilities: serde_json::Value,
    /// Server-provided free-form instructions appended to the system prompt.
    /// Truncated to MAX_MCP_DESCRIPTION_LENGTH on receipt (matches
    /// `claude-code/src/services/mcp/client.ts:1163-1166`).
    #[serde(default)]
    instructions: Option<String>,
}

impl McpClient {
    /// Send the MCP `initialize` request, parse the server capability
    /// declaration, and cache it on `self`. Also captures and truncates
    /// the optional `instructions` field per claude-code parity.
    ///
    /// Emits a JSON-RPC payload whose bytes contain:
    ///   * `"method":"initialize"`
    ///   * `"clientInfo":{"name":"claude-code", ...}`
    ///   * `"protocolVersion":"2024-11-05"`
    ///   * `"capabilities":{"roots":{},"elicitation":{}}`
    pub async fn initialize(&self) -> Result<ServerCapabilitiesDto, McpClientError> {
        let params = InitializeParams::default();
        let resp: InitializeResponse = self
            .connection
            .call("initialize", &params)
            .await
            .map_err(|e| McpClientError::Rpc(e.to_string()))?;

        let caps = decode_server_capabilities(&resp.capabilities);
        *self.server_capabilities.write().await = Some(caps.clone());

        // Truncate server instructions matching claude-code behavior
        // (client.ts:1163-1166: if > MAX_MCP_DESCRIPTION_LENGTH, slice + "… [truncated]").
        if let Some(raw) = resp.instructions {
            let orig_len = raw.chars().count();
            let truncated = truncate_description(&raw).into_owned();
            if orig_len > MAX_MCP_DESCRIPTION_LENGTH {
                tracing::warn!(
                    target: "lingxi_mcp::client",
                    server = %self.server_name,
                    from = orig_len,
                    to = MAX_MCP_DESCRIPTION_LENGTH,
                    "Server instructions truncated from {orig_len} to {} chars",
                    MAX_MCP_DESCRIPTION_LENGTH,
                );
            }
            *self.server_instructions.write().await = Some(truncated);
        }

        Ok(caps)
    }

    /// Returns the (possibly truncated) server instructions captured during
    /// `initialize`, or `None` if the server omitted them.
    pub async fn server_instructions(&self) -> Option<String> {
        self.server_instructions.read().await.clone()
    }
}

/// Decode the server's capability JSON object into the trait DTO.
/// MCP servers send capability *objects* (e.g. `"tools": {}`); the DTO
/// only carries boolean presence flags. Empty objects → `true`.
fn decode_server_capabilities(raw: &serde_json::Value) -> ServerCapabilitiesDto {
    use std::collections::HashMap;
    let obj = raw.as_object();
    let has = |k: &str| obj.map(|o| o.contains_key(k)).unwrap_or(false);
    ServerCapabilitiesDto {
        tools: has("tools"),
        resources: has("resources"),
        prompts: has("prompts"),
        logging: has("logging"),
        experimental: obj
            .and_then(|o| o.get("experimental"))
            .and_then(|v| v.as_object())
            .map(|m| m.iter().map(|(k, v)| (k.clone(), v.clone())).collect())
            .unwrap_or_default()
            .into_iter()
            .collect::<HashMap<_, _>>(),
    }
}

/// Maximum length of an MCP tool/prompt description before truncation.
/// Verified against `claude-code/src/services/mcp/client.ts:218` —
/// `const MAX_MCP_DESCRIPTION_LENGTH = 2048`. Applied to tool descriptions
/// (client.ts:1791-1792), prompt descriptions, AND server instructions
/// returned by `initialize` (client.ts:1163-1166).
pub const MAX_MCP_DESCRIPTION_LENGTH: usize = 2048;

/// Truncate `s` to `MAX_MCP_DESCRIPTION_LENGTH` chars, appending
/// `"… [truncated]"` if shortened. Returns `Cow::Borrowed` for short
/// inputs (zero-alloc) and `Cow::Owned` only when truncation occurs.
pub fn truncate_description(s: &str) -> Cow<'_, str> {
    if s.chars().count() <= MAX_MCP_DESCRIPTION_LENGTH {
        Cow::Borrowed(s)
    } else {
        let head: String = s.chars().take(MAX_MCP_DESCRIPTION_LENGTH).collect();
        Cow::Owned(format!("{}… [truncated]", head))
    }
}

    ///
    /// Each [`McpToolDto`] is decorated with the LITERAL full-name
    /// `mcp__<server>__<tool>` per spec §6.2 — caller-facing code (tool
    /// registry, prompt rendering, MCP audit logs) only deals with the
    /// full name.
    pub async fn list_tools(&self) -> Result<Vec<McpToolDto>, McpClientError> {
        let resp: ToolsListResponse = self
            .connection
            .call("tools/list", serde_json::Value::Null)
            .await

            server_name: self.server_name.clone(),
            full_name: format!("mcp__{}__{}", self.server_name, t.name),
            tool_name: t.name,
            description: truncate_description(&t.description).into_owned(),
            input_schema: t.input_schema,
        }).collect())
    }

    /// Invoke a tool by its `mcp__<server>__<tool>` full-name with the
    /// default 60-second timeout.
    pub async fn call_tool(
        &self,
        full_name: &str,
        input: serde_json::Value,
    ) -> Result<McpToolResultDto, McpClientError> {
        self.call_tool_with_timeout(full_name, input, DEFAULT_CALL_TOOL_TIMEOUT)
            .await
    }

    /// `call_tool` with a custom timeout — only used by tests.
    pub async fn call_tool_with_timeout(
        &self,
        full_name: &str,
        input: serde_json::Value,
        timeout: std::time::Duration,
    ) -> Result<McpToolResultDto, McpClientError> {
        // Strip the mcp__<server>__ prefix to recover the wire `name`.
        let prefix = format!("mcp__{}__", self.server_name);
        let tool_name = full_name
            .strip_prefix(&prefix)
            .ok_or_else(|| McpClientError::Rpc(format!(
                "full_name {full_name:?} missing prefix {prefix:?}"
            )))?
            .to_string();

        let params = serde_json::json!({
            "name": tool_name,
            "arguments": input,
        });

        let secs = timeout.as_secs().max(1);
        let fut = self.connection.call::<_, ToolCallResponse>(
            "tools/call",
            params,
        );

        match tokio::time::timeout(timeout, fut).await {
            Err(_elapsed) => Err(McpClientError::Timeout {
                server: self.server_name.clone(),
                tool: tool_name,
                secs,
            }),
            Ok(Err(e)) => Err(McpClientError::Rpc(e.to_string())),
            Ok(Ok(resp)) => Ok(McpToolResultDto {
                content: resp.content,
                is_error: resp.is_error,
            }),
        }
    }
}

/// receiving the client's `initialize`, then captures the client's

async fn run_inbound_roundtrip(
    peer_method: &'static str,
    peer_params: Value,
    cwd: std::path::PathBuf,
) -> Value {

    let (client_read, mut server_write) = duplex(64 * 1024);
    let (server_read, client_write) = duplex(64 * 1024);

    let response_holder = Arc::new(Mutex::new(None::<Value>));
    let response_clone = response_holder.clone();

            if reader.read_line(&mut line).await.unwrap_or(0) == 0 { return; }
            let req: Value = match serde_json::from_str(&line) {
                Ok(v) => v, Err(_) => continue,
            };
            if req["method"] == "initialize" {
                let id = req["id"].clone();
                let resp = json!({
                    "jsonrpc": "2.0", "id": id,
                    "result": {
                        "protocolVersion": "2024-11-05",
                        "capabilities": {},
                        "serverInfo": { "name": "m", "version": "0" }
                    }
                });
                let mut out = serde_json::to_vec(&resp).unwrap();
                out.push(b'\n');
                server_write.write_all(&out).await.unwrap();
                server_write.flush().await.unwrap();
                break;
            }
        }

        // Step 2: issue the peer-initiated request to the client.
        let peer_req = json!({
            "jsonrpc": "2.0",
            "id": 1000,
            "method": peer_method,
            "params": peer_params,
        });
        let mut out = serde_json::to_vec(&peer_req).unwrap();
        out.push(b'\n');
        server_write.write_all(&out).await.unwrap();
        server_write.flush().await.unwrap();

        // Step 3: read the client's response (the handler's output).
        loop {
            line.clear();
            if reader.read_line(&mut line).await.unwrap_or(0) == 0 { return; }
            let msg: Value = match serde_json::from_str(&line) {
                Ok(v) => v, Err(_) => continue,
            };
            if msg["id"] == json!(1000) {
                *response_clone.lock().await = Some(msg["result"].clone());
                return;
            }
        }
    });

    let connection = lingxi_jsonrpc::Connection::new_line_delimited(
        Box::new(client_read) as Box<dyn AsyncRead + Send + Unpin>,
        Box::new(client_write) as Box<dyn AsyncWrite + Send + Unpin>,
    );
    let client = McpClient::new("inbound-srv", cwd, Arc::new(connection));
    client.initialize().await.expect("init");

    // Give the mock server time to fire its peer request + receive the
    // client's response.
    for _ in 0..20 {
        if response_holder.lock().await.is_some() { break; }
        tokio::time::sleep(std::time::Duration::from_millis(25)).await;
    }
    response_holder.lock().await.clone().expect("response captured")
}
