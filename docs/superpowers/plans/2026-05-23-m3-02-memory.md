# LingXi Core M3 · Plan 02 · Memory (CLAUDE.md hierarchy + memdir + fixed-point ranking + secret scan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate at the end (Task 18) is the workspace-wide guard.

**Goal:** Build `lingxi-memory::memdir` and `lingxi-memory::claude_md` providing claude-code-equivalent memory: a CLAUDE.md hierarchy loader (cwd → parents → user, plus `CLAUDE.local.md` overrides), a memdir scan that drops only stale entries older than 365 days, and a relevance ranker (`find_relevant`) that combines Jaccard keyword overlap, age penalty, tier weight, and team boost using **fixed-point u64 basis points** so output is byte-identical across x86_64 and aarch64. Secret scanning reuses v3 §16.5 `lingxi-secret::scanner::SecretScanner` instead of duplicating gitleaks rules.

**Architecture:** Two parallel sub-modules under `crates/memory/src/`. `claude_md/` walks the dir-up hierarchy and loads each `CLAUDE.md` / `CLAUDE.local.md` once with a 10 MB cap. `memdir/` enumerates `~/.claude/memdir/` plus the optional team dir, drops entries older than 365 days as scan hygiene, then computes a `score_bps: u64` per entry by multiplying four bps-scaled factors (jaccard × age weight × tier weight × team boost) and returning the top-`k` by sorted score. `find.rs` carries `#![deny(clippy::float_arithmetic)]` so the scoring path stays integer-only and the parity fixtures don't flake on cross-platform float rounding. `secret_scan.rs` is replaced with a thin adapter that calls `lingxi_secret::SecretScanner::builtin().redact(...)`; `team_memory.rs` keeps its public surface but delegates to `memdir::team_paths::resolve_team_memory_dir(...)`.

**Tech Stack:** Rust 2021, `serde`/`serde_json` (workspace), `walkdir 2.5` (new — non-recursive dir enumeration with safe symlink behaviour), `tokio` (workspace, sync subset; the loader stays sync — async is reserved for higher-level prefetch in M3-06), `lingxi-secret` (path-dep, gitleaks rules), `lingxi-protocol` (already a dep — for `MemoryEntry` newly defined in this plan), `lingxi-telemetry` (path-dep added in this plan for `AnalyticsBus` + `Verified`/`PiiTagged`), `tempfile 3.13` (dev-only, new — for hierarchy + memdir integration tests).

## Critical 1:1 fidelity items (locked specifics — appear byte-for-byte in code AND in at least one test assertion)

These are non-negotiable strings, file names, and numeric constants from claude-code that drift breaks interop with:

- **Project memory filename**: `CLAUDE.md` (case-sensitive in our match function — `Hierarchy::FILE_NAME = "CLAUDE.md"`).
- **Local override filename**: `CLAUDE.local.md` (`Hierarchy::LOCAL_OVERRIDE_NAME = "CLAUDE.local.md"`). Local overrides shadow same-tier project memory; they do NOT cascade upward.
- **OS-layer case insensitivity**: on macOS APFS / Windows NTFS the OS may return a lowercased `claude.md` from the directory listing. The loader does a case-insensitive comparison but emits `tengu_memory_case_mismatch` when the actual filename's bytes differ from `CLAUDE.md`. The exact-case match is preferred when both exist in the same directory.
- **Memdir directory**: `~/.claude/memdir/` (`MEMDIR_SUBDIR = "memdir"` under the resolved `~/.claude/` root).
- **Team memory directory**: `~/.claude/team-mem/` (`TEAM_MEM_SUBDIR = "team-mem"`).
- **Per-file size cap**: `MAX_MEMORY_FILE_SIZE = 10 * 1024 * 1024` (10 MB exactly). Files larger than this are skipped and an event `tengu_memory_file_too_large` is emitted; loading continues with the remaining files.
- **Age penalty block**: `MEMORY_AGE_PENALTY_DAYS = 30`. Age in 30-day blocks: `age_blocks = age_days / 30` (integer division — floor).
- **Hard-drop threshold**: `MEMORY_AGE_HARD_DROP_DAYS = 365`. Entries older than 365 days ARE dropped at scan time as a hygiene measure; this is the ONLY drop in the loader path. Age otherwise penalizes, never drops.
- **Minimum age weight**: `MEMORY_MIN_AGE_WEIGHT_BPS = 1_000` (basis points; 10%). Even very old entries (within 365 days) stay reachable at 10% weight.
- **Default relevance k**: `DEFAULT_RELEVANT_MEMORIES = 5`. `find_relevant(prompt, None)` defaults to 5; callers may override.
- **Tier weights (bps)**: `session = 10_000`, `project = 8_000`, `team = 7_000`, `user = 6_000`. Order is `session > project > team > user`. These are the **basis-point** values multiplied into the score accumulator.
- **Team boost (bps)**: `TEAM_BOOST_NUMERATOR_BPS = 12_000`, `TEAM_BOOST_DENOMINATOR_BPS = 10_000` — applied as `score = score * 12_000 / 10_000` (final divide) ONLY when (a) entry tier is `Team` AND (b) `settings.team_memory.enabled == true`. The team boost is **opt-in via the explicit settings bool** — auto-detect from filesystem presence is intentionally NOT used.
- **Scoring arithmetic**: fixed-point `u64` basis points. No `f64` anywhere on the scoring path. `find.rs` carries `#![deny(clippy::float_arithmetic)]` at the file top so the compiler rejects any drift.
- **Jaccard formula**: integer `intersection_count * 10_000 / union_count` (both `u64`), returning `0` when `union_count == 0` (empty prompt OR empty entry tokens). Tokenization is lowercased ASCII word splits (`['a'..='z' | '0'..='9' | '_']+`) with stop-words NOT removed (no per-language stop list — claude-code's deterministic split).
- **Age weight formula**: `age_weight_bps = max(MEMORY_MIN_AGE_WEIGHT_BPS, 10_000 / (1 + age_blocks))` where `age_blocks: u64 = age_days / MEMORY_AGE_PENALTY_DAYS` (integer division). The `+1` is on `age_blocks` (NOT on `age_days`) so a brand-new entry yields `10_000 / 1 = 10_000` (no penalty).
- **Telemetry events** (locked, byte-for-byte): `tengu_agent_memory_loaded`, `tengu_memory_secret_redacted`, `tengu_memory_file_too_large`, `tengu_memory_case_mismatch`. All four appear as the first argument to `AnalyticsBus::log_event(...)` exactly as written.
- **`tengu_agent_memory_loaded` payload keys**: `count: AnalyticsValue::Int(N)`, `sources: AnalyticsValue::String("session,project,team,user")` (comma-joined; ordered by enum-declaration order; only tiers contributing ≥1 entry are listed), `had_team_boost: AnalyticsValue::Bool(b)`.
- **`tengu_memory_secret_redacted` payload keys**: `rule_id: Verified(<rule-id>)` (rule IDs are non-PII; e.g. `aws-access-token`), `_PROTO_path: PiiTagged(<file path>)`. The redacted secret value itself is NOT emitted.
- **`tengu_memory_file_too_large` payload keys**: `_PROTO_path: PiiTagged(<file path>)`, `size_bytes: AnalyticsValue::Int(N as i64)`.
- **`tengu_memory_case_mismatch` payload keys**: `_PROTO_path: PiiTagged(<file path>)`, `actual: Verified(<actual filename, e.g. "claude.md">)` (only the filename component — directory leaked elsewhere as `_PROTO_path`).
- **Deterministic ordering**: when two entries score equal, ties break by `(tier_order_descending, path lexicographic ascending)`. Tier order: `Session(0)`, `Project(1)`, `Team(2)`, `User(3)`. This makes `find_relevant` byte-identical across runs and platforms.

/// One in-memory unit surfaced from the loader to the agent loop.
///
/// Boundary type shared by `lingxi-memory` (producer) and `lingxi-agent`
/// (consumer). Tier ordering and scoring rules live in `lingxi-memory`.
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize, PartialEq, Eq)]
pub struct MemoryEntry {
    /// Absolute path the entry was loaded from.
    pub path: std::path::PathBuf,
    /// Tier the entry belongs to (`Session`, `Project`, `Team`, `User`).
    pub tier: MemoryEntryTier,
    /// Raw markdown body (frontmatter stripped, secrets redacted).
    pub body: String,
    /// Age in whole days from the load `now`. `0` for a just-written file.
    pub age_days: u64,
    /// File size in bytes (post-redaction body length).
    pub size_bytes: u64,
}

/// Cross-crate stand-in for `lingxi_memory::MemoryTier`.

/// variants (`Project { repo_root }`, etc.) live in `lingxi-memory::tier`.

    Session,
    /// Project-scoped entry (next tier).
    Project,
    /// Team-scoped entry (subject to team-boost gate).
    Team,
    /// User-scoped entry (lowest tier).

}

```rust
use std::path::Path;

/// Walk cwd → parents → `<home>/.claude` collecting CLAUDE.md files.
///
/// At each directory, `CLAUDE.local.md` (if present) is emitted FIRST,
/// then `CLAUDE.md`. The walk visits each directory at most once.
/// Returns an empty hierarchy when no files exist (NOT an error).
#[must_use]
pub fn walk(cwd: &Path, home: &Path) -> Hierarchy {
    let mut entries = Vec::new();
    let mut seen = std::collections::HashSet::new();

    let mut walker: Option<&Path> = Some(cwd);
    while let Some(dir) = walker {
        if seen.insert(dir.to_path_buf()) {
            collect_in_dir(dir, &mut entries);
        }
        walker = dir.parent();
    }

    let user_dir = home.join(".claude");
    if seen.insert(user_dir.clone()) {
        collect_in_dir(&user_dir, &mut entries);
    }

    Hierarchy { entries }
}

fn collect_in_dir(dir: &Path, out: &mut Vec<HierarchyEntry>) {
    // CLAUDE.local.md first (so it shadows the canonical entry).
    if let Some(entry) = probe(dir, LOCAL_OVERRIDE_NAME, true) {
        out.push(entry);
    }
    if let Some(entry) = probe(dir, FILE_NAME, false) {
        out.push(entry);
    }
}

fn probe(dir: &Path, want: &str, is_local: bool) -> Option<HierarchyEntry> {
    // Exact-case check first.
    let exact = dir.join(want);
    if exact.is_file() {
        return Some(HierarchyEntry {
            path: exact,
            is_local_override: is_local,
            exact_case: true,
        });
    }
    // Case-insensitive fallback (Task 3 wires the warning event).
    let want_lc = want.to_ascii_lowercase();
    let read = std::fs::read_dir(dir).ok()?;
    for ent in read.flatten() {
        let name = ent.file_name();
        let s = name.to_string_lossy();
        if s.to_ascii_lowercase() == want_lc && ent.file_type().ok()?.is_file() {
            return Some(HierarchyEntry {
                path: ent.path(),
                is_local_override: is_local,
                exact_case: s == want,
            });
        }
    }
    None
}
```

use crate::MAX_MEMORY_FILE_SIZE;
use std::path::Path;
use std::sync::Arc;

/// Telemetry event name emitted when a file exceeds `MAX_MEMORY_FILE_SIZE`.
pub const TENGU_MEMORY_FILE_TOO_LARGE: &str = "tengu_memory_file_too_large";

/// Load one CLAUDE.md (or local override) with the 10 MB cap.
///
/// Returns `Err(FileTooLarge)` when the file exceeds the cap. The caller
/// is expected to log the event via `emit_file_too_large` and continue
/// processing the remaining files — oversized files are skipped, never
/// fatal.
///
/// # Errors
///
/// - `LoaderError::Io` for filesystem errors (file unreadable, perms).
/// - `LoaderError::FileTooLarge` when the size exceeds the cap.
pub fn load_file(path: &Path, _bus: Option<&Arc<lingxi_telemetry::AnalyticsBus>>) -> Result<LoadedFile, LoaderError> {
    let meta = std::fs::metadata(path).map_err(|e| LoaderError::Io(e.to_string()))?;
    let size = meta.len();
    if size as usize > MAX_MEMORY_FILE_SIZE {
        return Err(LoaderError::FileTooLarge {
            path: path.to_path_buf(),
            bytes: size,
        });
    }
    let body = std::fs::read_to_string(path).map_err(|e| LoaderError::Io(e.to_string()))?;
    Ok(LoadedFile {
        path: path.to_path_buf(),
        body,
        size_bytes: size,
    })
}

/// Emit `tengu_memory_file_too_large` when a file was skipped.
///
/// No-op when `bus` is `None`. Payload keys (locked):
/// `_PROTO_path: PiiTagged(<path>)`, `size_bytes: Int(N)`.
pub async fn emit_file_too_large(
    bus: Option<&Arc<lingxi_telemetry::AnalyticsBus>>,
    path: &Path,
    bytes: u64,
) {
    let Some(bus) = bus else {
        return;
    };
    let mut md = lingxi_telemetry::sink::LogEventMetadata::new();
    md.insert(
        "_PROTO_path".into(),
        lingxi_telemetry::sink::AnalyticsValue::String(
            lingxi_telemetry::pii::PiiTagged::assert_pii_tagged_column(
                path.display().to_string(),
            )
            .into_inner(),
        ),
    );
    md.insert(
        "size_bytes".into(),
        lingxi_telemetry::sink::AnalyticsValue::Int(bytes as i64),
    );
    bus.log_event(TENGU_MEMORY_FILE_TOO_LARGE, md).await;
}

/// Scan with explicit `now` (testable). Files older than
/// `MEMORY_AGE_HARD_DROP_DAYS` are dropped; oversized files (>10 MB) are
/// dropped too (their event is emitted by the caller through
/// [`crate::claude_md::loader::emit_file_too_large`] for hierarchy files;
/// memdir files emit the same event via the loader path used by the
/// engine wrapper — see Task 13).
///
/// # Errors
///
/// Returns `std::io::Error` for directory-iteration errors other than
/// `NotFound`.
pub fn scan_memdir_at(
    roots: &super::paths::MemdirRoots,
    now: SystemTime,
) -> std::io::Result<MemdirSnapshot> {
    let mut entries = Vec::new();
    enumerate(&roots.user_memdir, MemoryEntryTier::User, now, &mut entries)?;
    if let Some(team) = roots.team_memdir.as_deref() {
        enumerate(team, MemoryEntryTier::Team, now, &mut entries)?;
    }
    Ok(MemdirSnapshot { entries })
}

fn enumerate(
    dir: &Path,
    tier: MemoryEntryTier,
    now: SystemTime,
    out: &mut Vec<MemoryEntry>,
) -> std::io::Result<()> {
    let read = match std::fs::read_dir(dir) {
        Ok(r) => r,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(()),
        Err(e) => return Err(e),
    };
    // Sort by filename for deterministic ordering.
    let mut paths: Vec<_> = read.flatten().filter(|e| e.file_type().map(|t| t.is_file()).unwrap_or(false)).map(|e| e.path()).collect();
    paths.sort();
    for path in paths {
        let meta = match std::fs::metadata(&path) {
            Ok(m) => m,
            Err(_) => continue,
        };
        if meta.len() as usize > MAX_MEMORY_FILE_SIZE {
            // Oversized — skip (caller emits tengu_memory_file_too_large
            // via the loader wrapper in Task 13).
            continue;
        }
        let mtime = meta.modified().unwrap_or(now);
        let age_days = now
            .duration_since(mtime)
            .map(|d| d.as_secs() / 86_400)
            .unwrap_or(0);
        if age_days > MEMORY_AGE_HARD_DROP_DAYS {
            continue;
        }
        let body = std::fs::read_to_string(&path).unwrap_or_default();
        out.push(MemoryEntry {
            path,
            tier,
            body,
            age_days,
            size_bytes: meta.len(),
        });
    }
    Ok(())
}

///
/// Stop-words are NOT removed (claude-code default). Tokens are
/// deduplicated for set-style Jaccard.
#[must_use]
pub fn tokenize(s: &str) -> std::collections::BTreeSet<String> {

    let mut current = String::new();
    for ch in s.chars() {

            current.push(ch.to_ascii_lowercase());
        } else if !current.is_empty() {
            out.insert(std::mem::take(&mut current));
        }
    }
    if !current.is_empty() {
        out.insert(current);
    }
    out
}

    let a = tokenize(prompt);

    let union = (a.len() as u64) + (b.len() as u64) - intersection;
    if union == 0 {
        return 0;
    }
    intersection * 10_000 / union
}

//! Thin adapter over `lingxi_secret::SecretScanner`.
//!
//! Reuses the v3 §16.5 30+ gitleaks rules — we do NOT duplicate the rule
//! set here. The scanner is built once via [`SecretScanner::builtin`] and
//! shared across loader passes.

use lingxi_secret::{SecretDetection, SecretScanner};
use std::path::Path;
use std::sync::{Arc, OnceLock};

/// Telemetry event name emitted on each per-rule redaction hit.
pub const TENGU_MEMORY_SECRET_REDACTED: &str = "tengu_memory_secret_redacted";

fn scanner() -> &'static SecretScanner {
    static SCANNER: OnceLock<SecretScanner> = OnceLock::new();
    SCANNER.get_or_init(SecretScanner::builtin)
}

/// Redact secrets in `content`, returning the redacted text and any
/// detections so callers can emit `tengu_memory_secret_redacted` events
/// with PII discipline (path is PII; rule id is not).
#[must_use]
pub fn redact_with_detections(content: &str) -> (String, Vec<SecretDetection>) {
    let s = scanner();
    let dets = s.scan(content);
    let red = s.redact(content);
    (red, dets)
}

/// Redact-only variant (no detections returned). Convenience for
/// callers that don't need telemetry.
#[must_use]
pub fn redact(content: &str) -> String {
    scanner().redact(content)
}

/// Emit `tengu_memory_secret_redacted` once per detection.
///
/// Payload (locked): `rule_id: Verified(<rule id>)`, `_PROTO_path: PiiTagged(<path>)`.
/// The matched secret value itself is NEVER emitted.
pub async fn emit_redactions(
    bus: Option<&Arc<lingxi_telemetry::AnalyticsBus>>,
    path: &Path,
    detections: &[SecretDetection],
) {
    let Some(bus) = bus else {
        return;
    };
    for det in detections {
        let mut md = lingxi_telemetry::sink::LogEventMetadata::new();
        md.insert(
            "rule_id".into(),
            lingxi_telemetry::sink::AnalyticsValue::String(
                lingxi_telemetry::pii::Verified::assert_safe(det.rule_id.clone()).into_inner(),
            ),
        );
        md.insert(
            "_PROTO_path".into(),
            lingxi_telemetry::sink::AnalyticsValue::String(
                lingxi_telemetry::pii::PiiTagged::assert_pii_tagged_column(
                    path.display().to_string(),
                )
                .into_inner(),
            ),
        );
        bus.log_event(TENGU_MEMORY_SECRET_REDACTED, md).await;
    }
}

use lingxi_protocol::{MemoryEntry, MemoryEntryTier};
use std::sync::Arc;

/// Telemetry event name emitted once per memory-load operation.
pub const TENGU_AGENT_MEMORY_LOADED: &str = "tengu_agent_memory_loaded";

/// Emit `tengu_agent_memory_loaded` for a finished load pass.
///
/// Payload (locked):
///   - `count: Int(N)` — number of entries surfaced
///   - `sources: String("session,project,team,user")` — comma-joined tier
///     list in declaration order (Session, Project, Team, User), only
///     tiers contributing ≥1 entry
///   - `had_team_boost: Bool(b)` — mirrors `settings.team_memory.enabled`
///     at the time of the load
pub async fn emit_agent_memory_loaded(
    bus: Option<&Arc<lingxi_telemetry::AnalyticsBus>>,
    entries: &[MemoryEntry],
    had_team_boost: bool,
) {
    let Some(bus) = bus else {
        return;
    };
    let mut tiers_present = std::collections::BTreeSet::new();
    for e in entries {
        tiers_present.insert(e.tier);
    }
    // Emit in declaration order: Session, Project, Team, User.

//! Parity fixture: CLAUDE.md hierarchy walk + 10 MB cap.
//!
//! Locks the shape of `claude_md::hierarchy::walk` + `claude_md::loader::load_file`
//! against claude-code's reference (`src/memory/hierarchy.ts:22-71`,
//! `src/memory/loader.ts:14-38`). Each scenario builds a tempdir layout
//! and asserts the walk order + skipped-due-to-size set match.

use lingxi_memory::claude_md::loader::{load_file, LoaderError};
use lingxi_memory::MAX_MEMORY_FILE_SIZE;
use lingxi_test_harness::parity::load_fixture;
use serde::Deserialize;
use std::collections::BTreeMap;
use std::fs;
use std::path::PathBuf;

#[derive(Deserialize)]
struct Fixture {
    scenarios: Vec<Scenario>,
}

#[derive(Deserialize)]
struct Scenario {
    name: String,
    /// Map of relative path → body. The literal "OVERSIZED:11mb" is replaced
    /// by 11 MB of `x` bytes at write time (keeps the fixture file small).
    layout: BTreeMap<String, String>,
    cwd: String,
    home: String,
    #[serde(default)]
    expected_order: Vec<String>,
    #[serde(default)]
    expected_skipped: Vec<String>,
}

fn materialize(layout: &BTreeMap<String, String>, root: &std::path::Path) {
    for (rel, body) in layout {
        let full = root.join(rel);
        if let Some(parent) = full.parent() {
            fs::create_dir_all(parent).unwrap();
        }
        if body == "OVERSIZED:11mb" {
            let bytes = vec![b'x'; MAX_MEMORY_FILE_SIZE + 1024 * 1024];
            fs::write(&full, &bytes).unwrap();
        } else {
            fs::write(&full, body.as_bytes()).unwrap();
        }
    }
}

    let fx: Fixture = load_fixture("memory_loading");

    for sc in &fx.scenarios {
        let root = tempfile::TempDir::new().expect("tempdir");
        materialize(&sc.layout, root.path());
        let cwd = root.path().join(&sc.cwd);
        // The walk skips dirs that don't exist; if scenarios reference a
        // cwd that wasn't in the layout, create it now.
        fs::create_dir_all(&cwd).unwrap();

        fs::create_dir_all(&home).unwrap();

        let h = walk(&cwd, &home);
        let mut loaded: Vec<PathBuf> = Vec::new();

            match load_file(&entry.path, None) {

                Err(LoaderError::FileTooLarge { path, .. }) => skipped.push(path),

        let to_rel = |p: &PathBuf| -> String {
            p.strip_prefix(root.path())
                .unwrap_or(p)
                .to_string_lossy()
                .replace('\\', "/")

        let got_skipped: Vec<String> = skipped.iter().map(to_rel).collect();

        );

            got_skipped, sc.expected_skipped,

        );
