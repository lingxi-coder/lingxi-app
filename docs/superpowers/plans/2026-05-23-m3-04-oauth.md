# LingXi Core M3 · Plan 04 · OAuth (refresh + scope upgrade + single-flight)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate at the end (Task 11) is the workspace-wide guard.

**Goal:** Extend `lingxi-anthropic-oauth` with a concrete `RefreshDriver` that implements M3-03's frozen `OAuthRefreshHook` trait. Drive both reactive (401) refresh from the api-client middleware and a proactive task that wakes at `min(remaining_lifetime / 2, 5 * 60)` seconds before expiry. Share a single `refresh_lock: Arc<tokio::sync::Mutex<()>>` between paths with double-check-after-acquire so concurrent expirations collapse to exactly one HTTP refresh (loom-verified). When the API returns 403-with-`required_scopes`, re-run PKCE preserving the existing `refresh_token` and fall back cleanly on PKCE failure. The proactive task's `BackgroundTaskHandle` is owned by `AuthState` and cancelable via `Engine::shutdown`.

**Architecture:** Two new files under `crates/anthropic-oauth/src/` form the OAuth runtime: `refresh.rs` defines `RefreshDriver` (the `OAuthRefreshHook` impl) plus `AuthState` (which owns `refresh_lock`, the current token + expiry, and the proactive `BackgroundTaskHandle`); `scope_upgrade.rs` parses 403 responses for `required_scopes` and runs a fresh PKCE flow preserving the old `refresh_token`. The existing `client.rs` is extended with `init_refresh_driver(...)` which constructs `RefreshDriver`, calls `register_oauth_hook(Arc::new(driver))` (process-global from M3-03), and spawns the proactive task via `RuntimeSpawner`. Telemetry events flow through the existing `AnalyticsBus`; all string payloads cross the boundary via `Verified::assert_safe` / `PiiTagged::assert_pii_tagged_column` (the real PII newtypes — the spec's `VerifiedClean` is a typo we follow the codebase on).

**Tech Stack:** Rust 2021, `tokio` (workspace, `sync` + `time` features — `Mutex`, `sleep_until`, `Instant`), `reqwest` (already in tree via `lingxi-platform-posix`; M3-04 stays on `lingxi-traits::HttpTransport` and never imports `reqwest` directly), `serde`/`serde_json` (workspace), existing `lingxi-anthropic-oauth` PKCE infra (`pkce.rs`, `callback.rs`, `config.rs`), `lingxi_protocol::Secret` (re-exported from `secrecy 0.10`), `lingxi-secret::CredentialManager` for keychain (M2-06), `lingxi-api-client` (for the frozen `OAuthRefreshHook` trait + `BearerToken` + `TokenHash` + `register_oauth_hook` from M3-03), `sha2 0.10` (already in tree — `Sha256` for `TokenHash` derivation), `async-trait 0.1` (workspace), `thiserror 2` (workspace), `loom 0.7` (new dev-dep — single-flight invariant check, gated behind `#[cfg(loom)]`).

## Critical 1:1 fidelity items (locked specifics — appear byte-for-byte in code AND in at least one test assertion)

These are non-negotiable strings/numbers from claude-code @ 6a25909 that drift breaks interop with:

- **Authorize endpoint**: `https://claude.ai/oauth/authorize` (browser-facing; user signs in here)
- **Token endpoint**: `https://console.anthropic.com/v1/oauth/token` (back-channel for both token exchange after PKCE AND refresh grant)
- **Refresh grant_type**: `refresh_token`
- **OAuth scopes**: `read:user`, `write:messages`, `read:projects` (declaration order matters — emitted as the space-joined `scope=` query/body parameter in that exact order)
- **Loopback redirect URI template**: `http://127.0.0.1:{port}/callback` (v3 §30.3 — loopback ONLY; no public callback)
- **PKCE method**: `S256` (RFC 7636 §4.2; inherited from existing `pkce.rs` which already computes SHA-256 of the verifier)
- **State token entropy**: 256 bits (32 bytes) — existing `pkce.rs::generate_state_token` returns 16 bytes; M3-04 does NOT change this because v3 §30.1 actually specs 16 bytes (128 bits — adequate for CSRF). The spec table line 717 says 256 bits referring to authorize URL state-parameter entropy in claude-code; we treat 128 bits as adequate per the v3 contract and flag as a deviation if reviewer disagrees.
- **Login flow deadline**: 5 minutes (300 seconds) — proactive task wake formula edge case AND PKCE deadline.
- **Proactive refresh lead formula**: `min(remaining_lifetime / 2, 5 * 60)` seconds — locked as a `const fn` that takes `remaining: Duration` and returns `Duration`. For a 4-minute-remaining token: returns `2 min` (remaining/2 is smaller). For a 1-hour-remaining token: returns `5 min`. Tested directly in Task 3.
- **Single-flight lock**: `refresh_lock: Arc<tokio::sync::Mutex<()>>` (v3 §16.3) — declared as a field of `AuthState`. The lock value is `()`; the lock's purpose is critical-section serialization, NOT data protection (the data is in separate `RwLock<TokenInfo>`).
- **Double-check-after-acquire**: After acquiring `refresh_lock`, RE-READ the current `TokenInfo` and check whether `token_hash == prev_token_hash`. If `!=`, another task already refreshed; return the now-current `BearerToken` without making a network call.
- **401 retry policy**: The api-client middleware retries ONCE after a refresh; M3-04's `RefreshDriver::refresh` is invoked at most once per logical API request. If the post-refresh request also returns 401, the middleware surfaces `ApiError::Unauthorized` (no further retries; avoids tight loops on permanently-expired refresh tokens). M3-04 does NOT implement the retry policy itself — that lives in M3-03's `with_retry`. M3-04 only ensures `refresh()` is idempotent under the lock.
- **`OAuthError::RefreshExpired` Display string (byte-for-byte)**: `"Session expired. Re-authenticate?"` — locked in `client.rs` via `#[error("Session expired. Re-authenticate?")]` AND asserted in Task 2.
- **`OAuthError::ScopeRejected` Display string**: `"Scope upgrade denied by provider"` — locked in `client.rs` via `#[error("Scope upgrade denied by provider")]` AND asserted in Task 7.
- **`OAuthError::ProactiveFailed` Display string**: `"proactive refresh failed: {source}"` — `{source}` is the wrapped `Box<OAuthError>`'s Display. Asserted in Task 3.
- **`Secret<T>` wrapping**: Every access_token and refresh_token MUST be wrapped in `Secret<String>` at construction. The keychain blob holds raw bytes; the moment it's deserialized into `TokenInfo`, both fields go through `Secret::new(...)`.
- **`BearerToken` construction**: `lingxi_api_client::oauth_hook::BearerToken(Secret::new(access_token.clone()))` — the field is `pub` per M3-03's frozen surface (`pub struct BearerToken(pub Secret<String>)`).
- **`TokenHash` derivation**: `TokenHash(Sha256::digest(access_token.as_bytes()).into())` — SHA-256 of the access_token bytes, exactly 32 bytes. M3-03 declared this type with `pub [u8; 32]`; M3-04 owns the derivation.
- **Telemetry event names** (locked, byte-for-byte; appear in `name` arg to `AnalyticsBus::log_event(...)` exactly as written):
  - `tengu_oauth_refresh_started`
  - `tengu_oauth_refresh_succeeded`
  - `tengu_oauth_refresh_failed`
  - `tengu_oauth_scope_upgraded`
  - `tengu_oauth_proactive_canceled`
- **`tengu_oauth_refresh_started` payload keys**: `trigger: Verified` (either `"reactive_401"` or `"proactive_timer"`).
- **`tengu_oauth_refresh_succeeded` payload keys**: `trigger: Verified`, `new_expiry_unix: AnalyticsValue::Int(N as i64)`, `duration_ms: AnalyticsValue::Int(N as i64)`.
- **`tengu_oauth_refresh_failed` payload keys**: `trigger: Verified`, `error_kind: Verified` (`"refresh_expired"`, `"provider_unreachable"`, `"token_stale"`, or `"scope_rejected"`).
- **`tengu_oauth_scope_upgraded` payload keys**: `granted_count: AnalyticsValue::Int(N as i64)`, `required_count: AnalyticsValue::Int(N as i64)`.
- **`tengu_oauth_proactive_canceled` payload keys**: `reason: Verified` (always `"engine_shutdown"` in this milestone; future milestones may add others). NOTE: emitted by `AuthState::shutdown` cleanly — NOT on transient task failure.
- **`tengu_oauth_scope_upgraded`** is emitted on success of `run_scope_upgrade` — `tengu_oauth_refresh_failed` with `error_kind: "scope_rejected"` is emitted on PKCE failure during a scope upgrade.
- **Keychain account name**: `"claude-code-credentials"` — string passed to `CredentialManager` for OAuth-token persistence; matches the spec's startup-flow line 311. Service name is `"lingxi"` (matches `CredentialManager::store_anthropic_api_key`'s `"anthropic-api-key"` pattern — same service, different account).
- **Token blob shape on keychain**: JSON-serialized `TokenInfo` (`{access_token, refresh_token, expires_at_unix, scopes}`), then `Secret<String>`-wrapped, then UTF-8 bytes into `SecureStorageData`.

```rust
//! OAuth scope upgrade: 403-with-`required_scopes` re-triggers PKCE preserving
//! the existing refresh_token. See spec §3 / §8 M3-04 phase 4.
//!
//! M3-04 populates this in Task 7.

#![allow(dead_code)]

use serde::Deserialize;

/// Decoded shape of a 403 response body announcing a required scope upgrade.
#[derive(Debug, Clone, Deserialize)]
pub struct ScopeUpgradeRequired {
    /// Scopes the provider now requires.
    pub required: Vec<String>,
    /// Scopes currently granted on the token.
    pub granted: Vec<String>,
}

/// Parse a 403 body for `required_scopes`. Returns `None` if the body is not
/// a scope-upgrade signal (other 403 reasons exist).
#[must_use]
pub fn parse_scope_upgrade(body: &str) -> Option<ScopeUpgradeRequired> {
    let v: serde_json::Value = serde_json::from_str(body).ok()?;
    let required = v.get("required_scopes")?.as_array()?;
    let granted = v.get("granted_scopes").and_then(|g| g.as_array()).cloned().unwrap_or_default();
    let required: Vec<String> = required
        .iter()
        .filter_map(|s| s.as_str().map(str::to_string))
        .collect();
    let granted: Vec<String> = granted
        .iter()
        .filter_map(|s| s.as_str().map(str::to_string))
        .collect();
    Some(ScopeUpgradeRequired { required, granted })
}
```

This is the heart of M3-04. Implement `OAuthRefreshHook::refresh(prev_token_hash)` with the v3 §16.3 single-flight contract:

1. Acquire `refresh_lock` (blocking until available).

```rust
#[async_trait]
impl OAuthRefreshHook for RefreshDriver {
    async fn refresh(
        &self,
        prev_token_hash: lingxi_api_client::oauth_hook::TokenHash,
    ) -> Result<BearerToken, OAuthHookError> {
        // 1. Acquire the single-flight lock (v3 §16.3).
        let _guard = self.state.refresh_lock.lock().await;

        // 2. Double-check after acquire — another caller may have already
        //    refreshed under the lock we just got. Compare the current
        //    token_hash against prev; if different, return the current token.
        {
            let token = self.state.token.read().await;
            let current_hash = token.token_hash();
            if current_hash != prev_token_hash {
                // Another task refreshed; return the now-current token without
                // making an HTTP call.
                return Ok(BearerToken(Secret::new(
                    token.access_token.expose_secret().clone(),
                )));
            }
        }

        // 3. Hash still matches → we own the refresh. Read the refresh_token.
        let refresh_token = {
            let token = self.state.token.read().await;
            token
                .refresh_token
                .as_ref()
                .map(|s| Secret::new(s.expose_secret().clone()))
                .ok_or(OAuthHookError::RefreshFailed("no refresh_token in state".into()))?
        };

        let started = std::time::Instant::now();
        emit_refresh_started(&self.state.bus, "reactive_401").await;

        // 4. Perform the HTTP refresh.
        let body = match self.state.do_refresh_http(&refresh_token).await {
            Ok(b) => b,
            Err(OAuthError::RefreshExpired) => {
                emit_refresh_failed(&self.state.bus, "reactive_401", "refresh_expired").await;
                return Err(OAuthHookError::RefreshFailed(
                    "Session expired. Re-authenticate?".into(),
                ));
            }
            Err(e) => {
                emit_refresh_failed(&self.state.bus, "reactive_401", "provider_unreachable").await;
                return Err(OAuthHookError::ProviderUnreachable(format!("{e}")));
            }
        };

        // 5. Build the new `TokenInfo`.
        let now = self.state.clock.now();
        let new_expiry = now + Duration::from_secs(body.expires_in);
        let scopes = body
            .scope
            .as_deref()
            .map(|s| s.split_whitespace().map(str::to_string).collect::<Vec<_>>())
            .unwrap_or_else(|| self.state.config.scopes.clone());

        let new_info = TokenInfo {
            access_token: Secret::new(body.access_token.clone()),
            refresh_token: body
                .refresh_token
                .clone()
                .map(Secret::new)
                .or_else(|| {
                    // Provider didn't rotate refresh_token; keep the old one.
                    Some(refresh_token)
                }),
            expires_at: new_expiry,
            scopes,
        };

        // 6. Atomic swap. The double-check-after-acquire above guarantees we're
        //    the only writer in flight.
        {
            let mut guard = self.state.token.write().await;
            *guard = new_info;
        }

        // 7. Persist to keychain (best-effort — never fails the refresh on a
        //    keychain write error; the in-memory rotation succeeded).
        if let Err(e) = self
            .state
            .persist_to_keychain(&*self.state.token.read().await)
            .await
        {
            tracing::warn!(
                target: "lingxi::anthropic_oauth::refresh",
                error = %e,
                "keychain persistence failed; in-memory token is still rotated",
            );
        }

        let duration_ms = started.elapsed().as_millis() as u64;
        emit_refresh_succeeded(
            &self.state.bus,
            "reactive_401",
            new_expiry
                .duration_since(std::time::UNIX_EPOCH)
                .unwrap_or_default()
                .as_secs() as i64,
            duration_ms,
        )
        .await;

        Ok(BearerToken(Secret::new(body.access_token)))
    }

    async fn proactive_refresh(&self) -> Result<(), OAuthHookError> {
        // The proactive driver lives in the spawned task; this default impl
        // would only fire if the api-client middleware calls it directly,
        // which it does NOT in M3-04. Stub returning Ok per the trait default.
        Ok(())
    }
}
```

```rust
impl Clock for AdvancingClock {

/// Spawner that runs tasks on the tokio runtime and tracks handles via tokio
/// `JoinHandle` stored in a Mutex. Cancellation aborts the JoinHandle.
struct TokioSpawner {
    next_id: AtomicU64,
    handles: Mutex<Vec<(u64, tokio::task::JoinHandle<()>)>>,
}

#[async_trait]
impl RuntimeSpawner for TokioSpawner {
    async fn spawn(
        &self,
        name: &str,
        task: Pin<Box<dyn Future<Output = ()> + Send + 'static>>,
    ) -> Result<BackgroundTaskHandle, RuntimeError> {
        let id = self.next_id.fetch_add(1, Ordering::SeqCst);
        let jh = tokio::spawn(task);
        self.handles.lock().await.push((id, jh));
        Ok(BackgroundTaskHandle {
            task_name: name.into(),
            task_id: id,
        })
    }
    async fn sleep(&self, duration: Duration) {
        tokio::time::sleep(duration).await;
    }
    async fn cancel(&self, handle: &BackgroundTaskHandle) -> Result<(), RuntimeError> {
        let mut h = self.handles.lock().await;
        if let Some(pos) = h.iter().position(|(id, _)| *id == handle.task_id) {
            let (_, jh) = h.remove(pos);
            jh.abort();
            Ok(())
        } else {
            Err(RuntimeError::NotFound(handle.task_name.clone()))
        }
    }
}
```

```rust
impl RefreshDriver {
    /// Spawn the proactive refresh task. Returns once the spawn handle is
    /// stored in `state.proactive_handle`. The task itself loops until canceled
    /// by `AuthState::shutdown`.
    ///
    /// Wake interval is `min(remaining_lifetime / 2, PROACTIVE_LEAD_CAP)`
    /// before expiry (spec §7 line 721).
    pub async fn spawn_proactive(
        state: Arc<AuthState>,
        spawner: Arc<dyn lingxi_traits::RuntimeSpawner>,
    ) -> Result<(), OAuthError> {
        let task_state = state.clone();
        let task_spawner = spawner.clone();
        let fut: std::pin::Pin<Box<dyn std::future::Future<Output = ()> + Send + 'static>> =
            Box::pin(async move {
                proactive_loop(task_state, task_spawner).await;
            });
        let handle = spawner
            .spawn("lingxi-oauth-proactive-refresh", fut)
            .await
            .map_err(|e| OAuthError::TokenExchange(format!("spawn failed: {e}")))?;
        *state.proactive_handle.write().await = Some(handle);
        Ok(())
    }
}

/// The proactive task loop. Wakes at `min(remaining/2, 5min)` before expiry,
/// calls `RefreshDriver::refresh`, and reschedules against the new expiry.
async fn proactive_loop(
    state: Arc<AuthState>,
    spawner: Arc<dyn lingxi_traits::RuntimeSpawner>,
) {
    let driver = RefreshDriver::new(state.clone());
    loop {
        // Read current expiry + token_hash.
        let (expires_at, prev_hash) = {
            let t = state.token.read().await;
            (t.expires_at, t.token_hash())
        };
        let now = state.clock.now();
        let remaining = expires_at
            .duration_since(now)
            .unwrap_or(Duration::ZERO);
        let lead = proactive_lead(remaining);
        let sleep_for = remaining.checked_sub(lead).unwrap_or(Duration::ZERO);

        emit_refresh_started(&state.bus, "proactive_timer").await;

        // Sleep until the wake instant. `RuntimeSpawner::sleep` lets tests
        // virtualize time.
        spawner.sleep(sleep_for).await;

        // Fire a refresh. If it fails we emit a `_failed` event and back off
        // for 30 seconds; on hard failure (RefreshExpired) we exit the loop —
        // the next API call will surface the auth error to the user.
        match driver.refresh(prev_hash).await {
            Ok(_) => {
                // Success — loop continues against the freshly-rotated token.
                continue;
            }
            Err(lingxi_api_client::oauth_hook::OAuthHookError::RefreshFailed(msg))
                if msg == "Session expired. Re-authenticate?" =>
            {
                tracing::error!(
                    target: "lingxi::anthropic_oauth::proactive",
                    "refresh_token expired; exiting proactive loop"
                );
                emit_refresh_failed(&state.bus, "proactive_timer", "refresh_expired").await;
                return;
            }
            Err(e) => {
                tracing::warn!(
                    target: "lingxi::anthropic_oauth::proactive",
                    error = ?e,
                    "transient refresh failure; backing off 30s",
                );
                emit_refresh_failed(&state.bus, "proactive_timer", "provider_unreachable").await;
                spawner.sleep(Duration::from_secs(30)).await;
                continue;
            }
        }
    }
}
```

```rust
impl AuthState {
    /// Cancel the proactive refresh task (if running) and emit
    /// `tengu_oauth_proactive_canceled`. Idempotent — safe to call after the
    /// handle is already cleared.
    ///
    /// `spawner` must be the same `RuntimeSpawner` used by `spawn_proactive`;
    /// if a different one is passed, the handle may not be recognized and
    /// `cancel` returns `RuntimeError::NotFound` which we treat as a no-op.
    pub async fn shutdown(
        &self,
        spawner: &dyn lingxi_traits::RuntimeSpawner,
    ) {
        let handle = self.proactive_handle.write().await.take();
        let Some(handle) = handle else {
            // Already shut down — emit no event; matches v3 §16.4 idempotency.
            return;
        };
        if let Err(e) = spawner.cancel(&handle).await {
            tracing::warn!(
                target: "lingxi::anthropic_oauth::shutdown",
                error = ?e,
                task_name = %handle.task_name,
                "proactive task cancel returned error; treating as no-op",
            );
        }
        emit_proactive_canceled(&self.bus, "engine_shutdown").await;
    }
}
```

```rust
    pub required: Vec<String>,

/// Parse a 403 body for `required_scopes`. Returns `None` if the body is not
/// a scope-upgrade signal (other 403 reasons exist).
#[must_use]
pub fn parse_scope_upgrade(body: &str) -> Option<ScopeUpgradeRequired> {
    let v: serde_json::Value = serde_json::from_str(body).ok()?;
    let required = v.get("required_scopes")?.as_array()?;
    let required: Vec<String> = required
        .iter()
        .filter_map(|s| s.as_str().map(str::to_string))
        .collect();
    if required.is_empty() {
        return None;
    }
    let granted: Vec<String> = v
        .get("granted_scopes")
        .and_then(|g| g.as_array())
        .cloned()
        .unwrap_or_default()
        .iter()
        .filter_map(|s| s.as_str().map(str::to_string))
        .collect();
    Some(ScopeUpgradeRequired { required, granted })
}

/// Result of running a PKCE flow: a complete `TokenInfo` ready to swap into
/// `AuthState`.
#[derive(Debug)]
pub struct PkceRunResult {
    /// Fresh access_token from the IdP.
    pub access_token: Secret<String>,
    /// Fresh refresh_token from the IdP. Always rotated on a successful PKCE.
    pub refresh_token: Secret<String>,
    /// Scopes granted by the new token.
    pub scopes: Vec<String>,
    /// Expiry instant (wall clock).
    pub expires_at: SystemTime,
}

/// Abstraction over the PKCE flow. Production uses
/// `BrowserOpeningPkceRunner` (lives in `client.rs`); tests inject mocks.
#[async_trait]
pub trait PkceRunner: Send + Sync {
    /// Run a PKCE flow against the IdP and return the fresh tokens, or an
    /// `OAuthError` if the flow fails (e.g. user closed browser).
    async fn run_pkce(
        &self,
        config: &crate::config::ClaudeAiOAuthConfig,
        required_scopes: &[String],
    ) -> Result<PkceRunResult, OAuthError>;
}

/// Run a scope upgrade. Acquires `refresh_lock` (the same lock the reactive
/// path uses), runs PKCE, and atomically swaps `TokenInfo` on success.
///
/// On `Err(OAuthError::ScopeRejected)` (PKCE failed), the old `TokenInfo` is
/// preserved — the user is not logged out.
pub async fn run_scope_upgrade(
    state: &Arc<AuthState>,
    upgrade: ScopeUpgradeRequired,
    pkce_runner: &dyn PkceRunner,
) -> Result<(), OAuthError> {
    // Acquire the same lock the reactive refresh path uses so we serialize
    // against concurrent refreshes.
    let _guard = state.refresh_lock.lock().await;

    emit_scope_upgrade_started(&state.bus).await;

    // Run PKCE with the union of currently-granted + newly-required scopes.
    let mut requested = upgrade.granted.clone();
    for s in &upgrade.required {
        if !requested.contains(s) {
            requested.push(s.clone());
        }
    }
    let result = match pkce_runner.run_pkce(&state.config, &requested).await {
        Ok(r) => r,
        Err(e) => {
            emit_refresh_failed_scope_rejected(&state.bus).await;
            tracing::warn!(
                target: "lingxi::anthropic_oauth::scope_upgrade",
                error = ?e,
                "PKCE failed during scope upgrade; preserving existing token",
            );
            return Err(OAuthError::ScopeRejected {
                required: upgrade.required,
                granted: upgrade.granted,
            });
        }
    };

    // Atomically swap TokenInfo.
    let granted_count = result.scopes.len() as i64;
    let required_count = upgrade.required.len() as i64;
    let new_info = TokenInfo {
        access_token: result.access_token,
        refresh_token: Some(result.refresh_token),
        expires_at: result.expires_at,
        scopes: result.scopes,
    };
    {
        let mut guard = state.token.write().await;
        *guard = new_info;
    }

    emit_scope_upgraded(&state.bus, granted_count, required_count).await;
    Ok(())
}
```

```rust
//! Loom-driven single-flight invariant: concurrent reactive + proactive
//! `refresh()` invocations with the same `prev_token_hash` MUST collapse to
//! exactly ONE HTTP call.
//!
//! Spec §6 line 595, §8 M3-04 phase 8 — THE acceptance criterion.
//! Per v3 §32.7 hotspot list — OAuth single-flight is one of the four loom
//! invariants explicitly listed.
//!
//! Build/run:
//!   RUSTFLAGS="--cfg loom" cargo test -p lingxi-anthropic-oauth --test refresh_single_flight_test
//!
//! This file is gated behind `#[cfg(loom)]` so it does NOT compile in normal
//! `cargo test` runs (loom replaces std primitives with model-checking variants).

#![cfg(loom)]

use loom::sync::atomic::{AtomicU32, Ordering};
use loom::sync::{Arc, Mutex};
use loom::thread;

/// Stripped-down model of `AuthState` + `RefreshDriver::refresh`.
///
/// We don't run the real tokio code under loom (loom doesn't support tokio
/// scheduling). Instead, we model the invariant: a shared `Mutex<()>` for the
/// critical section, a shared atomic for `token_version` (analogue of
/// `TokenHash`), and a shared atomic for `http_calls`. The `refresh` analogue
/// performs: lock → double-check → (if check passes) increment http_calls +
/// bump token_version → unlock.
struct ModelAuthState {
    refresh_lock: Mutex<()>,
    token_version: AtomicU32,
    http_calls: AtomicU32,
}

impl ModelAuthState {
    fn new() -> Self {
        Self {
            refresh_lock: Mutex::new(()),
            token_version: AtomicU32::new(1),
            http_calls: AtomicU32::new(0),
        }
    }

    /// The single-flight refresh under model. Returns `()` on success.
    fn refresh(&self, prev_version: u32) {
        let _guard = self.refresh_lock.lock().unwrap();
        // Double-check after acquire: if version changed, another task
        // refreshed while we were waiting on the lock — bail without HTTP call.
        if self.token_version.load(Ordering::SeqCst) != prev_version {
            return;
        }
        // Otherwise: simulate the HTTP call + token rotation.
        self.http_calls.fetch_add(1, Ordering::SeqCst);
        self.token_version.fetch_add(1, Ordering::SeqCst);
    }
}

#[test]
fn concurrent_refresh_collapses_to_one_http_call() {
    loom::model(|| {
        let state = Arc::new(ModelAuthState::new());
        let prev = state.token_version.load(Ordering::SeqCst);

        let s1 = state.clone();
        let s2 = state.clone();
        let t1 = thread::spawn(move || s1.refresh(prev));
        let t2 = thread::spawn(move || s2.refresh(prev));
        t1.join().unwrap();
        t2.join().unwrap();

        // Across ALL schedules loom explores, exactly one HTTP call escaped.
        assert_eq!(state.http_calls.load(Ordering::SeqCst), 1);
        // And the token rotated exactly once.
        assert_eq!(state.token_version.load(Ordering::SeqCst), prev + 1);
    });
}
```
