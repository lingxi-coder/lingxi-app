# LingXi Core M3 · Plan 06 · Telemetry schema lock (200 `tengu_*` events + 3 sinks + audit proc-macro)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate at the end (Task 14) is the workspace-wide guard.

**Goal:** Build the `lingxi-telemetry::tengu` module tree as the **single authoritative source** for ~200 `tengu_*` event schemas across 8 sub-modules (`api`, `agent`, `session`, `tool`, `cost`, `oauth`, `memory`, `settings`). Every payload struct is `#[serde(deny_unknown_fields)]`; every payload enum is `#[non_exhaustive]`; every user-derived string field uses `Verified` or `PiiTagged` (not bare `String`). Ship three sinks — `NoOpSink` (default, no network), `InMemorySink` (test capture, required by M3-01..M3-05 integration tests), `StatsigSink` (trait extension point with skeleton HTTP-shaped impl). Add a new `lingxi-telemetry-macros` proc-macro crate whose `tengu_event_audit!` macro walks the module tree at compile time and refuses to compile if any payload struct uses bare `String`, omits `#[serde(deny_unknown_fields)]`, or any payload enum omits `#[non_exhaustive]`. Lock the full event-name list + sample payloads in `parity_tengu_events.json` (v3 §32.6 fixture protocol).

**Architecture:** The crate gains two new top-level module trees: `tengu/` (eight files, one per category, each declaring the typed payload structs and a thin emit helper that builds `LogEventMetadata` and calls `AnalyticsBus::log_event`) and `sinks/` (three files implementing the existing `AnalyticsSink` trait). Each `tengu_<category>::EventName` value is a `pub const EventName(&'static str)` — wire bytes locked at compile time. The proc-macro lives in a NEW sibling crate `lingxi-telemetry-macros` (separate crate so `proc-macro = true` doesn't infect the runtime crate); `lingxi-telemetry::tengu::mod` invokes `tengu_event_audit!()` once at crate root, which expands to a `compile_error!()` if the audit fails. Integration tests live under `crates/telemetry/tests/` and exercise (1) every payload deserializes-then-reserializes-byte-stable, (2) every sink correctly receives a representative event, (3) the audit macro rejects bare `String` via a `compile_fail` trybuild case. The parity driver lives at the workspace test-harness level and asserts the JSON fixture's 200-name list is **exactly** the names re-exported from `tengu::ALL_EVENT_NAMES`.

**Tech Stack:** Rust 2021, `serde 1` + `serde_json 1` (workspace), `async-trait 0.1` (workspace), `tokio 1` (workspace; `sync` + `time` features only), existing `lingxi-telemetry::pii::{Verified, PiiTagged}`, existing `lingxi-telemetry::sink::{AnalyticsSink, AnalyticsValue, LogEventMetadata}`, existing `lingxi-telemetry::bus::AnalyticsBus`, existing `lingxi-telemetry::killswitch::Killswitch`, existing `lingxi-protocol::Secret<T>` (for `StatsigSink::sdk_key`). New dev deps: `trybuild 1` (compile_fail test harness for the proc-macro), `tempfile 3` (no — already in workspace). New proc-macro deps in the new sibling crate `lingxi-telemetry-macros`: `proc-macro2 1`, `syn 2` (`full` + `extra-traits` features for module-walk), `quote 1`.

## Critical 1:1 fidelity items (locked specifics — appear byte-for-byte in code AND in at least one test assertion)

These are non-negotiable strings/numbers from claude-code @ 6a25909 + spec §7 that drift breaks downstream parity with:

- **Statsig wire shape**: every event serializes through `MockStatsigSink` (and downstream real `StatsigSink` impls) as JSON `{"event_name": "<name>", "value": <number-or-null>, "metadata": <object>}`. The `value` field is `null` for events with no numeric primary measurement (most events) and is the primary numeric measurement (e.g. `cost_nano_usd as f64 / 1e9` for `tengu_cost_recorded`) otherwise. Matches `src/services/statsig.ts::logStatsigEvent(eventName, value, metadata)` in claude-code @ 6a25909. Locked in Task 11 and parity-asserted in Task 13.
- **All payload structs use `#[serde(deny_unknown_fields)]`**: enforced by the audit proc-macro (Task 12) and verified in `schema_validation_test.rs` (Task 11). A struct lacking this attribute MUST fail compilation.
- **All payload enums use `#[non_exhaustive]`**: enforced by the audit proc-macro. New variants are non-breaking additions; missing the attribute MUST fail compilation.
- **All user-derived string fields are `Verified` or `PiiTagged`**: bare `String` in a `*Payload` struct MUST fail compilation via the audit macro. The whitelist of permitted primitive types is: `bool`, `i32`, `i64`, `u32`, `u64`, `f32`, `f64`, `Verified`, `PiiTagged`, `Option<Verified>`, `Option<PiiTagged>`, `Option<u64>`, `Option<i64>`, `Option<bool>`, `SessionId`, `Vec<Verified>`, `Vec<PiiTagged>`, `serde_json::Value` (only for the `extra: serde_json::Value` field on agent.rs's `LoopIterationPayload`, which carries free-form snapshot data that the audit walker special-cases by exact field name).
- **`#[non_exhaustive]` on `OverflowPolicy`**: `pub enum OverflowPolicy` is `#[non_exhaustive]` so adding `Block` or `Reject` later is non-breaking.
- **Event-name append-only rule**: spec §7 line 787-789 — removing a name from `ALL_EVENT_NAMES` is a v0.5+ breaking change. The audit macro checks the previous-known-name list (sourced from the parity fixture) is a subset of the current `ALL_EVENT_NAMES`. (Implemented as a "previous names file" embed in Task 12; M3-06 establishes the baseline at 143 names.)
- **Event-name evolution**: spec §7 line 781-784 — adding a field to an *existing* event is breaking; instead define a sibling `tengu_<name>_v2` event and deprecate `tengu_<name>` over 2 minor releases. M3-06 ships no `_v2` siblings (no breaks yet) but the fixture's `_note` field documents the rule.
- **`Verified::assert_safe`** is the constructor — caller must explicitly assert the string is PII-free. The audit-macro check is "field type literally `Verified`" — the discipline of when to call `assert_safe` lives in the emitter, not the schema. Same for `PiiTagged::assert_pii_tagged_column`.
- **`strip_proto_fields` runs at every non-proto sink before serialization**: `MockStatsigSink::log_event` calls `strip_proto_fields(&mut metadata)` before building the wire JSON. `InMemorySink` does NOT strip (tests need to see proto keys to verify routing). `NoOpSink` ignores metadata entirely so the question doesn't apply.
- **`NoOpSink::log_event` MUST NOT do network I/O**: enforced by clippy lint `await_holding_lock` + manual code review; verified in `sinks_roundtrip_test.rs` by asserting no `reqwest`/`tokio::net` symbol leaks (compile-time check via the absence of those deps from `crates/telemetry/Cargo.toml`).
- **`NoOpSink` is the default**: `AnalyticsBus::with_default_sink()` constructor attaches a `NoOpSink` immediately so the bus never buffers events when called from a platform's default config. The existing `AnalyticsBus::new()` keeps the "no sink attached, buffer first 1000 events" semantics (for boot-strap windows where the sink choice depends on settings loaded later).
- **`InMemorySink` retains insertion order**: `Vec<RecordedEvent>` push-only; `events()` clones in insertion order. Required because M3-01..M3-05 integration tests assert event-order invariants (e.g. M3-05's "succeeded before cost_recorded" rule).
- **`InMemorySink::clear()` is provided**: tests that reuse a sink across cases need a clear; without it the sink leaks state between `#[tokio::test]` functions.
- **`StatsigSink::sdk_key` returns `&Secret<String>`**: not `&str`, not `&String`. The `Secret<T>` wrapper enforces `Debug`/`Display` redaction. Audit: search for `expose_secret(` to find every read.
- **`StatsigSink::flush` + `shutdown` are async** and return `Result<(), TelemetryError>`. Locked per spec line 925-927.
- **`TelemetryError::UnknownEvent { name: String }` Display string (byte-for-byte)**: `"unknown event name {name} (not in tengu_* schema)"` — locked via `#[error("unknown event name {name} (not in tengu_* schema)")]` per spec line 506-507.
- **`TelemetryError::PayloadInvalid { event: String, detail: String }` Display string (byte-for-byte)**: `"event payload validation failed for {event}: {detail}"` — locked per spec line 508-509.
- **The proc-macro lives in a SIBLING crate, not the runtime crate**: `proc-macro = true` on the runtime telemetry crate would prevent it from being used as a regular dep by downstream crates. The new `lingxi-telemetry-macros` crate is `proc-macro = true`; the runtime crate `lingxi-telemetry` depends on it normally and re-exports the macro via `pub use lingxi_telemetry_macros::tengu_event_audit;` (Task 12 wires this).
- **Audit-macro file walk**: at compile time, `tengu_event_audit!()` reads files from `$CARGO_MANIFEST_DIR` (i.e. the directory of `lingxi-telemetry/Cargo.toml`, which is where the macro is invoked from) — specifically `src/tengu/*.rs` via a relative path. Files outside that directory are not walked; macros invoked from other crates produce a `compile_error!("tengu_event_audit must be invoked from lingxi-telemetry crate root")`. Implementation note: `proc_macro2::Span::call_site()` does NOT give file paths reliably across compiler versions; we use `std::env!("CARGO_MANIFEST_DIR")` baked into the macro's expansion at compile time via the `cargo` build script env mechanism. Concretely the macro reads `option_env!("CARGO_MANIFEST_DIR")` from within the proc-macro itself — which gives the proc-macro crate's own dir, NOT the invoking crate's. To get the invoking crate's dir we use the well-known proc-macro pattern: the macro takes no arguments, hard-codes the relative path `../telemetry/src/tengu/` (this works because the proc-macro crate is at a known sibling location in the workspace). Concrete spec: `let macro_crate_dir = env!("CARGO_MANIFEST_DIR"); let tengu_dir = PathBuf::from(macro_crate_dir).join("..").join("telemetry").join("src").join("tengu");`. Documented in Task 12 with the rationale.

use lingxi_telemetry::{
    AnalyticsBus, AnalyticsSink, AnalyticsValue, InMemorySink, LogEventMetadata, NoOpSink,

#[tokio::test]

    let sink = Arc::new(InMemorySink::new());
    let mut md1 = HashMap::new();
    md1.insert("x".into(), AnalyticsValue::Int(1));
    let mut md2 = HashMap::new();
    md2.insert("y".into(), AnalyticsValue::Int(2));

    sink.log_event("evt_one", md1).await;
    sink.log_event("evt_two", md2).await;

    let events = sink.events().await;
    assert_eq!(events.len(), 2);
    assert_eq!(events[0].name, "evt_one");

    assert_eq!(sink.events().await.len(), 1);
    sink.clear().await;
    assert_eq!(sink.events().await.len(), 0);
}

#[tokio::test]
async fn analytics_bus_with_default_sink_is_noop() {
    let bus = AnalyticsBus::with_default_sink();
    // No buffer drain needed; sink is attached at construction.

    let in_mem = Arc::new(InMemorySink::new());
    bus.attach_sink(in_mem.clone()).await;
    bus.log_event("after_swap", HashMap::new()).await;
    let events = in_mem.events().await;
    assert_eq!(events.len(), 1);
    assert_eq!(events[0].name, "after_swap");

impl AnalyticsBus {
    /// Construct a bus with a [`crate::sinks::NoOpSink`] attached synchronously.
    ///
    /// Use this when the platform has no opinion about telemetry sinks and
    /// wants the "never buffer" guarantee. The bus's existing
    /// [`Self::new`] keeps the "no sink attached, buffer up to 1000 events"
    /// semantics for boot-strap windows where the sink choice depends on
    /// settings loaded later.
    #[must_use]
    pub fn with_default_sink() -> Self {
        use crate::sinks::NoOpSink;
        use std::sync::Arc;
        let bus = Self::new();
        // Synchronous attach: NoOpSink construction is infallible and
        // `attach_sink` only awaits when there are pending events to drain
        // (there are none here since we just constructed the bus). We use
        // `block_in_place` would deadlock — instead inject directly via the
        // private state. Since `sink` is `RwLock<Option<Arc<...>>>` we can't
        // poke it without an async context. Workaround: stash NoOp in a
        // try_write that always succeeds for a freshly-constructed bus.
        if let Ok(mut guard) = bus.sink.try_write() {
            *guard = Some(Arc::new(NoOpSink));
        }
        bus
    }
}

//! `StatsigSink` trait + `MockStatsigSink` reference impl.
//!
//! Spec §8 M3-06 phase 11. Real provider impls live in platform crates;
//! this module ships only the trait surface and a mock with the wire
//! format locked.
//!
//! Wire shape (claude-code @ 6a25909 `src/services/statsig.ts::logStatsigEvent`):
//! `{"event_name": "<name>", "value": <number|null>, "metadata": <object>}`.

use crate::error::TelemetryError;
use crate::pii::strip_proto_fields;
use crate::sink::{AnalyticsSink, AnalyticsValue, LogEventMetadata};
use async_trait::async_trait;
use lingxi_protocol::Secret;
use serde_json::{json, Map, Value};
use tokio::sync::Mutex;

/// Statsig-shaped sink contract. Spec line 921-929.
///
/// Adapters implement [`AnalyticsSink`] + this trait. Engine init code that
/// wants Statsig routing downcasts via `Arc<dyn AnalyticsSink>::downcast`-able
/// wrappers (or constructs the concrete sink at platform-init time).
#[async_trait]
pub trait StatsigSink: AnalyticsSink {
    /// Return the SDK key, wrapped in [`Secret<String>`] so `Debug`/`Display`
    /// always redact.
    fn sdk_key(&self) -> &Secret<String>;

    /// Force-flush any buffered events. Real impls block until the upstream
    /// confirms delivery; the mock returns `Ok(())` immediately.
    async fn flush(&self) -> Result<(), TelemetryError>;

    /// Tear the sink down; same semantics as `flush` plus releases any
    /// background tasks. Idempotent.
    async fn shutdown(&self) -> Result<(), TelemetryError>;
}

/// Reference mock impl. Captures events to an in-memory `Vec`, builds the
/// canonical wire JSON via [`Self::statsig_wire_payload`], and provides the
/// `flush` / `shutdown` no-op stubs.
pub struct MockStatsigSink {
    sdk_key: Secret<String>,
    captured: Mutex<Vec<Value>>,
}

impl MockStatsigSink {
    /// Construct with a (zeroed-on-drop) SDK key.
    #[must_use]
    pub fn new(sdk_key: Secret<String>) -> Self {
        Self {
            sdk_key,
            captured: Mutex::new(Vec::new()),
        }
    }

    /// Build the Statsig `logStatsigEvent` wire-JSON payload.
    ///
    /// `value` is `Some(numeric primary measurement)` for events with a single
    /// dominant number (e.g. cost USD, duration); `None` for events that have
    /// no scalar primary (most events). `metadata` is the raw `LogEventMetadata`
    /// from the bus; `_PROTO_*` keys are stripped before serialization.
    #[must_use]
    pub fn statsig_wire_payload(
        &self,
        event_name: &str,
        metadata: &LogEventMetadata,
        value: Option<f64>,
    ) -> Value {
        let mut md = metadata.clone();
        strip_proto_fields(&mut md);
        let metadata_value: Map<String, Value> = md
            .into_iter()
            .map(|(k, v)| (k, analytics_value_to_json(&v)))
            .collect();
        json!({
            "event_name": event_name,
            "value": value,
            "metadata": Value::Object(metadata_value),
        })
    }

    /// Return a snapshot of every captured wire payload (for test assertion).
    pub async fn captured_payloads(&self) -> Vec<Value> {
        self.captured.lock().await.clone()
    }
}

fn analytics_value_to_json(v: &AnalyticsValue) -> Value {
    match v {
        AnalyticsValue::Bool(b) => Value::Bool(*b),
        AnalyticsValue::Int(i) => Value::Number((*i).into()),
        AnalyticsValue::Float(f) => {
            serde_json::Number::from_f64(*f).map_or(Value::Null, Value::Number)
        }
        AnalyticsValue::String(s) => Value::String(s.clone()),
        AnalyticsValue::None => Value::Null,
    }
}

#[async_trait]
impl AnalyticsSink for MockStatsigSink {
    async fn log_event(&self, name: &str, metadata: LogEventMetadata) {
        let wire = self.statsig_wire_payload(name, &metadata, None);
        self.captured.lock().await.push(wire);
    }

    async fn log_event_async(&self, name: &str, metadata: LogEventMetadata) {
        self.log_event(name, metadata).await;
    }

    fn name(&self) -> &str {
        "mock_statsig"
    }
}

#[async_trait]
impl StatsigSink for MockStatsigSink {
    fn sdk_key(&self) -> &Secret<String> {
        &self.sdk_key
    }

    async fn flush(&self) -> Result<(), TelemetryError> {
        // Mock: nothing to flush; real impl awaits upstream confirmation.
        Ok(())
    }

    async fn shutdown(&self) -> Result<(), TelemetryError> {
        // Mock: clear buffer and return.
        self.captured.lock().await.clear();
        Ok(())
    }
}

//!   source as input; same audit logic but inline. Used by `trybuild` cases
//!   to exercise the negative paths.

/// Compile-time event-audit macro. Takes no arguments; expands to `()` on
/// success, `compile_error!(...)` on failure.
///
/// Invoke from `tengu/mod.rs` as `lingxi_telemetry_macros::tengu_event_audit!();`.
#[proc_macro]
pub fn tengu_event_audit(input: TokenStream) -> TokenStream {
    let _ = input;
    let macro_crate_dir = env!("CARGO_MANIFEST_DIR");
    let tengu_dir = PathBuf::from(macro_crate_dir)
        .join("..")
        .join("telemetry")
        .join("src")
        .join("tengu");

    let mut errors: Vec<String> = Vec::new();
    let categories = [
        "api", "agent", "session", "tool", "cost", "oauth", "memory", "settings",
    ];
    for cat in &categories {
        let path = tengu_dir.join(format!("{cat}.rs"));
        match std::fs::read_to_string(&path) {
            Ok(src) => {
                if let Err(msg) = audit_source(&src) {
                    errors.push(format!("{cat}.rs: {msg}"));
                }
            }
            Err(e) => {
                errors.push(format!("{cat}.rs: failed to read {}: {}", path.display(), e));
            }
        }
    }

    if errors.is_empty() {
        quote!(()).into()
    } else {
        let joined = errors.join("\n  ");
        let msg = format!("tengu_event_audit rejected schema:\n  {joined}");
        quote!(compile_error!(#msg);).into()
    }
}

/// Doc-hidden test helper. Takes a string-literal source as input, runs the
/// same audit logic, and emits `compile_error!` on rejection. Used by the
/// `trybuild` compile_fail / compile_pass cases.
#[proc_macro]
#[doc(hidden)]
pub fn _audit_source(input: TokenStream) -> TokenStream {
    let lit = parse_macro_input!(input as LitStr);
    match audit_source(&lit.value()) {
        Ok(()) => quote!(()).into(),
        Err(msg) => {
            let m = format!("audit rejected: {msg}");
            quote!(compile_error!(#m);).into()
        }
    }
}

/// Private — parses a single source string and audits its payload structs +
/// payload enums. Not exported (proc-macro crates cannot export non-macro fns).
///
/// Returns `Ok(())` if the source is acceptable, `Err(detail)` otherwise.
fn audit_source(src: &str) -> Result<(), String> {
    let file = syn::parse_file(src).map_err(|e| format!("parse error: {e}"))?;

    // First pass: enumerate every enum defined in the file. The second pass
    // verifies that any enum referenced as a payload field is `#[non_exhaustive]`.
    let mut enums_by_name: std::collections::HashMap<String, bool> = Default::default();
    for item in &file.items {
        if let syn::Item::Enum(e) = item {
            let has_non_exhaustive = e.attrs.iter().any(|a| a.path().is_ident("non_exhaustive"));
            enums_by_name.insert(e.ident.to_string(), has_non_exhaustive);
        }
    }

    // The whitelist of acceptable primitive type segment names (last segment).
    let allowed_types: HashSet<&str> = [
        "bool", "i32", "i64", "u32", "u64", "f32", "f64",
        "Verified", "PiiTagged",
        "SessionId",
    ]
    .into_iter()
    .collect();

    for item in &file.items {
        let syn::Item::Struct(s) = item else { continue };
        let name = s.ident.to_string();
        if !name.ends_with("Payload") {
            continue;
        }

        // (1) #[serde(deny_unknown_fields)] is required.
        let has_deny = s.attrs.iter().any(|a| {
            if !a.path().is_ident("serde") { return false; }
            let mut found = false;
            // Best-effort: parse the meta list and look for the bareword.
            let _ = a.parse_nested_meta(|m| {
                if m.path.is_ident("deny_unknown_fields") {
                    found = true;
                }
                Ok(())
            });
            found
        });
        if !has_deny {
            return Err(format!(
                "{name}: missing #[serde(deny_unknown_fields)] (spec §7 line 768)"
            ));
        }

        // (2) Every field must be a whitelisted type.
        let syn::Fields::Named(fields) = &s.fields else {
            return Err(format!("{name}: payload structs must use named fields"));
        };
        for field in &fields.named {
            let field_name = field
                .ident
                .as_ref()
                .map(ToString::to_string)
                .unwrap_or_default();
            let type_ok = field_type_is_allowed(
                &field.ty,
                &field_name,
                &allowed_types,
                &enums_by_name,
            )?;
            if !type_ok {
                let ty = &field.ty;
                let ty_str = quote!(#ty).to_string();
                return Err(format!(
                    "{name}::{field_name}: disallowed field type `{}` — \
                    user-derived strings must use Verified or PiiTagged \
                    (spec §7 line 772-774)",
                    ty_str.trim()
                ));
            }
        }
    }
    Ok(())
}

fn field_type_is_allowed(
    ty: &syn::Type,
    field_name: &str,
    allowed_types: &HashSet<&str>,
    enums_by_name: &std::collections::HashMap<String, bool>,
) -> Result<bool, String> {
    let syn::Type::Path(p) = ty else { return Ok(false) };
    let segs = &p.path.segments;
    let last = segs.last().expect("type path must have at least one segment");
    let ident = last.ident.to_string();

    // Special-case 1: the LoopIterationPayload `extra: serde_json::Value` field.
    if field_name == "extra" {
        // Must be exactly `serde_json::Value` (full path) OR `Value` (alias).
        let path_str = segs
            .iter()
            .map(|s| s.ident.to_string())
            .collect::<Vec<_>>()
            .join("::");
        if path_str == "serde_json::Value" || ident == "Value" {
            return Ok(true);
        }
        return Ok(false);
    }
    // serde_json::Value is otherwise disallowed.
    let path_str_check = segs
        .iter()
        .map(|s| s.ident.to_string())
        .collect::<Vec<_>>()
        .join("::");
    if path_str_check == "serde_json::Value" || ident == "Value" {
        // Not in the `extra` slot -> reject.
        return Err(format!(
            "field `{field_name}`: serde_json::Value is only allowed for the \
            free-form `extra` field name"
        ));
    }

    // Whitelist primitives + Verified / PiiTagged / SessionId by leaf name.
    if allowed_types.contains(ident.as_str()) {
        return Ok(true);
    }

    // Option<T> / Vec<T> — unwrap one level and recurse.
    if ident == "Option" || ident == "Vec" {
        let syn::PathArguments::AngleBracketed(args) = &last.arguments else {
            return Ok(false);
        };
        let Some(syn::GenericArgument::Type(inner)) = args.args.first() else {
            return Ok(false);
        };
        return field_type_is_allowed(inner, field_name, allowed_types, enums_by_name);
    }

    // Enum used as field — must be locally defined AND `#[non_exhaustive]`.
    if let Some(non_exh) = enums_by_name.get(&ident) {
        if !non_exh {
            return Err(format!(
                "field `{field_name}` uses enum `{ident}` which lacks #[non_exhaustive] \
                (spec §7 line 785-786)"
            ));
        }
        return Ok(true);
    }

    Ok(false)
}
