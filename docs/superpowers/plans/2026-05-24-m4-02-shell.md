# LingXi Core M4 · Plan 02 · Shell tools (Bash + PowerShell + REPL + Sleep)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate at the end (Task 18) is the workspace-wide guard.

**Goal:** Ship 4 byte-aligned, hermetic, telemetry-bound shell tools — `BashTool`, `PowerShellTool`, `REPLTool`, `SleepTool` — under `lingxi-code/crates/tools/src/builtin/`, fully integrating M2-04 sandbox dispatch (`should_use_sandbox` + `wrap_with_sandbox`) and M2-06 process polish (setsid+killpg tree-kill, 64 MB `StderrRing` cap, `spawn_background` + `task_output_path`). Tag `m4.2` at the end. All claude-code wire literals from spec §7 baked into both production code AND test assertions byte-for-byte.

**Architecture:** Four new files under `lingxi-tools/src/builtin/` plus a new shared helper `shared/ansi_strip.rs` for cleaning ANSI escape sequences out of bash/repl output. The 4 tools depend on the existing M1 `lingxi-traits::Process` (`ProcessRunner::run` for synchronous, `spawn_background` for `run_in_background: true`), `lingxi-traits::Clock` (`SleepTool`), and the M2-04 `lingxi-sandbox` decision/wrap pipeline (`should_use_sandbox` returns either `NoSandbox`, `Sandbox { policy }`, or `RefuseBecauseSandboxUnavailable { reason }`; the Sandbox branch is then converted into a wrapped shell command via `wrap_with_sandbox(command, &policy, platform)` and re-fed into `/bin/sh -c <wrapped>` for the `ProcessRunner`). `BuiltinToolContext` (declared in M4-01 `builtin/mod.rs`) grows two new fields: `process: Arc<dyn ProcessRunner>`, `clock: Arc<dyn Clock>`, plus shell-specific runtime hints (`SandboxRuntimeConfig`, `PermissionMode`, `ProjectTrustLevel`, `sandbox_available: bool`, `workspace: PathBuf`). The 12 tengu events: `BASH_*` already exist in M3-06 (`BASH_STARTED`/`BASH_COMPLETED`/`BASH_FAILED`/`BASH_TIMEOUT`); PowerShell/REPL/Sleep events do NOT exist in M3-06's `tengu/tool.rs` yet — M4-02 declares the 9 new string constants directly in `lingxi-telemetry::tengu::tool` (the central name registry) AND extends the crate-private `NAMES` array so M4-09's `parity_telemetry_coverage.rs` driver enumerates them. The local `lingxi-tools/src/builtin/shell_events.rs` module is a thin re-export façade only — the canonical declarations live upstream.

**Tech Stack:** Rust 2021, `async-trait 0.1` (workspace), `serde 1` + `serde_json 1` (workspace), `tokio 1` (workspace; `process` + `time` + `sync` features), `lingxi-traits::process::{ProcessRunner, ProcessCommand, ProcessOutput, ProcessHandle, ProcessError}` (M1), `lingxi-traits::sandbox::{Sandbox, SandboxedCommand, ProcessCommand}` (M1), `lingxi-traits::Clock` (M1), `lingxi-sandbox::decision::{should_use_sandbox, SandboxDecision, ProjectTrustLevel}` + `lingxi-sandbox::wrap::{wrap_with_sandbox, SandboxWrapError}` + `lingxi-sandbox::runtime_config::{SandboxRuntimeConfig, Platform}` (M2-04), `lingxi-permission::PermissionMode`, `lingxi-telemetry::{AnalyticsBus, AnalyticsValue, LogEventMetadata, pii::{Verified, PiiTagged}}` (M3-06) + `lingxi-telemetry::tengu::tool::{BASH_STARTED, BASH_COMPLETED, BASH_FAILED, BASH_TIMEOUT}`. New crate-level deps in `lingxi-tools/Cargo.toml`: `lingxi-sandbox = { path = "../sandbox" }`. No new third-party deps (`which` is **not** added — PowerShell path resolution uses `std::env::var("PATH")` + `Path::join` because adding the `which` crate just for `pwsh` discovery would bloat the dep graph; the resolution logic is 15 LOC). Dev deps: `tempfile = "3.13"` (likely already added in M4-01), `lingxi-test-harness = { path = "../test-harness" }` (for the `MockProcessRunner` + `MockClock` fakes already in place from M1).

- `lingxi-code/crates/tools/src/shared/ansi_strip.rs` — pure-functional ANSI escape-sequence stripper.
  - `pub fn strip_ansi(input: &str) -> String` — applies the regex `\x1b\[[0-9;]*[a-zA-Z]` and returns a copy with all matches removed. Uses a hand-rolled state machine (no `regex` crate dep — the pattern is trivial: `ESC` (`\x1b`) → `[` → zero or more digits/`;` → exactly one alpha char terminates the sequence). Pure-Rust, no extra dep. Counts dropped chars and exposes them via a sibling `pub fn strip_ansi_count(input: &str) -> (String, usize)` returning `(stripped, dropped_chars)` so telemetry can record `ansi_chars_stripped`.
  - `pub const ANSI_ESCAPE_REGEX_LITERAL: &str = r"\x1b\[[0-9;]*[a-zA-Z]";` — locked literal (string form of the spec §7 regex); used in the parity fixture assertion.

- `lingxi-code/crates/tools/src/builtin/bash.rs` — `BashTool`. Input schema:
  ```jsonc
  {
    "type": "object",
    "properties": {
      "command":           { "type": "string" },
      "timeout_ms":        { "type": "integer", "minimum": 1, "maximum": 600000 },
      "run_in_background": { "type": "boolean" },
      "description":       { "type": "string" }
    },
    "required": ["command"]
  }
  ```
  - Constants:
    - `pub const BASH_DEFAULT_TIMEOUT_MS: u64 = 120_000;`  (2 min, claude-code lock)
    - `pub const BASH_MAX_TIMEOUT_MS: u64 = 600_000;`  (10 min, claude-code lock)
    - `pub const BASH_TIMEOUT_ERROR_TEMPLATE: &str = "Bash command timed out after {N}ms";` (literal lock; `{N}` substituted via `String::replace`)
    - `pub const BASH_SHELL_LINUX: &str = "/bin/bash";`
    - `pub const BASH_SHELL_MACOS: &str = "/bin/zsh";`
  - Flow per spec §4 Flow C:
    1. Validate `timeout_ms ≤ BASH_MAX_TIMEOUT_MS`; default = `BASH_DEFAULT_TIMEOUT_MS`.
    2. Resolve shell binary: macOS → `BASH_SHELL_MACOS`, else `BASH_SHELL_LINUX`. Windows is rejected upstream by `wrap_with_sandbox::Unsupported`, but as a defensive fallback BashTool also rejects `cfg(target_os = "windows")` with `ToolError::InvalidInput("Bash is not supported on Windows; use PowerShellTool")`.
    3. Call `should_use_sandbox(&command, ctx.permission_mode, ctx.project_trust, ctx.classifier_safe, ctx.sandbox_available, ctx.workspace)` to get a `SandboxDecision`.
    4. Branch:
       - `NoSandbox` → build `ProcessCommand { command: shell, args: vec!["-c".into(), command.clone()], cwd: Some(workspace), env, timeout: Some(Duration::from_millis(timeout_ms)), stdin: None }` and feed through `Sandbox::bypass_with_audit(reason="classifier_safe_in_trusted_project")`.
       - `Sandbox { policy }` → produce `SandboxRuntimeConfig` from the policy via `policy_convert::from_policy(&policy)`, call `wrap_with_sandbox(&command, &runtime_config, platform_from_cfg())?`, then build a `ProcessCommand` whose `args = ["-c", wrapped_command_string]` and whose `command` is still the shell binary, and feed through `Sandbox::prepare(...)`. **Critical:** sandbox wrap returns a `Result<String, SandboxWrapError>`; on `SandboxWrapError::Unsupported(s)` we surface `ToolError::InvalidInput(s)` (the string is M2-04's locked `"sandbox not supported on this platform"`).
       - `RefuseBecauseSandboxUnavailable { reason }` → `ToolError::PermissionDenied(reason)`.
    5. If `run_in_background == true` → `runner.spawn_background(&sandboxed).await` → return `{ pid, task_id, task_output_path: <path from task_output_path(&task_id)> }` immediately (do NOT wait). Emit `BASH_STARTED` only (no `_COMPLETED`).
    6. Else → `runner.run(&sandboxed).await` → branch on `ProcessOutput.timed_out`:
       - `timed_out=true` → emit `BASH_TIMEOUT` (with `request_id`, `command_hash`, `timeout_ms`) → return `ToolError::Timeout { timeout_ms }`. **But** the human-facing string surfaced to the model in the returned JSON (when wrapped through `Tool::call`'s error path by the dispatcher) is the byte-locked `"Bash command timed out after {N}ms"` — to keep both the machine `ToolError` AND the model-facing string available, we surface the string via `ToolError::Internal(format!("Bash command timed out after {}ms", timeout_ms))` instead of `Timeout { ... }`. Trade-off documented in the Critical Fidelity table below.
       - `timed_out=false` → strip ANSI from `stdout` AND `stderr` (`shared::ansi_strip::strip_ansi_count`) → truncate combined output (`stdout + "\n" + stderr` if stderr non-empty, else just `stdout`) at `MAX_TOOL_OUTPUT_LENGTH` (30_000 chars from `shared::output_truncation::TRUNCATION_SUFFIX`) → emit `BASH_COMPLETED` with `{ request_id, exit_code, output_bytes, duration_ms, ansi_chars_stripped, truncated }` → return `ToolCallResult { data: json!({ "exit_code": <i32>, "stdout": <truncated>, "stderr": "", "timed_out": false, "is_error": <bool>, "truncated": <bool> }) }`. `is_error = (exit_code != 0)` — but this is reported as **data**, NOT as a `Result::Err` (per spec §5 "non-zero is NOT Err — ToolCallResult.is_error=true").
  - Tool metadata: `name() = "Bash"`, `is_concurrency_safe(_) = false` (commands have side effects), `is_read_only(_) = false`, `is_open_world(_) = false` (the agent loop may overrule if `command` contains network requests, but the static answer is false), `is_destructive(_) = true` (default to defensive), `interrupt_behavior(_) = InterruptBehavior::Cancel` (bash can be killed).
  - Telemetry per call:
    - Start: `bus.log_event(BASH_STARTED, { request_id: Verified, command_hash: Verified (sha256 of command), timeout_ms: Verified, run_in_background: Verified })`.
    - On error path: `BASH_FAILED` with `{ request_id, error_kind: Verified, duration_ms }`. The `error_kind` is one of `"timeout"|"spawn_failed"|"sandbox_refused"|"validation"|"io"`.
    - On success: `BASH_COMPLETED` with `{ request_id, exit_code: Verified, output_bytes: Verified, duration_ms, ansi_chars_stripped, truncated }`.

  ```jsonc
  {
    "type": "object",
    "properties": {
      "language": { "type": "string", "enum": ["python", "node", "ruby"] },

    },
  ```

  ```jsonc
    "type": "object",
  ```

```rust
//! ANSI escape-sequence stripper.
//!
//! Removes the `\x1b\[[0-9;]*[a-zA-Z]` pattern from process output before it
//! is returned to the model. The regex literal is locked in spec §7 (M4-02

/// Locked regex literal — the canonical cross-platform parity contract.
/// The implementation below is a hand-rolled state machine that recognizes
/// the same language as this regex; the constant exists so test fixtures and
/// downstream consumers can assert the contract by string.
pub const ANSI_ESCAPE_REGEX_LITERAL: &str = r"\x1b\[[0-9;]*[a-zA-Z]";

/// Strip ANSI CSI escape sequences from `input`. Returns the cleaned string.
#[must_use]
pub fn strip_ansi(input: &str) -> String {
    strip_ansi_count(input).0
}

/// Strip ANSI CSI escape sequences and report how many characters were dropped.
///
/// State machine:
/// - `Normal`: pass char through; on `\x1b`, transition to `Esc`.
/// - `Esc`: expect `[`; on `[`, transition to `Csi`; on anything else, emit the
///   buffered `\x1b` and the current char and go back to `Normal`.
/// - `Csi`: consume digits and `;` greedily; on an ASCII alpha (`[a-zA-Z]`),
///   terminate the sequence (drop everything from `\x1b` through this char
///   inclusive) and go back to `Normal`; on EOF, emit the buffered bytes verbatim.
#[must_use]
pub fn strip_ansi_count(input: &str) -> (String, usize) {
    enum State {
        Normal,
        Esc,
        Csi,
    }
    let mut out = String::with_capacity(input.len());
    let mut dropped = 0usize;
    let mut state = State::Normal;
    let mut pending = String::new(); // chars consumed in Esc/Csi that we may need to flush back
    for ch in input.chars() {
        match state {
            State::Normal => {
                if ch == '\x1b' {
                    state = State::Esc;
                    pending.clear();
                    pending.push(ch);
                } else {
                    out.push(ch);
                }
            }
            State::Esc => {
                if ch == '[' {
                    state = State::Csi;
                    pending.push(ch);
                } else {
                    // Not a CSI introducer; flush ESC and current char verbatim.
                    out.push_str(&pending);
                    out.push(ch);
                    pending.clear();
                    state = State::Normal;
                }
            }
            State::Csi => {
                pending.push(ch);
                if ch.is_ascii_alphabetic() {
                    // Sequence terminator — drop everything in `pending`.
                    dropped += pending.chars().count();
                    pending.clear();
                    state = State::Normal;
                } else if !(ch.is_ascii_digit() || ch == ';') {
                    // Unexpected char inside CSI — bail: flush buffered bytes.
                    out.push_str(&pending);
                    pending.clear();
                    state = State::Normal;
                }
            }
        }
    }
    if !pending.is_empty() {
        // EOF inside a partial escape — flush buffered bytes verbatim.
        out.push_str(&pending);
    }
    (out, dropped)
}
```

```rust
fn uuid_v4_short() -> String {
    // The full uuid crate is overkill; 16 hex chars from sha256(epoch+pid) is sufficient
    // for in-process request_id correlation. Production sweeps to a real uuid in M5.
    use std::time::{SystemTime, UNIX_EPOCH};
    let nanos = SystemTime::now().duration_since(UNIX_EPOCH).unwrap_or_default().as_nanos();
    format!("{:016x}", nanos as u64 ^ std::process::id() as u64)
}

fn sha256_short(s: &str) -> String {
    // Lightweight FNV-1a (cryptographic strength not required — this is for
    // _PROTO_command_hash routing; M5 may upgrade to real sha256).
    let mut h: u64 = 0xcbf2_9ce4_8422_2325;
    for b in s.bytes() {
        h ^= b as u64;
        h = h.wrapping_mul(0x100_0000_01b3);
    }
    format!("{h:016x}")
}

async fn emit_failed(
    bus: &lingxi_telemetry::AnalyticsBus,
    request_id: &str,
    error_kind: &str,
    started_at: std::time::SystemTime,
) {
    use lingxi_telemetry::AnalyticsValue;
    use std::collections::HashMap;
    let elapsed_ms = std::time::SystemTime::now()
        .duration_since(started_at).unwrap_or_default().as_millis() as u64;
    let mut meta = HashMap::new();
    meta.insert("request_id".into(),
        AnalyticsValue::String(lingxi_telemetry::pii::Verified::assert_safe(request_id.into())));
    meta.insert("error_kind".into(),
        AnalyticsValue::String(lingxi_telemetry::pii::Verified::assert_safe(error_kind.into())));
    meta.insert("duration_ms".into(), AnalyticsValue::U64(elapsed_ms));
    bus.log_event(lingxi_telemetry::tengu::tool::BASH_FAILED, meta).await;
}
```

```rust
        // On Windows, no sandbox; spawn directly.
        // On non-Windows, follow the same sandbox dispatch as BashTool — but for
        // M4-02 we use the simpler `NoSandbox` path when sandbox_available=false,
        // and rely on the sandbox decision matrix otherwise.
        let decision = should_use_sandbox(
            &cmd_str,
            self.ctx.permission_mode,
            self.ctx.project_trust,
            None,
            self.ctx.sandbox_available && cfg!(not(target_os = "windows")),
            self.ctx.workspace.clone(),
        );
        let final_cmd = match decision {
            SandboxDecision::NoSandbox => cmd_str.clone(),
            SandboxDecision::Sandbox { policy: _ } => {
                match wrap_with_sandbox(&cmd_str, &self.ctx.sandbox_runtime, self.ctx.platform) {
                    Ok(w) => w,
                    Err(lingxi_sandbox::wrap::SandboxWrapError::Unsupported(s)) => {
                        return Err(ToolError::InvalidInput(s));
                    }
                    Err(lingxi_sandbox::wrap::SandboxWrapError::SbplWrite(s)) => {
                        return Err(ToolError::Io(s));
                    }
                }
            }
            SandboxDecision::RefuseBecauseSandboxUnavailable { reason } => {
                return Err(ToolError::PermissionDenied(reason));
            }
        };

        // Argv shape: ["pwsh", "-Command", <cmd>] on Unix; ["powershell.exe", "-Command", <cmd>] on Win.
        let pcmd = SbxCommand {
            command: bin.display().to_string(),
            args: vec!["-Command".into(), final_cmd],
            cwd: Some(self.ctx.workspace.clone()),
            env: HashMap::new(),
            timeout: Some(Duration::from_millis(timeout_ms)),
            stdin: None,
        };
        let sandboxed = self.ctx.sandbox.bypass_with_audit(pcmd, "powershell_tool_call");

        match self.ctx.process.run(&sandboxed).await {
            Ok(out) => {
                let (stdout_clean, _ansi_out) = strip_ansi_count(&out.stdout);
                let (stderr_clean, _ansi_err) = strip_ansi_count(&out.stderr);
                let (stdout_final, truncated) = truncate_default(stdout_clean);
                let is_error = out.exit_code != 0 || out.timed_out;
                let elapsed = SystemTime::now().duration_since(started_at).unwrap_or_default().as_millis() as u64;

                let mut meta = HashMap::new();
                meta.insert("request_id".into(),
                    AnalyticsValue::String(Verified::assert_safe(request_id)));
                meta.insert("exit_code".into(), AnalyticsValue::I64(out.exit_code as i64));
                meta.insert("duration_ms".into(), AnalyticsValue::U64(elapsed));
                meta.insert("truncated".into(), AnalyticsValue::Bool(truncated));
                self.ctx.bus.log_event(POWERSHELL_COMPLETED, meta).await;

                Ok(ToolCallResult {
                    data: json!({
                        "exit_code": out.exit_code,
                        "stdout":    stdout_final,
                        "stderr":    stderr_clean,
                        "is_error":  is_error,
                        "timed_out": out.timed_out,
                        "truncated": truncated,
                    }),
                    new_messages: vec![],
                    context_modifier: None,
                    mcp_meta: None,
```
