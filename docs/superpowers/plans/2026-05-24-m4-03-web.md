# LingXi Core M4 · Plan 03 · Web tools (WebFetch + WebSearch)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate at the end (Task 10) is the workspace-wide guard.

**Goal:** Ship 2 byte-aligned, hermetic, telemetry-bound web tools — `WebFetchTool` (HTTPS/HTTP fetch with 5 MB cap + scheme allow-list + truncation suffix) and `WebSearchTool` (routes the agent's query through Anthropic Messages API with the `web-search-2025-03-05` anthropic-beta header and the `web_search_20250305` tool block) — under `lingxi-code/crates/tools/src/builtin/`. Tag `m4.3` at the end. All claude-code wire literals from spec §7 baked into both production code AND test assertions byte-for-byte.

**Architecture:** Two new files under `lingxi-tools/src/builtin/`. Both depend on the existing M1 `lingxi-traits::http::HttpTransport` trait (provider-neutral; `MockHttpTransport` from `lingxi-test-harness` is the test fake). WebSearchTool additionally depends on M3-03 `lingxi-api-client::AnthropicProvider::build_request` (to attach `anthropic-version` / `content-type` / `accept` / `x-api-key`) and `lingxi-api-client::betas::WEB_SEARCH` (the locked `web-search-2025-03-05` literal). WebFetchTool is purely transport-level — no api-client involvement. Neither tool self-retries (spec §5: tools never self-retry; agent decides on `ToolError::Transport`). The `BuiltinToolContext` struct (declared in M4-01 `builtin/mod.rs`) grows ONE new field: `http: Arc<dyn HttpTransport>` (plus a `default_model: String` for WebSearch's `MessageRequest.model` — sourced from the running session's `coordinator_model`). The 6 tengu events (3 per tool × 2 tools) — `tengu_tool_web_fetch_{started,completed,failed}` and `tengu_tool_web_search_{started,completed,failed}` — already exist in M3-06's `tengu/tool.rs` (committed at `cc05dc0`); M4-03 only binds the emitter.

**Tech Stack:** Rust 2021, `async-trait 0.1` (workspace), `serde 1` + `serde_json 1` (workspace), `tokio 1` (workspace), `url = "2"` (NEW — added to `lingxi-tools/Cargo.toml`; pure-Rust URL parser, no transitive C deps), `lingxi-traits::http::{HttpTransport, HttpError}` (M1), `lingxi-protocol::{HttpRequest, HttpResponse, HttpMethod}` (M1), `lingxi-api-client::{AnthropicProvider, MessageResponse, ContentBlockApi}` (M3-03), `lingxi-api-client::betas::WEB_SEARCH` (M3-03 lock = `"web-search-2025-03-05"`), `lingxi-telemetry::{AnalyticsBus, AnalyticsValue, LogEventMetadata, pii::{Verified, PiiTagged}}` (M3-06) + `lingxi-telemetry::tengu::tool::{WEB_FETCH_STARTED, WEB_FETCH_COMPLETED, WEB_FETCH_FAILED, WEB_SEARCH_STARTED, WEB_SEARCH_COMPLETED, WEB_SEARCH_FAILED}`. ## File touch inventory (locked at top per spec Appendix A convention)

**Creates (new files):**

- `lingxi-code/crates/tools/src/builtin/web_fetch.rs` — `WebFetchTool`. Input schema:
  ```jsonc
  {
    "type": "object",
    "properties": {
      "url":    { "type": "string", "format": "uri" },
      "prompt": { "type": "string" }
    },
    "required": ["url"]
  }
  ```
  - Constants (all `pub const`, MUST appear byte-for-byte in code AND in parity fixture assertion):
    - `pub const WEBFETCH_MAX_BYTES: usize = 5 * 1024 * 1024;`  (5 MB; spec §7)
    - `pub const WEBFETCH_TRUNCATION_SUFFIX: &str = "\n\n[Content truncated due to length...]";`
    - `pub const WEBFETCH_USER_AGENT_PREFIX: &str = "claude-code-tool/";` (full UA assembled at runtime via `concat!(WEBFETCH_USER_AGENT_PREFIX, env!("CARGO_PKG_VERSION"))`)
    - `pub const WEBFETCH_ALLOWED_SCHEMES: &[&str] = &["https", "http"];`
    - `pub const WEBFETCH_TIMEOUT: Duration = Duration::from_secs(30);` (claude-code parity; not byte-locked but spec-implied)
  - Error string templates (all literals appear in code AND test assertions):
    - Scheme rejection: `format!("URL scheme '{scheme}' not allowed; only https/http")`
    - HTTP error: `format!("WebFetch: HTTP {status} from {url}")`
    - DNS error: `format!("WebFetch: cannot resolve {host}")`
  - Flow per spec §4 Flow B (transport):
    1. Parse `url` via `url::Url::parse(input.url)` → on parse failure return `ToolError::InvalidInput(format!("invalid URL: {e}"))`.
    2. Validate `url.scheme()` against `WEBFETCH_ALLOWED_SCHEMES`; on miss → `ToolError::InvalidInput(format!("URL scheme '{}' not allowed; only https/http", url.scheme()))`.
    3. Emit `WEB_FETCH_STARTED` with `{ request_id: Verified, url: PiiTagged, prompt_present: Verified(bool->string) }`.
    4. Build `HttpRequest { method: HttpMethod::Get, url: url.to_string(), headers: vec![("user-agent".into(), full_user_agent), ("accept".into(), "text/markdown, text/html, */*".into())], body: None, timeout: Some(WEBFETCH_TIMEOUT) }`.
    5. Call `ctx.http.request(req).await`.
    6. Branch on `HttpError`:
       - `HttpError::Status { status, body }` where `status >= 400` → emit `WEB_FETCH_FAILED { error_kind: "http_status", status, duration_ms }` → return `ToolError::Transport(format!("WebFetch: HTTP {status} from {url}"))`.
       - `HttpError::Connection(msg)` where msg contains `"resolve"` OR `"name resolution"` (case-insensitive) → emit `WEB_FETCH_FAILED { error_kind: "dns", duration_ms }` → return `ToolError::Transport(format!("WebFetch: cannot resolve {}", url.host_str().unwrap_or("<unknown>")))`.
       - `HttpError::Connection(msg)` other → emit `WEB_FETCH_FAILED { error_kind: "connection", duration_ms }` → return `ToolError::Transport(format!("WebFetch: connection failed: {msg}"))`.
       - `HttpError::Timeout(_)` → emit `WEB_FETCH_FAILED { error_kind: "timeout", duration_ms }` → return `ToolError::Transport("WebFetch: request timed out".into())`.
       - other `HttpError::*` → emit `WEB_FETCH_FAILED { error_kind: "invalid_response", duration_ms }` → return `ToolError::Transport(format!("WebFetch: invalid response: {e}"))`.
    7. On `Ok(HttpResponse { status, headers: _, body })`:
       - If `status >= 400` → same as `HttpError::Status` branch above (defensive: some transports return 4xx as `Ok`).
       - Compute `body_bytes = body.as_bytes().len()`. If `body_bytes > WEBFETCH_MAX_BYTES`:
         - Truncate `body` at the first char boundary `<= WEBFETCH_MAX_BYTES` (use `body.floor_char_boundary(WEBFETCH_MAX_BYTES)` via the slot-stable polyfill below, OR a hand-rolled `while !body.is_char_boundary(n) { n -= 1; }` loop — see Task 4 step 3).
         - Append `WEBFETCH_TRUNCATION_SUFFIX`. Set `truncated = true`.
       - Else `truncated = false`.
       - Emit `WEB_FETCH_COMPLETED` with `{ request_id, status: Verified, body_bytes: Verified, truncated: Verified, duration_ms }`.
       - Return `ToolCallResult { data: json!({ "url": url.to_string(), "status": status, "content": final_body, "truncated": truncated, "bytes": body_bytes }) }`.
  - Tool metadata: `name() = "WebFetch"`, `is_concurrency_safe(_) = true`, `is_read_only(_) = true`, `is_open_world(_) = true` (talks to internet), `is_destructive(_) = false`, `interrupt_behavior(_) = InterruptBehavior::Cancel`.

- `lingxi-code/crates/tools/src/builtin/web_search.rs` — `WebSearchTool`. Input schema:
  ```jsonc
  {
    "type": "object",
    "properties": {
      "query":           { "type": "string", "minLength": 2 },
      "allowed_domains": { "type": "array", "items": { "type": "string" } },
      "blocked_domains": { "type": "array", "items": { "type": "string" } }
    },
    "required": ["query"]
  }
  ```
  - Constants:
    - `pub const WEB_SEARCH_TOOL_BLOCK_TYPE: &str = "web_search_20250305";` (the `type` field on the tool block; spec §7 lock)
    - `pub const WEB_SEARCH_TOOL_BLOCK_NAME: &str = "web_search";` (the `name` field on the tool block; matches upstream)
    - `pub const WEB_SEARCH_MAX_USES: u32 = 8;` (claude-code lock)
    - `pub const WEB_SEARCH_DEFAULT_MAX_TOKENS: u32 = 4096;` (matches `messages_create_non_stream` default)
  - Flow:
    1. Validate `query.chars().count() >= 2` → on miss return `ToolError::InvalidInput("query must be at least 2 characters".into())`.
    2. Emit `WEB_SEARCH_STARTED` with `{ request_id: Verified, query: PiiTagged, allowed_domains_count: Verified(u32->string), blocked_domains_count: Verified(u32->string) }`.
    3. Build the tool block as a `serde_json::Value`:
       ```rust
       let mut tool_block = serde_json::Map::new();
       tool_block.insert("type".into(), json!(WEB_SEARCH_TOOL_BLOCK_TYPE));
       tool_block.insert("name".into(), json!(WEB_SEARCH_TOOL_BLOCK_NAME));
       tool_block.insert("max_uses".into(), json!(WEB_SEARCH_MAX_USES));
       if let Some(a) = &input.allowed_domains { tool_block.insert("allowed_domains".into(), json!(a)); }
       if let Some(b) = &input.blocked_domains { tool_block.insert("blocked_domains".into(), json!(b)); }
       ```
    4. Build the request body as a `MessageRequest`-shaped `serde_json::Value`:
       ```rust
       let body = json!({
           "model": ctx.default_model,
           "max_tokens": WEB_SEARCH_DEFAULT_MAX_TOKENS,
           "messages": [{ "role": "user", "content": query }],
           "tools": [Value::Object(tool_block)],
       });
       ```
    5. Build the HTTP request via `ctx.provider.build_request(&body)` (M3-03), then push `anthropic-beta` header with `lingxi_api_client::betas::WEB_SEARCH` (= `"web-search-2025-03-05"`), and push `user-agent = concat!(WEBFETCH_USER_AGENT_PREFIX, env!("CARGO_PKG_VERSION"))` (re-uses WebFetch's UA constant — tools share a single tool-side UA).
    6. Call `ctx.http.request(req).await`.
    7. Branch on `HttpError` → return `ToolError::Transport(...)` analogous to WebFetch error mapping; emit `WEB_SEARCH_FAILED { error_kind, duration_ms }`.
    8. On `Ok(HttpResponse { status, body, .. })`:
       - If `status != 200` → emit `WEB_SEARCH_FAILED { error_kind: "http_status", status }` → return `ToolError::Transport(format!("WebSearch: HTTP {status}"))`.
       - Parse `body` as `MessageResponse` via `serde_json::from_str` → on parse error return `ToolError::Transport(format!("WebSearch: invalid response: {e}"))` after emitting `_FAILED`.
       - Walk `response.content`, accumulating `Text { text }` blocks into a single string, and collecting `ServerToolUse { name == "web_search" }` blocks' results when present. Specifically: emit `results: Vec<Value>` where each entry is either the raw `ContentBlockApi::Text.text` (string) or the `ServerToolUse.input` value (object). Mirrors upstream `makeOutputFromSearchResponse`.
       - Emit `WEB_SEARCH_COMPLETED { request_id: Verified, hits: Verified(u32->string), input_tokens: Verified, output_tokens: Verified, duration_ms }` where `hits = count of Text blocks + count of ServerToolUse blocks`.
       - Return `ToolCallResult { data: json!({ "query": input.query, "results": results, "duration_ms": elapsed_ms }) }`.
  - Tool metadata: `name() = "WebSearch"`, `is_concurrency_safe(_) = true`, `is_read_only(_) = true`, `is_open_world(_) = true`, `is_destructive(_) = false`, `interrupt_behavior(_) = InterruptBehavior::Cancel`.

```rust
/// Truncate `body` so that its byte length is `<= WEBFETCH_MAX_BYTES`, falling
/// back to the nearest UTF-8 char boundary so we never split a multi-byte
/// codepoint. If truncated, the byte-locked [`WEBFETCH_TRUNCATION_SUFFIX`]
/// is appended.
///
/// Returns `(possibly_truncated_body, truncated_flag)`.
pub fn truncate_body(body: String) -> (String, bool) {
    if body.len() <= WEBFETCH_MAX_BYTES {
        return (body, false);
    }
    // Walk backwards from WEBFETCH_MAX_BYTES to the nearest char boundary.
    let mut cut = WEBFETCH_MAX_BYTES;
    while cut > 0 && !body.is_char_boundary(cut) {
        cut -= 1;
    }
    let mut truncated = body[..cut].to_string();
    truncated.push_str(WEBFETCH_TRUNCATION_SUFFIX);
    (truncated, true)
}
```

Add tests inside the existing `tests` mod (append):

```rust
    fn does_not_truncate_small_body() {
        let small = "hello world".to_string();

        assert_eq!(out, small);
        assert!(!flag);
    }

    #[test]
    fn does_not_truncate_exactly_at_cap() {
        let exact = "a".repeat(WEBFETCH_MAX_BYTES);
        let (out, flag) = truncate_body(exact.clone());
        assert_eq!(out, exact);
        assert!(!flag);
    }

    #[test]
    fn truncates_oversized_body() {
        let big = "a".repeat(WEBFETCH_MAX_BYTES + 1024);
        let (out, flag) = truncate_body(big);
        assert!(flag);
        assert!(out.ends_with(WEBFETCH_TRUNCATION_SUFFIX));
        // The pre-suffix portion must be exactly WEBFETCH_MAX_BYTES bytes
        // (all `a` chars are 1-byte ASCII so no boundary walk-back).
        let suffix_len = WEBFETCH_TRUNCATION_SUFFIX.len();
        assert_eq!(out.len(), WEBFETCH_MAX_BYTES + suffix_len);
    }

    #[test]
    fn truncates_multibyte_at_char_boundary() {
        // Build a body that overflows by inserting multi-byte chars right at the cap.
        // "日" is 3 bytes in UTF-8. Place WEBFETCH_MAX_BYTES-1 ASCII bytes, then "日",
        // then more "日"s so total > cap.

        s.push('日');
        s.push('日');

        assert!(body_only.is_char_boundary(body_only.len()));

        assert_eq!(body_only.len(), WEBFETCH_MAX_BYTES - 1);
```

```rust
use crate::tool_trait::{
    DescriptionOptions, InterruptBehavior, PromptOptions, Tool, ToolCallResult, ToolError,

};
use async_trait::async_trait;
use lingxi_protocol::{HttpMethod, HttpRequest};

use lingxi_telemetry::AnalyticsValue;
use lingxi_telemetry::tengu::tool::{

/// locked truncation suffix on overflow. Never self-retries on transient
/// 5xx (spec §5: caller decides). See module-level docs for the full
/// fidelity table.
pub struct WebFetchTool {
    ctx: BuiltinToolContext,
}

impl WebFetchTool {
    pub fn new(ctx: BuiltinToolContext) -> Self {
        Self { ctx }
    }

    fn user_agent() -> String {
        format!("{}{}", WEBFETCH_USER_AGENT_PREFIX, env!("CARGO_PKG_VERSION"))

#[async_trait]
impl Tool for WebFetchTool {
    fn name(&self) -> &'static str {
        "WebFetch"
    }

    fn is_concurrency_safe(&self, _ctx: &ToolStaticContext) -> bool {
        true
    }
    fn is_read_only(&self, _ctx: &ToolStaticContext) -> bool {
        true
    }
    fn is_open_world(&self, _ctx: &ToolStaticContext) -> bool {
        true
    }
    fn is_destructive(&self, _ctx: &ToolStaticContext) -> bool {
        false
    }
    fn interrupt_behavior(&self, _ctx: &ToolStaticContext) -> InterruptBehavior {

    async fn prompt(&self, _opts: PromptOptions) -> String {

        let url = raw
            .get("url")
            .and_then(|v| v.as_str())
            .ok_or_else(|| ValidationError::new("missing required field: url"))?;
        validate_url(url).map_err(|e| ValidationError::new(e))?;

        &self,
        raw_input: serde_json::Value,
        use_ctx: ToolUseContext,

        let input: WebFetchInput = serde_json::from_value(raw_input)
            .map_err(|e| ToolError::InvalidInput(format!("invalid input: {e}")))?;
        let parsed_url = validate_url(&input.url).map_err(ToolError::InvalidInput)?;
        let host = parsed_url.host_str().unwrap_or("<unknown>").to_string();

        // --- STARTED event ---
        let mut started_meta: HashMap<String, AnalyticsValue> = HashMap::new();
        started_meta.insert(
            "request_id".into(),
            AnalyticsValue::Verified(Verified::assert_safe(use_ctx.request_id.clone())),
        );
        started_meta.insert(
            "url".into(),
            AnalyticsValue::PiiTagged(PiiTagged::assert_pii_tagged_column(input.url.clone())),
        );
        started_meta.insert(
            "prompt_present".into(),
            AnalyticsValue::Verified(Verified::assert_safe(
                input.prompt.is_some().to_string(),
            )),
        );
        self.ctx
            .bus
            .log_event(WEB_FETCH_STARTED, started_meta)
            .await;

        let started_at = std::time::Instant::now();

        // --- Build + send the HTTP request ---
        let req = HttpRequest {
            method: HttpMethod::Get,
            url: parsed_url.to_string(),

            Ok(resp) => {

                let mut done_meta: HashMap<String, AnalyticsValue> = HashMap::new();
                done_meta.insert(
                    "request_id".into(),
                    AnalyticsValue::Verified(Verified::assert_safe(use_ctx.request_id.clone())),

                    AnalyticsValue::Verified(Verified::assert_safe(body_bytes.to_string())),
                );

                    "truncated".into(),

                self.ctx

                    .log_event(WEB_FETCH_COMPLETED, done_meta)

                    "status": status,
                    "content": final_body,
                    "truncated": truncated,
                    "bytes": body_bytes,
                })))
            }
            Err(HttpError::Status { status, body: _ }) => {
                let err_msg = fmt_http_error(status, &input.url);

                Err(ToolError::Transport(err_msg))

            Err(HttpError::Timeout(_)) => {

                Err(ToolError::Transport(err_msg))
            }
            Err(other) => {
                let err_msg = format!("WebFetch: invalid response: {other}");
                self.emit_failed("invalid_response", None, elapsed_ms, &use_ctx)
                    .await;
                Err(ToolError::Transport(err_msg))
            }
        }
    }
}

    }
}
```

```rust
                    .await;
```

```rust
                    "WebSearch: transport failure: {other}"

    }
```

## Deviations summary (for the report back to the planning agent)

- **Spec § 7 line 478** says `User-Agent (tool side) | claude-code-tool/<CARGO_PKG_VERSION> (distinct from api-client UA)`. Implementation splits this into a `pub const WEBFETCH_USER_AGENT_PREFIX: &str = "claude-code-tool/"` plus runtime concat — necessary because Rust `const` can't `format!`. Test asserts both `starts_with(prefix)` AND `ends_with(env!("CARGO_PKG_VERSION"))`.
- **Spec § 1 line 27** uses `started/succeeded/failed`, but M3-06 locked the tool family to `started/completed/failed` (`cc05dc0`). Plan follows the M3-06 lock per user prompt ("Tool events use `_completed` suffix (matches M3-06 lock)").
- **Spec § 7 line 476** locks WebFetch at 5 MB; upstream claude-code uses 10 MB. Plan follows the spec lock — documented in Critical Fidelity table.
- WebSearchTool bypasses `messages_create_non_stream` (which only builds a model+max_tokens+messages body and runs the retry+OAuth+cost loop) and instead uses `AnthropicProvider::build_request` directly so it can attach the `tools` array + custom `anthropic-beta` header. Per spec § 5 line 323 ("Tools never self-retry — only `messages_create` retries"), this is correct: tool-level direct calls are not expected to retry; the agent decides.
