# LingXi Core M4 · Plan 04 · Workflow tools (TodoWrite + Plan/Worktree enter/exit)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate at the end (Task 16) is the workspace-wide guard.

**Goal:** Ship 5 byte-aligned, hermetic, telemetry-bound workflow tools — `TodoWriteTool` (persists a `pending`/`in_progress`/`completed` todo list onto the running `SessionState`), `EnterPlanModeTool` + `ExitPlanModeTool` (toggle `session.plan_mode` and emit the locked `[PLAN MODE]` / `[EXIT PLAN MODE]` markers), `EnterWorktreeTool` + `ExitWorktreeTool` (create / remove a disposable git worktree via the M2-01 `WorktreeManager` trait, locking the `worktree-<flatten(slug)>` branch prefix and `<repo>/.claude/worktrees/<flatten(slug)>` path layout) — under `lingxi-code/crates/tools/src/builtin/`. Tag `m4.4` at the end. All claude-code wire literals from spec §7 (lines 482-489) baked into both production code AND test assertions byte-for-byte.

**Architecture:** Three new files under `lingxi-tools/src/builtin/`:
- `todo_write.rs` — one tool, owns `TodoItem` + `TodoState` types, mutates `SessionState.todos` behind a `Mutex`.
- `plan_mode.rs` — TWO tools (`EnterPlanModeTool` + `ExitPlanModeTool`) sharing one file per spec §3 module layout; both flip `SessionState.plan_mode` and emit the locked text marker as part of `ToolCallResult.data`.
- `worktree.rs` — TWO tools (`EnterWorktreeTool` + `ExitWorktreeTool`) sharing one file per spec §3; both dispatch through `Arc<dyn WorktreeManager>` (M2-01 trait) and serialise the returned `WorktreeHandle` into the result JSON. Slug validation reuses the M2-01 `validate_worktree_slug` + `flatten_slug` helpers (already exported from `lingxi_platforms_posix`).

The five tools depend on:
- `lingxi_core::SessionState` (M1 model) — **extended in Task 1** to add `pub todos: Vec<TodoItem>` and `pub plan_mode: bool` fields with `#[serde(default)]` so existing fixtures round-trip unchanged. NOTE: the user prompt names this `lingxi-session::SessionState` but the actual surface is `lingxi_core::SessionState`; `lingxi-session` is the JSONL persistence layer (not the model crate). Documented in the Critical Fidelity table.
- `lingxi_platform_api::{WorktreeManager, WorktreeHandle, WorktreeError}` (M2-01 trait) — `Arc<dyn WorktreeManager>` is injected via `BuiltinToolContext.worktree` (new field added in Task 0).
- `lingxi_platforms_posix::worktree::{validate_worktree_slug, flatten_slug}` (M2-01 locks) — re-exported as `pub use` from `lingxi_tools::builtin::worktree` so test code can assert the byte-locked prefix/path without depending directly on the platform crate.
- `lingxi_telemetry::tengu::tool::*` — **15 NEW constants added in Task 2** (3 per tool × 5 tools); the workflow event family is NOT yet in the M3-06 locked schema. The NAMES array under `tengu/tool.rs` is extended from 49 (post-M4-02, which added 9 PowerShell/REPL/Sleep events to the M3-06 baseline of 40) to 64 names. M3-06's overall `ALL_EVENT_NAMES` count moves up by +15 — Task 2 updates that lock too.

The `BuiltinToolContext` struct (declared in M4-01 `builtin/mod.rs`, extended in M4-02/M4-03) grows ONE new field in Task 0: `worktree: Arc<dyn WorktreeManager>` (no other context fields needed; TodoWrite + plan_mode operate purely on the `SessionState` reference already threaded through `ToolUseContext`).

Per spec §5: tools NEVER self-retry. Worktree errors surface as `ToolError::Io` (mapping `WorktreeError::Io`) or `ToolError::InvalidInput` (mapping `WorktreeError::InvalidSlug`) or `ToolError::Internal` (mapping `WorktreeError::Git` + `WorktreeError::Unsupported`).

## File touch inventory (locked at top per spec Appendix A convention)

**Creates (new files):**

- `lingxi-code/crates/tools/src/builtin/todo_write.rs` — `TodoWriteTool` + supporting types:
  - `pub struct TodoWriteTool { bus: Arc<AnalyticsBus> }` — no FS/HTTP dependencies; pure session mutation.
  - `#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)] pub struct TodoItem { pub id: String, pub content: String, pub status: TodoState }`.
  - `#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)] #[serde(rename_all = "snake_case")] pub enum TodoState { Pending, InProgress, Completed }` — the THREE locked variants, with `#[serde(rename_all = "snake_case")]` so wire bytes are `pending` / `in_progress` / `completed` exactly.
  - Constants (`pub const`):
    - `pub const TODO_STATE_PENDING: &str = "pending";`
    - `pub const TODO_STATE_IN_PROGRESS: &str = "in_progress";`
    - `pub const TODO_STATE_COMPLETED: &str = "completed";`
    - `pub const TODO_STATES: &[&str] = &[TODO_STATE_PENDING, TODO_STATE_IN_PROGRESS, TODO_STATE_COMPLETED];`
    - `pub const TODO_MAX_CONTENT_CHARS: usize = 4_096;` — defensive cap to keep one todo from blowing past `MAX_TOOL_OUTPUT_LENGTH`.
  - Error string templates (all literals appear in code AND test assertions):
    - Duplicate id: `format!("TodoWrite: duplicate id '{id}'")`
    - Empty content: `"TodoWrite: todo content is empty"`
    - Over-long content: `format!("TodoWrite: todo content exceeds {TODO_MAX_CONTENT_CHARS} chars (got {n})")`
    - Multiple in-progress: `format!("TodoWrite: at most one todo may be 'in_progress' (got {n})")`
  - Input schema (JSON):
    ```jsonc
    {
      "type": "object",
      "properties": {
        "todos": {
          "type": "array",
          "items": {
            "type": "object",
            "properties": {
              "id":      { "type": "string" },
              "content": { "type": "string", "minLength": 1 },
              "status":  { "type": "string", "enum": ["pending", "in_progress", "completed"] }
            },
            "required": ["id", "content", "status"]
          }
        }
      },
      "required": ["todos"]
    }
    ```
  - Flow:
    1. Parse `input.todos` via `serde_json::from_value::<Vec<TodoItem>>(input["todos"].clone())`. On serde failure → `ToolError::InvalidInput(format!("TodoWrite: invalid todos shape: {e}"))`. Serde's `#[serde(rename_all = "snake_case")]` on `TodoState` enforces the literal allow-list (`pending`/`in_progress`/`completed`) — any other string yields a deserialize error containing the literal `unknown variant`, and we re-wrap so the tool surfaces the expected literal.
    2. Emit `TODO_WRITE_STARTED { invocation_id, todo_count: Verified }`.
    3. Validate:
       - Each `content` non-empty and `<= TODO_MAX_CONTENT_CHARS` chars.
       - All ids unique within the list.
       - At most one item has `status == TodoState::InProgress`.
       - On any failure → emit `TODO_WRITE_FAILED { error_kind, duration_ms }` → return `ToolError::InvalidInput(<locked literal>)`.
    4. Acquire `ctx.session.lock().await`; replace `session.todos = parsed_todos.clone()`.
    5. Emit `TODO_WRITE_COMPLETED { invocation_id, todo_count, pending_count, in_progress_count, completed_count, duration_ms }`.
    6. Return `ToolCallResult { data: json!({ "todos": parsed_todos, "summary": { "pending": .., "in_progress": .., "completed": .. } }) }`.
  - Tool metadata: `name() = "TodoWrite"`, `is_concurrency_safe(_) = false` (mutates session), `is_read_only(_) = false`, `is_destructive(_) = false`, `is_open_world(_) = false`, `interrupt_behavior(_) = InterruptBehavior::Block`.

      "properties": {},

    1. Emit `EXIT_PLAN_MODE_STARTED { invocation_id }`.

    4. Set `session.plan_mode = false`.
    5. Emit `EXIT_PLAN_MODE_COMPLETED { invocation_id, duration_ms }`.
    6. Return `ToolCallResult { data: json!({ "marker": PLAN_MODE_EXIT_MARKER, "plan_mode": false }) }`.

    ```jsonc

    }
    ```
  - Error string templates:
    - Slug validation (mapped from `WorktreeError::InvalidSlug`): `format!("EnterWorktree: invalid slug: {detail}")`
    - Unsupported (mapped from `WorktreeError::Unsupported`): `"EnterWorktree: worktrees are not supported on this platform"` / `"ExitWorktree: worktrees are not supported on this platform"`
    - Git failure: `format!("EnterWorktree: git error: {msg}")` / `format!("ExitWorktree: git error: {msg}")`
    - IO failure: `format!("EnterWorktree: io error: {msg}")` / `format!("ExitWorktree: io error: {msg}")`
  - Flow `EnterWorktreeTool`:
    1. Parse `input` (`slug` required; `base_branch` + `copy_includes` optional). Empty `copy_includes` defaults to `Vec::new()`.
    2. Emit `ENTER_WORKTREE_STARTED { invocation_id, slug: PiiTagged }`.
    3. Validate slug via `validate_worktree_slug(&slug)` — on `Err(InvalidSlug(detail))` → emit `ENTER_WORKTREE_FAILED { error_kind: "invalid_slug", duration_ms }` → return `ToolError::InvalidInput(format!("EnterWorktree: invalid slug: {detail}"))`.
    4. Call `ctx.worktree.create_worktree(&slug, base_branch.as_deref(), &copy_includes_paths).await`.
    5. Map errors:
       - `Err(WorktreeError::InvalidSlug(detail))` → emit `ENTER_WORKTREE_FAILED { error_kind: "invalid_slug" }` → `ToolError::InvalidInput(...)`.
       - `Err(WorktreeError::Unsupported)` → emit `ENTER_WORKTREE_FAILED { error_kind: "unsupported" }` → `ToolError::Internal("EnterWorktree: worktrees are not supported on this platform".into())`.
       - `Err(WorktreeError::Git(msg))` → emit `ENTER_WORKTREE_FAILED { error_kind: "git", duration_ms }` → `ToolError::Internal(format!("EnterWorktree: git error: {msg}"))`.
       - `Err(WorktreeError::Io(msg))` → emit `ENTER_WORKTREE_FAILED { error_kind: "io" }` → `ToolError::Io(format!("EnterWorktree: io error: {msg}"))`.
    6. On `Ok(handle)`:
       - Assert (via `debug_assert!`) `handle.branch_name == format!("{WORKTREE_BRANCH_PREFIX}{}", flatten_slug(&slug))` — the M2-01 implementation guarantees this; the debug_assert catches regressions.
       - Emit `ENTER_WORKTREE_COMPLETED { invocation_id, branch_name: PiiTagged, duration_ms }`.
       - Return `ToolCallResult { data: json!({ "path": handle.path.to_string_lossy(), "branch_name": handle.branch_name }) }`.
  - Flow `ExitWorktreeTool`:
    1. Parse `input.path` + `input.branch_name`.
    2. Emit `EXIT_WORKTREE_STARTED { invocation_id, branch_name: PiiTagged }`.
    3. Build `WorktreeHandle { path: PathBuf::from(input.path), branch_name: input.branch_name }`.
    4. Call `ctx.worktree.remove_worktree(&handle).await`.
    5. Map errors symmetrically to EnterWorktree's mapping (emit `EXIT_WORKTREE_FAILED` with matching `error_kind`).
    6. On `Ok(())`:
       - Emit `EXIT_WORKTREE_COMPLETED { invocation_id, duration_ms }`.
       - Return `ToolCallResult { data: json!({ "removed": true, "branch_name": handle.branch_name }) }`.
  - Tool metadata for both: `is_concurrency_safe(_) = false` (mutates FS + git state), `is_read_only(_) = false`, `is_destructive(EnterWorktreeTool, _) = false`, `is_destructive(ExitWorktreeTool, _) = true` (removes a worktree), `is_open_world(_) = false`, `interrupt_behavior(_) = InterruptBehavior::Block`. Tool names: `"EnterWorktree"`, `"ExitWorktree"`.

/// Running total of `Usage` across all turns in a session.
#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct CumulativeUsage(pub Usage);

impl CumulativeUsage {
    /// Accumulate a per-turn `Usage` into the cumulative total.
    pub fn add(&mut self, u: &Usage) {
        self.0.add(u);
    }
}

/// One entry in a session's todo list. Wire-locked by spec §7 line 486.
///
/// `status` serialises to one of three literals: `"pending"`, `"in_progress"`,
/// or `"completed"` — see [`TodoState`].
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct TodoItem {
    /// Stable identifier (caller-supplied; uniqueness enforced by `TodoWriteTool`).
    pub id: String,
    /// Human-readable description of the todo.
    pub content: String,
    /// Lifecycle state of this todo. Wire-locked.
    pub status: TodoState,
}

/// Wire-locked todo lifecycle states.
///
/// Serialises to `"pending"` / `"in_progress"` / `"completed"` per
/// spec §7 line 486. The aliases `"done"` and `"todo"` are explicitly
/// rejected by `TodoWriteTool`.
#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum TodoState {
    /// Not yet started.
    Pending,
    /// Actively being worked on (at most one per todo list).
    InProgress,
    /// Finished.
    Completed,
}

/// In-memory model of a conversation session.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SessionState {
    /// Unique identifier for this session.
    pub session_id: SessionId,
    /// Ordered conversation history.
    pub history: Vec<ConversationMessage>,
    /// Cumulative token usage across all turns.
    pub usage: CumulativeUsage,
    /// Model identifier (e.g. `"claude-opus-4-7"`).
    pub model: String,
    /// Active todo list (M4-04). Mutated by `TodoWriteTool`. Defaults to empty
    /// on deserialize so pre-M4-04 persisted sessions still load.
    #[serde(default)]
    pub todos: Vec<TodoItem>,
    /// Plan-mode flag (M4-04). Flipped by `EnterPlanModeTool` /
    /// `ExitPlanModeTool`. Defaults to `false` on deserialize.
    #[serde(default)]
    pub plan_mode: bool,
}

impl SessionState {
    /// Construct a fresh session with no history.
    #[must_use]
    pub fn empty(session_id: SessionId, model: String) -> Self {
        Self {
            session_id,
            history: Vec::new(),
            usage: CumulativeUsage::default(),
            model,
            todos: Vec::new(),
            plan_mode: false,
        }
    }
}

/// Validate a `Vec<TodoItem>` for the locked TodoWrite contract.
///
/// Rules (spec §7 line 486 + this plan):
/// - Each `content` is non-empty and `<= TODO_MAX_CONTENT_CHARS` chars.
/// - All `id`s are unique within the list.
/// - At most one item has `status == TodoState::InProgress`.
///
/// Returns the byte-locked error string on failure.
pub fn validate_todos(todos: &[TodoItem]) -> Result<(), String> {
    use std::collections::HashSet;
    let mut seen_ids: HashSet<&str> = HashSet::with_capacity(todos.len());
    let mut in_progress_count: u32 = 0;
    for t in todos {
        if t.content.is_empty() {
            return Err("TodoWrite: todo content is empty".into());
        }
        let n = t.content.chars().count();
        if n > TODO_MAX_CONTENT_CHARS {
            return Err(format!(
                "TodoWrite: todo content exceeds {TODO_MAX_CONTENT_CHARS} chars (got {n})"
            ));
        }
        if !seen_ids.insert(t.id.as_str()) {
            return Err(format!("TodoWrite: duplicate id '{}'", t.id));
        }
        if t.status == TodoState::InProgress {
            in_progress_count += 1;
        }
    }
    if in_progress_count > 1 {
        return Err(format!(
            "TodoWrite: at most one todo may be 'in_progress' (got {in_progress_count})"
        ));
    }
    Ok(())
}

/// Compute `(pending, in_progress, completed)` counts over a todo list.
#[must_use]
pub fn summary(todos: &[TodoItem]) -> (u32, u32, u32) {
    let mut pending = 0u32;
    let mut in_progress = 0u32;
    let mut completed = 0u32;
    for t in todos {
        match t.status {
            TodoState::Pending => pending += 1,
            TodoState::InProgress => in_progress += 1,
            TodoState::Completed => completed += 1,
        }
    }
    (pending, in_progress, completed)
}

#[async_trait]
impl Tool for ExitWorktreeTool {
    fn name(&self) -> &str { "ExitWorktree" }
    fn input_schema(&self) -> &Value { &self.schema }
    fn is_enabled(&self, _: &ToolStaticContext) -> bool { true }
    fn max_result_size_chars(&self) -> usize { 30_000 }
    fn is_concurrency_safe(&self, _: &Value) -> bool { false }
    fn is_read_only(&self, _: &Value) -> bool { false }
    fn is_destructive(&self, _: &Value) -> bool { true }
    fn is_open_world(&self, _: &Value) -> bool { false }
    fn interrupt_behavior(&self, _: &Value) -> InterruptBehavior { InterruptBehavior::Block }

    async fn check_permissions(&self, _: &Value, _: &ToolUseContext) -> PermissionResult {
        PermissionResult::allow(PermissionDecisionReason::Allow, PermissionMetadata::default())
    }
    async fn description(&self, _: &Value, _: &DescriptionOptions) -> String {
        "Remove a worktree".into()
    }
    async fn prompt(&self, _: &PromptOptions) -> String {
        "ExitWorktree removes a worktree by `path` + `branch_name`.".into()
    }

    async fn call(
        &self,
        input: Value,
        _ctx: ToolUseContext,
        _progress: ToolProgressSender,
    ) -> Result<ToolCallResult, ToolError> {
        let invocation_id = uuid::Uuid::new_v4().to_string();
        let started_at = Instant::now();
        let parsed: ExitInput = match serde_json::from_value(input) {
            Ok(v) => v,
            Err(e) => {
                self.emit_failed(&invocation_id, "invalid_input", started_at).await;
                return Err(ToolError::InvalidInput(format!(
                    "ExitWorktree: invalid input: {e}"
                )));
            }
        };
        {
            let mut meta = LogEventMetadata::new();
            meta.insert(
                "invocation_id".into(),
                AnalyticsValue::String(Verified::assert_safe(invocation_id.clone()).into_inner()),
            );
            meta.insert("tool_name".into(), AnalyticsValue::String("ExitWorktree".into()));
            meta.insert(
                "branch_name".into(),
                AnalyticsValue::String(
                    PiiTagged::assert_pii_tagged_column(parsed.branch_name.clone()).into_inner(),
                ),
            );
            self.bus.log_event(EXIT_WORKTREE_STARTED, meta).await;
        }
        let handle = WorktreeHandle {
            path: PathBuf::from(&parsed.path),
            branch_name: parsed.branch_name.clone(),
        };
        match self.worktree.remove_worktree(&handle).await {
            Ok(()) => {
                let duration_ms = started_at.elapsed().as_millis() as u64;
                let mut meta = LogEventMetadata::new();
                meta.insert(
                    "invocation_id".into(),
                    AnalyticsValue::String(Verified::assert_safe(invocation_id).into_inner()),
                );
                meta.insert("tool_name".into(), AnalyticsValue::String("ExitWorktree".into()));
                meta.insert("duration_ms".into(), AnalyticsValue::Integer(duration_ms as i64));
                self.bus.log_event(EXIT_WORKTREE_COMPLETED, meta).await;
                Ok(ToolCallResult {
                    data: json!({
                        "removed": true,
                        "branch_name": parsed.branch_name,
                    }),
                    new_messages: Vec::new(),
                    context_modifier: None,
                    mcp_meta: None,
                })
            }
            Err(WorktreeError::InvalidSlug(detail)) => {
                self.emit_failed(&invocation_id, "invalid_slug", started_at).await;
                Err(ToolError::InvalidInput(format!(
                    "ExitWorktree: invalid slug: {detail}"
                )))
            }
            Err(WorktreeError::Unsupported) => {
                self.emit_failed(&invocation_id, "unsupported", started_at).await;
                Err(ToolError::Internal(
                    "ExitWorktree: worktrees are not supported on this platform".into(),
                ))
            }
            Err(WorktreeError::Git(msg)) => {
                self.emit_failed(&invocation_id, "git", started_at).await;
                Err(ToolError::Internal(format!("ExitWorktree: git error: {msg}")))
            }
            Err(WorktreeError::Io(msg)) => {
                self.emit_failed(&invocation_id, "io", started_at).await;
                Err(ToolError::Io(format!("ExitWorktree: io error: {msg}")))
            }
        }
    }
}
