# LingXi Core M4 · Plan 05 · Agent + Task tools (recursive subagent dispatch)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate (final task) is the workspace-wide guard.

**Goal:** Ship 8 byte-aligned, hermetic, telemetry-bound agent / task tools under `lingxi-code/crates/tools/src/builtin/` — `AgentTool` (spawns a subagent via the M1 coordinator + agent pool, inherits the parent `BudgetEnforcer`, recurses through the SAME `Arc<ToolRegistry>`), six task CRUD wrappers (`TaskCreateTool`, `TaskGetTool`, `TaskListTool`, `TaskUpdateTool`, `TaskStopTool`, `TaskOutputTool` — thin facades over `lingxi_tasks::TaskRegistry` + `TaskOutputManager`), and `SendMessageTool` (routes inter-agent text into `lingxi_msgqueue::MessageQueueManager` with the LingXi-locked `Duration::from_secs(30)` claim window). Tag `m4.5` at the end. All wire identifiers from spec §7 (lines 491-499) baked into both production code AND test assertions byte-for-byte.

**Architecture:** Three new files under `lingxi-tools/src/builtin/`:
- `agent.rs` — one tool (`AgentTool`); owns the recursive spawn path through `MultiAgentDispatcher` → `StateMachinePool::allocate` → `run_subagent`; clones the parent's `Arc<BudgetEnforcer>` so the subagent shares a single budget latch; clones the parent's `Arc<ToolRegistry>` so a subagent's tool dispatch reuses the SAME registry (the recursion lock).
- `task.rs` — SIX tools (`TaskCreateTool`, `TaskGetTool`, `TaskListTool`, `TaskUpdateTool`, `TaskStopTool`, `TaskOutputTool`) sharing one file per spec §3 module-layout. All thin async wrappers over `Arc<TaskRegistry>` + `Arc<TaskOutputManager>`. State serialized via `serde_json::to_value(&TaskState)`.
- `send_message.rs` — one tool (`SendMessageTool`); owns the `Duration::from_secs(30)` claim-window literal; enqueues a `QueuedCommand { content: QueuedCommandContent::TeammateMessage { from, content }, priority: QueuePriority::Next, source: QueueSource::AgentSendMessage, .. }` onto an `Arc<MessageQueueManager>` (one-per-`to_agent_id`, looked up via a new `BuiltinToolContext.mailbox_router` field).

The eight tools depend on:
- `lingxi_tasks::{TaskRegistry, TaskOutputManager, TaskType, TaskState, TaskStatus, TaskError, TaskSpawnInput, generate_task_id, output_manager::{OutputOptions, OutputError}}` (M1 surface).
- `lingxi_agent::{MultiAgentDispatcher, MultiAgentSpawnSpec, StateMachinePool, SubagentEvent, SubagentContext, AgentDefinition}` (M1 surface).
- `lingxi_msgqueue::{MessageQueueManager, QueuedCommand, QueuedCommandContent, QueuePriority, QueueSource}` (M1 surface).
- `lingxi_cost::{BudgetEnforcer, BudgetCheckResult, BudgetExceedPolicy}` (M3-05 surface).
- `lingxi_protocol::{AgentId, SessionId}` (M1 surface).
- `lingxi_telemetry::tengu::tool::*` — **24 NEW constants added in Task 2** (3 per tool × 8 tools). The NAMES array under `tengu/tool.rs` extends from 64 (post-M4-04; M3-06 baseline 40 + 9 PowerShell/REPL/Sleep from M4-02 + 15 workflow from M4-04) to 88. `ALL_EVENT_NAMES` count moves up by +24 — Task 2 updates that lock too.

The `BuiltinToolContext` struct (declared in M4-01, extended through M4-02/03/04) grows FOUR new fields in Task 0:
- `task_registry: Arc<TaskRegistry>`
- `task_output: Arc<TaskOutputManager>`
- `agent_pool: Arc<StateMachinePool>`
- `mailbox_router: Arc<dyn MailboxRouter>` (new trait, defined in Task 0 step 4 — production impl wraps `Arc<MessageQueueManager>`, tests inject `MockMailboxRouter`).

The shared parent budget reaches `AgentTool` through the existing `ToolUseContext.budget: Arc<BudgetEnforcer>` field (added by M3-05). `AgentTool` does NOT construct a fresh `BudgetEnforcer`; it `Arc::clone`s the parent's into the `SubagentContext` it hands to `StateMachinePool::allocate`. This is the **subagent budget inheritance** lock from spec §7 line 499.

Per spec §5: tools NEVER self-retry. Subagent failures surface as `ToolError::SubagentFailed(reason)` (M4-01 added the variant). Budget exceeded mid-subagent surfaces as `ToolError::Denied(format!("Budget exceeded (${current:.2}); stopped."))` — this string is the **M3-05 byte-lock** (see `lingxi-code/crates/cost/src/pricing.rs:154`). Task-CRUD I/O failures surface as `ToolError::Io(std::io::Error::new(ErrorKind::Other, ...))` via the `lingxi_tasks::output_manager::OutputError` → `ToolError::Io` mapping (Task 8 documents this mapping table).

**Tech Stack:** Rust 2021, `async-trait 0.1` (workspace), `serde 1` + `serde_json 1` (workspace, `serde_json` with `preserve_order` workspace feature), `tokio 1` (workspace; `sync` for `Mutex`/`RwLock`), `thiserror 1` (workspace), `uuid 1` (workspace, `v4`+`serde` features — already inherited from M4-04). Crate-level deps already present in `lingxi-tools/Cargo.toml` from M4-01..04: `lingxi-core`, `lingxi-traits`, `lingxi-telemetry`, `lingxi-permission`, `lingxi-protocol`, `lingxi-platforms-posix`. **New deps added in Task 0**: `lingxi-tasks = { path = "../tasks" }`, `lingxi-agent = { path = "../agent" }`, `lingxi-coordinator = { path = "../coordinator" }`, `lingxi-msgqueue = { path = "../msgqueue" }`, `lingxi-cost = { path = "../cost" }`. M3-03 (`lingxi-api-client`) and M3-04 (`lingxi-anthropic-oauth`) are NOT directly required here — `AgentTool` reaches the API via the agent runtime, which already owns its own API client.

The formatter is verified against `lingxi-code/crates/cost/src/budget.rs:611` (`"Budget exceeded ($150.75); stopped."` test fixture).
  - Error string templates:
    - Unknown subagent type: `format!("Agent: unknown subagent_type '{subagent_type}' (known: {})", BUILTIN_SUBAGENT_TYPES.join(", "))`.

  - Input schema (JSON):
    ```jsonc
    {
      "type": "object",
      "properties": {
        "subagent_type":  { "type": "string", "minLength": 1 },
        "prompt":         { "type": "string", "minLength": 1 },
        "context_paths":  { "type": "array", "items": { "type": "string" }, "default": [] }
      },
      "required": ["subagent_type", "prompt"]
    }
    ```
  - Flow:
    1. Parse `input` via `serde_json::from_value::<AgentToolInput>(input)`; on serde error → `ToolError::InvalidInput(format!("Agent: invalid input shape: {e}"))`.
    2. Validate `subagent_type` is in `BUILTIN_SUBAGENT_TYPES`; if not → `ToolError::InvalidInput(<unknown-type lock>)`.
    3. Validate `prompt` is non-empty (`!prompt.trim().is_empty()`); if empty → `ToolError::InvalidInput("Agent: prompt is empty".into())`.
    4. Emit `AGENT_STARTED { invocation_id, subagent_type: PiiTagged, prompt_chars: Verified(count as u64) }`.
    5. **Budget pre-check**: `match ctx.budget.check_pre_api_call(0).await { BudgetCheckResult::Halt { current, .. } => return Err(ToolError::Denied(format!("Budget exceeded (${:.2}); stopped.", current as f64 / 1e9))), .. => () }`. The pre-check at `estimated_cost = 0` only trips on the realized-exceeded latch; any prior turn that overran will halt here.
    6. **Recursive context**: build a `SubagentContext` carrying (a) `Arc::clone(&ctx.budget)` (shared budget instance — the **inheritance lock**), (b) `Arc::clone(&ctx.registry)` (shared tool registry — the **recursion lock**), (c) a fresh `AgentId::new()`, (d) the `subagent_type` string, (e) the seeded `prompt`, (f) the `context_paths`. **NOTE:** `SubagentContext`'s real shape is in `lingxi-code/crates/agent/src/context.rs`; Task 3 step 2 adds the budget+registry fields if they are not already exposed (M3-05's audit of `SubagentContext` confirmed `budget` is already wired; `registry` is added by this plan).
    7. `let (subagent_id, mut rx) = self.pool.allocate(subagent_ctx).await.map_err(|e| ToolError::Internal(format!("Agent: pool.allocate failed: {e}")))?;`.
    8. **Event loop**: `while let Some(ev) = rx.recv().await { match ev { Completed { result, .. } => return Ok(...), Failed { error, .. } => return Err(ToolError::SubagentFailed(format!("Subagent '{subagent_type}' failed: {error}"))), Killed { .. } => return Err(ToolError::Aborted("Agent: subagent was killed".into())), Progress { tool_use_count, token_count, .. } => emit AGENT_PROGRESS, Message { .. } => continue } }`. If `rx` closes without a terminal event → `ToolError::SubagentFailed(format!("Subagent '{subagent_type}' failed: event stream closed before completion"))`.
    9. **Budget post-check**: after `Completed`, call `ctx.budget.check_post_api_call_with_bus(0, Some(&self.bus)).await` to latch any realized-exceeded crossing the subagent might have triggered.
    10. Emit `AGENT_COMPLETED { invocation_id, subagent_id: Verified, duration_ms: Verified, tool_use_count: Verified, token_count: Verified, result_bytes: Verified }`.
    11. Return `ToolCallResult { data: json!({ "subagent_id": subagent_id, "subagent_type": subagent_type, "result": result }) }`.
  - Tool metadata: `name() = AGENT_TOOL_NAME`, `aliases() = &[LEGACY_AGENT_TOOL_NAME]`, `is_concurrency_safe(_) = false`, `is_read_only(_) = false`, `is_destructive(_) = false`, `is_open_world(_) = true` (subagent may use network/web tools), `interrupt_behavior(_) = InterruptBehavior::Cancel`.

        self.inner.lock().await.captured.clone()

        &self,

#[async_trait]
impl Tool for AgentTool {
    fn name(&self) -> &str { AGENT_TOOL_NAME }
    fn aliases(&self) -> &[&str] { &[LEGACY_AGENT_TOOL_NAME] }
    fn input_schema(&self) -> &Value { &AGENT_INPUT_SCHEMA }
    fn is_enabled(&self, _ctx: &ToolStaticContext) -> bool { true }
    fn max_result_size_chars(&self) -> usize { 30_000 }
    fn is_concurrency_safe(&self, _input: &Value) -> bool { false }
    fn is_read_only(&self, _input: &Value) -> bool { false }
    fn is_destructive(&self, _input: &Value) -> bool { false }
    fn is_open_world(&self, _input: &Value) -> bool { true }
    fn interrupt_behavior(&self, _input: &Value) -> InterruptBehavior { InterruptBehavior::Cancel }

    async fn execute(&self, input: Value, ctx: &ToolUseContext) -> Result<ToolCallResult, ToolError> {
        let started = std::time::Instant::now();
        // 1. Parse input.
        let parsed: AgentToolInput = serde_json::from_value(input)
            .map_err(|e| ToolError::InvalidInput(format!("Agent: invalid input shape: {e}")))?;
        // 2. Validate subagent_type.
        if !BUILTIN_SUBAGENT_TYPES.contains(&parsed.subagent_type.as_str()) {
            return Err(ToolError::InvalidInput(format!(
                "Agent: unknown subagent_type '{}' (known: {})",
                parsed.subagent_type,
                BUILTIN_SUBAGENT_TYPES.join(", ")
            )));
        }
        // 3. Validate prompt.
        if parsed.prompt.trim().is_empty() {
            return Err(ToolError::InvalidInput("Agent: prompt is empty".into()));
        }

        // 4. Emit started.
        let invocation_id = lingxi_telemetry::pii::Verified::assert_safe(uuid::Uuid::new_v4().to_string());
        emit_agent_started(&self.bus, invocation_id.clone(), &parsed).await;

        // 5. Build SubagentContext (recursion + budget inheritance lock).
        let subagent_ctx = lingxi_agent::context::SubagentContext {
            agent_id: lingxi_protocol::AgentId::new(),
            session_id: ctx.session.lock().await.session_id,
            agent_type: parsed.subagent_type.clone(),
            prompt: parsed.prompt.clone(),
            registry: std::sync::Arc::clone(&ctx.registry),
            budget: std::sync::Arc::clone(&ctx.budget),
            // ... populate remaining real fields from real struct shape
            ..Default::default()
        };

        // 6. Allocate via pool.
        let (subagent_id, mut rx) = self
            .pool
            .allocate(subagent_ctx)
            .await
            .map_err(|e| {
                emit_agent_failed(&self.bus, invocation_id.clone(), "pool_alloc", started.elapsed());
                ToolError::Internal(format!("Agent: pool.allocate failed: {e}"))
            })?;

        // 7. Event loop.
        let mut tool_use_count = 0_u64;
        let mut token_count = 0_u64;
        let mut final_result = serde_json::Value::Null;
        while let Some(ev) = rx.recv().await {
            match ev {
                lingxi_agent::runner::SubagentEvent::Completed { result, .. } => {
                    final_result = result;
                    break;
                }
                lingxi_agent::runner::SubagentEvent::Failed { error, .. } => {
                    emit_agent_failed(&self.bus, invocation_id.clone(), "subagent_failed", started.elapsed());
                    return Err(ToolError::SubagentFailed(format!(
                        "Subagent '{}' failed: {error}",
                        parsed.subagent_type
                    )));
                }
                lingxi_agent::runner::SubagentEvent::Killed { .. } => {
                    emit_agent_failed(&self.bus, invocation_id.clone(), "subagent_killed", started.elapsed());
                    return Err(ToolError::Aborted("Agent: subagent was killed".into()));
                }
                lingxi_agent::runner::SubagentEvent::Progress { tool_use_count: t, token_count: tk, .. } => {
                    tool_use_count = t as u64;
                    token_count = tk;
                }
                lingxi_agent::runner::SubagentEvent::Message { .. } => continue,
            }
        }
        // (If rx closed without Completed → final_result stays Null; we treat that as a benign empty subagent.)

        // 8. Post-check budget latch.
        ctx.budget.check_post_api_call_with_bus(0, Some(&self.bus)).await;

        // 9. Emit completed.
        emit_agent_completed(
            &self.bus,
            invocation_id,
            subagent_id,
            tool_use_count,
            token_count,
            &final_result,
            started.elapsed(),
        ).await;

        // 10. Return.
        Ok(ToolCallResult {
            data: serde_json::json!({
                "subagent_id": subagent_id.to_string(),
                "subagent_type": parsed.subagent_type,
                "result": final_result
            }),
            ..Default::default()
        })
    }
}

/// Mutate the status of an existing task. Required by `TaskUpdateTool`
/// (M4-05). Returns `TaskError::Internal` if `task_id` is unknown.
pub async fn set_status(&self, task_id: &str, new: TaskStatus) -> Result<(), TaskError> {
    let mut guard = self.tasks.write().await;
    let Some(state) = guard.get_mut(task_id) else {
        return Err(TaskError::Internal(format!("no such task '{task_id}'")));
    };
    // Refuse silly transitions out of terminal states.

    if current.is_terminal() && current != new {
        return Err(TaskError::Internal(format!(
            "cannot transition from terminal {current:?} to {new:?}"
        )));
    }
    // Mutate via match — Rust enum variants have private `base` impl access.
    match state {
        TaskState::LocalBash(s) => s.base.status = new,
        TaskState::LocalAgent(s) => s.base.status = new,
        TaskState::RemoteAgent(s) => s.base.status = new,
        TaskState::InProcessTeammate(s) => s.base.status = new,
        TaskState::LocalWorkflow(s) => s.base.status = new,
        TaskState::MonitorMcp(s) => s.base.status = new,
        TaskState::Dream(s) => s.base.status = new,
    }
    Ok(())
