# LingXi Core M4 · Plan 07 · MCP + LSP tools (5 tools)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate (final task) is the workspace-wide guard.

**Goal:** Ship 5 byte-aligned, hermetic, telemetry-bound builtin tools that surface MCP (Model Context Protocol) and LSP (Language Server Protocol) functionality to the agent loop — `MCPTool` (the `mcp__<server>__<tool>` generic dispatcher), `McpAuthTool` (inspects MCP server auth config), `ListMcpResourcesTool` (wraps `McpClient::list_resources`), `ReadMcpResourceTool` (wraps `McpClient::read_resource`), and `LSPTool` (4-operation dispatcher over `LspClient`: hover / completion / definition / references with 1-based→0-based position conversion). Tag `m4.7` at the end. All wire identifiers from spec §7 (lines 685-700) baked into both production code AND test assertions byte-for-byte. Multi-commit allowed; estimated **~14 TDD tasks** (spec §8 M4-07 phase list).

**Architecture:** Two new files under `lingxi-code/crates/tools/src/builtin/`:
- `mcp.rs` — holds FOUR tools that share one file (precedent: `task.rs` from M4-05 / `team.rs` from M4-06 host multiple tools per file when they share a domain). The four MCP tools all share the `Arc<McpRegistry>` injection point.
- `lsp.rs` — holds ONE tool, `LSPTool`, with a 4-operation enum dispatcher (`hover` / `completion` / `definition` / `references`). The fifth available LSP operation (`workspaceSymbol`, `documentSymbol`, `goToImplementation`, etc.) defined by M2-03's `LspOperation` enum is deliberately NOT surfaced in M4-07 — spec §7 locks the M4-07 surface at four operations; the remaining operations are deferred to a future plan.

Both files depend on:
- `lingxi-mcp` (M2-02b) — `McpClient`, `McpRegistry`, `McpClientError`, `McpResourceDto`, `McpResourceContentDto`, `McpToolResultDto`, `ConfigScope`, `McpServerConfig`, `McpTransportSpec`.
- `lingxi-jsonrpc` (M2-02a) — for `McpClient` constructor signature only; not invoked directly by the tools.
- `lingxi-lsp` (M2-03) — `LspClient`, `LspRegistry`, `tool_operations::{hover, find_references, go_to_definition, position_from_one_based, uri_from_path, LspOperation, LspOperationError, LspOperationResult, MAX_LSP_FILE_SIZE_BYTES}`. M2-03 already implements 1-based→0-based conversion in `position_from_one_based` (`tool_operations.rs:112`); M4-07 calls that function rather than reimplementing.
- `lingxi-traits` — `McpError`, `LspError`, `LspServerConfig` (used by `language_id_for`).
- `lingxi-telemetry::tengu::tool::*` — **15 NEW constants** added in Task 2 (3 per tool × 5 tools). The `NAMES` array under `tengu/tool.rs` extends from 94 (post-M4-06; M3-06 baseline 40 + 9 from M4-02 + 15 from M4-04 + 24 from M4-05 + 6 from M4-06) to 109. The aggregate `ALL_EVENT_NAMES` count moves up by +15.

The `BuiltinToolContext` struct (declared in M4-01, extended through M4-02..06) grows by **2 new fields** in Task 0: `mcp_registry: Arc<McpRegistry>` and `lsp_registry: Arc<LspRegistry>`. The integration points:
- `mcp_registry: Arc<McpRegistry>` — supplies `Arc<McpClient>` per server via a thin lookup helper added in Task 1.
- `lsp_registry: Arc<LspRegistry>` — supplies `Arc<LspClient>` per server. M2-03's `LspRegistry::get(server_name: &str) -> Option<Arc<LspClient>>` is the lookup point.

**No new crates created.**

Per spec §5: tools NEVER self-retry. MCP timeout errors surface verbatim from `McpClientError::Timeout` (M2-02b lock — `MCP server "{server}" tool "{tool}" timed out after {N}s`). LSP "server not running" surfaces as a literal LingXi-locked string: `LSP server '{name}' is not running`. Position-validation refusal: `LSP position must be 1-based (line >= 1, character >= 1)`. Each surface is byte-locked in both production code and the parity fixture.

  - Flows:
    - `MCPTool::call`:
      1. Parse `full_name` (string) + optional `arguments` (object — default `{}`).
      2. `parse_full_name(full_name)` → `(server, tool)`.
      3. Emit `MCP_STARTED { server: PiiTagged, tool: PiiTagged }`.
      4. Look up `Arc<McpClient>` via `mcp_registry.get_client(server)` (helper added in Task 1). If absent → emit `MCP_FAILED { error_kind: "ServerNotRegistered" }`, return `ToolError::ValidationError(format!("MCPTool: MCP server {server:?} is not registered"))`.
      5. Call `client.call_tool(full_name, arguments).await`. On `Err(e)`:
         - if `McpClientError::Timeout { .. }` → emit `MCP_FAILED { error_kind: "Timeout" }`, return `ToolError::ValidationError(e.to_string())` (the timeout Display string IS the wire-locked literal).
         - else → emit `MCP_FAILED { error_kind: "Rpc" }`, return `ToolError::ValidationError(format!("MCPTool: server {server:?} rpc error: {e}"))`.
      6. On `Ok(dto)`: emit `MCP_COMPLETED { duration_ms: Verified, server: PiiTagged, tool: PiiTagged, is_error: Verified }`, return `ToolCallResult { data: json!({ "server_name": server, "tool_name": tool, "content": dto.content, "is_error": dto.is_error }) }`.

    - `McpAuthTool::call`:
      1. Parse `server_name`.
      2. Emit `MCP_AUTH_STARTED { server: PiiTagged }`.
      3. Look up `McpServerConfig` via `mcp_registry.get_config(server_name)` (helper added in Task 1; reads the state-map). If absent → emit `MCP_AUTH_FAILED { error_kind: "ServerNotRegistered" }`, return `ToolError::ValidationError(format!("McpAuthTool: MCP server {server_name:?} is not registered"))`.
      4. Walk `config.spec` enum:
         - `Stdio { .. }` → `transport_kind = "stdio"`, `auth_kind = "none"`.
         - `Sse { oauth: Some(o), headers, headers_helper, .. }` → `transport_kind = "sse"`, `auth_kind = "oauth"`, copy `o.client_id / callback_port / auth_server_metadata_url`; record `has_static_headers = !headers.is_empty()`, `has_headers_helper = headers_helper.is_some()`.
         - `Sse { oauth: None, headers_helper: Some(_), .. }` → `auth_kind = "headers_helper"`.
         - `Sse { oauth: None, headers_helper: None, headers, .. }` if `!headers.is_empty()` → `auth_kind = "static_headers"`; else `"none"`.
         - `Http { .. }` — same shape as `Sse` (oauth, headers, no headers_helper).
         - `WebSocket { headers, .. }` → `transport_kind = "websocket"`, `auth_kind = if headers.is_empty() { "none" } else { "static_headers" }`.
         - `InProcess { .. }` → `transport_kind = "inProcess"`, `auth_kind = "none"`.
         - `SseIde { .. }` → `transport_kind = "sseIde"`, `auth_kind = "none"`.
         - `SdkControl { .. }` → `transport_kind = "sdkControl"`, `auth_kind = "none"`.
      5. Emit `MCP_AUTH_COMPLETED { duration_ms, server: PiiTagged, auth_kind: PiiTagged }` and return `ToolCallResult { data: <built shape above> }`.

    - `ListMcpResourcesTool::call`:
      1. Parse `server_name`.
      2. Emit `LIST_MCP_RESOURCES_STARTED { server: PiiTagged }`.
      3. Look up `Arc<McpClient>` via `mcp_registry.get_client(server_name)`. Absent → `MCP_LIST_RESOURCES_FAILED { error_kind: "ServerNotRegistered" }`, return `ToolError::ValidationError(format!("ListMcpResourcesTool: MCP server {server_name:?} is not registered"))`.
      4. `client.list_resources().await`. On Err → emit `LIST_MCP_RESOURCES_FAILED { error_kind: "Rpc" }`, return `ToolError::ValidationError(format!("ListMcpResourcesTool: server {server_name:?} rpc error: {e}"))`.
      5. On Ok → emit `LIST_MCP_RESOURCES_COMPLETED { duration_ms, server: PiiTagged, count: Verified }`, return `ToolCallResult { data: json!({ "server_name": server_name, "resources": dto_vec }) }`.

    - `ReadMcpResourceTool::call`:
      1. Parse `server_name` + `uri`.
      2. Emit `READ_MCP_RESOURCE_STARTED { server: PiiTagged, uri: PiiTagged }`.
      3. Look up `Arc<McpClient>` via `mcp_registry.get_client(server_name)`. Absent → emit `READ_MCP_RESOURCE_FAILED { error_kind: "ServerNotRegistered" }`, return `ToolError::ValidationError(format!("ReadMcpResourceTool: MCP server {server_name:?} is not registered"))`.
      4. `client.read_resource(&uri).await`. On Err → emit `READ_MCP_RESOURCE_FAILED { error_kind: "Rpc" }`, return `ToolError::ValidationError(format!("ReadMcpResourceTool: server {server_name:?} read_resource error: {e}"))`.
      5. On Ok → emit `READ_MCP_RESOURCE_COMPLETED { duration_ms, server: PiiTagged, uri: PiiTagged, bytes: Verified }`, return `ToolCallResult { data: json!({ "server_name": server_name, "uri": uri, "content": dto }) }`.

  - Tool metadata:
    - `MCPTool`: `is_concurrency_safe = true` (different `(server,tool)` tuples never collide), `is_read_only = false` (tools can mutate), `is_destructive = false`, `is_open_world = true` (third-party MCP server), `interrupt_behavior = InterruptBehavior::Interrupt`, `max_result_size_chars = 30_000`.
    - `McpAuthTool`: `is_concurrency_safe = true`, `is_read_only = true`, `is_destructive = false`, `is_open_world = false`, `interrupt_behavior = InterruptBehavior::Block`, `max_result_size_chars = 4_096`.

    - `ReadMcpResourceTool`: `is_read_only = true`, `is_open_world = true` (URI may point at third-party data), `interrupt_behavior = InterruptBehavior::Interrupt`, `max_result_size_chars = 30_000`.

(We have already validated `line >= 1` and `character >= 1` in step 2; this is a sanity belt-and-suspenders call. If it errors, we re-emit with the M2-03 surface and return `ToolError::ValidationError(e.to_string())`.)

       - `"hover"` → `tool_operations::hover(client, file_path, position).await`.
       - `"definition"` → `tool_operations::go_to_definition(client, file_path, position).await`.

```rust
use lingxi_tools::tool_trait::ToolError;

/// Split a `mcp__<server>__<tool>` full-name into `(server, tool)`.
///
/// Splits on the FIRST `__` AFTER the `mcp__` prefix, so tool names may
/// themselves contain `__` substrings (e.g. `mcp__fs__read_file` → `(fs, read_file)`).
///
/// Each failure produces a byte-locked error string (see
/// `parity/fixtures/mcp_lsp_tools.json`).
pub(crate) fn parse_full_name(full_name: &str) -> Result<(&str, &str), ToolError> {
    let rest = full_name
        .strip_prefix(MCP_TOOL_FULL_NAME_PREFIX)
        .ok_or_else(|| ToolError::ValidationError(format!(
            "MCPTool: full_name {full_name:?} does not match mcp__<server>__<tool> pattern"
        )))?;
    let idx = rest
        .find(MCP_TOOL_FULL_NAME_SEPARATOR)
        .ok_or_else(|| ToolError::ValidationError(format!(
            "MCPTool: full_name {full_name:?} does not match mcp__<server>__<tool> pattern"
        )))?;
    let server = &rest[..idx];
    let tool = &rest[idx + MCP_TOOL_FULL_NAME_SEPARATOR.len()..];
    if server.is_empty() {
        return Err(ToolError::ValidationError(format!(
            "MCPTool: full_name {full_name:?} has empty server segment"
        )));
    }
    if tool.is_empty() {
        return Err(ToolError::ValidationError(format!(
            "MCPTool: full_name {full_name:?} has empty tool segment"
        )));
    }
    Ok((server, tool))
}
```

```rust
#[async_trait]
impl Tool for MCPTool {
    fn name(&self) -> &str { MCP_TOOL_NAME }
    fn input_schema(&self) -> &Value { &MCP_TOOL_INPUT_SCHEMA }
    fn is_enabled(&self, _ctx: &ToolStaticContext) -> bool { true }
    fn max_result_size_chars(&self) -> usize { 30_000 }
    fn is_concurrency_safe(&self, _input: &Value) -> bool { true }
    fn is_read_only(&self, _input: &Value) -> bool { false }
    fn is_destructive(&self, _input: &Value) -> bool { false }
    fn is_open_world(&self, _input: &Value) -> bool { true }
    fn interrupt_behavior(&self, _input: &Value) -> InterruptBehavior {
        InterruptBehavior::Interrupt
    }

    async fn validate_input(
        &self,
        input: &Value,
        _ctx: &ToolUseContext,
    ) -> Result<(), ValidationError> {
        let full_name = input.get("full_name")
            .and_then(|v| v.as_str())
            .ok_or_else(|| ValidationError::new("MCPTool: missing or non-string full_name"))?;
        parse_full_name(full_name).map_err(|e| match e {
            ToolError::ValidationError(s) | ToolError::InvalidInput(s) => ValidationError::new(s),
            other => ValidationError::new(format!("{other:?}")),
        })?;
        Ok(())
    }

    async fn check_permissions(&self, _input: &Value, _ctx: &ToolUseContext) -> PermissionResult {
        PermissionResult::Allow
    }

    async fn description(&self, _input: &Value, _opts: &DescriptionOptions) -> String {
        "Invoke a tool on a registered MCP server via mcp__<server>__<tool> full-name.".into()
    }

    async fn prompt(&self, _opts: &PromptOptions) -> String {
        "Use MCPTool to dispatch to an MCP-server-provided tool.".into()
    }

    async fn call(
        &self,
        input: Value,
        _ctx: &ToolUseContext,
    ) -> Result<ToolCallResult, ToolError> {
        let started = Instant::now();
        let full_name = input.get("full_name")
            .and_then(|v| v.as_str())
            .ok_or_else(|| ToolError::InvalidInput(
                "MCPTool: missing or non-string full_name".into()
            ))?;
        let arguments = input.get("arguments").cloned().unwrap_or_else(|| json!({}));

        // Parse name first; malformed names short-circuit BEFORE STARTED.
        let (server, tool) = parse_full_name(full_name)?;

        // Emit STARTED.
        let mut meta = HashMap::new();
        meta.insert("server".into(), pii(server));
        meta.insert("tool".into(), pii(tool));
        self.bus.log_event(
            lingxi_telemetry::tengu::tool::MCP_STARTED,
            meta.clone(),
        ).await;

        // Look up client.
        let client = match self.mcp_registry.get_client(server).await {
            Some(c) => c,
            None => {
                self.bus.log_event(
                    lingxi_telemetry::tengu::tool::MCP_FAILED,
                    meta.clone(),
                ).await;
                return Err(ToolError::ValidationError(format!(
                    "MCPTool: MCP server {server:?} is not registered"
                )));
            }
        };

        // Dispatch.
        let res = client.call_tool(full_name, arguments).await;
        match res {
            Ok(dto) => {
                let mut done = meta.clone();
                done.insert("duration_ms".into(), verified_u64(started.elapsed().as_millis() as u64));
                done.insert("is_error".into(), verified_bool(dto.is_error));
                self.bus.log_event(
                    lingxi_telemetry::tengu::tool::MCP_COMPLETED,
                    done,
                ).await;
                Ok(ToolCallResult {
                    data: json!({
                        "server_name": server,
                        "tool_name": tool,
                        "content": dto.content,
                        "is_error": dto.is_error,
                    }),
                })
            }
            Err(e) => {
                self.bus.log_event(
                    lingxi_telemetry::tengu::tool::MCP_FAILED,
                    meta.clone(),
                ).await;
                // For Timeout, the Display string IS the wire-locked
                // literal — propagate verbatim.
                Err(ToolError::ValidationError(match &e {
                    McpClientError::Timeout { .. } => e.to_string(),
                    _ => format!("MCPTool: server {server:?} rpc error: {e}"),
                }))
            }
        }
    }
}
```

```rust
use lingxi_traits::McpTransportSpec;

/// Inspect an [`McpTransportSpec`] and return `(transport_kind, auth_kind)`.
///
/// `transport_kind` is the lowercase discriminator name (`"stdio"`, `"sse"`,
/// `"http"`, `"websocket"`, `"inProcess"`, `"sseIde"`, `"sdkControl"`).
///
/// `auth_kind` is one of `"oauth"`, `"headers_helper"`, `"static_headers"`,
/// `"none"`. The classification follows the precedence: OAuth wins over
/// headers_helper; headers_helper wins over static_headers; only when none
/// of those are set do we report `"none"`.
pub(crate) fn auth_kind_from_spec(spec: &McpTransportSpec) -> (&'static str, &'static str) {
    use McpTransportSpec::*;
    match spec {
        Stdio { .. } => ("stdio", "none"),
        Sse { oauth: Some(_), .. } => ("sse", "oauth"),
        Sse { headers_helper: Some(_), .. } => ("sse", "headers_helper"),
        Sse { headers, .. } if !headers.is_empty() => ("sse", "static_headers"),
        Sse { .. } => ("sse", "none"),
        Http { oauth: Some(_), .. } => ("http", "oauth"),
        Http { headers, .. } if !headers.is_empty() => ("http", "static_headers"),
        Http { .. } => ("http", "none"),
        WebSocket { headers, .. } if !headers.is_empty() => ("websocket", "static_headers"),
        WebSocket { .. } => ("websocket", "none"),
        InProcess { .. } => ("inProcess", "none"),
        SseIde { .. } => ("sseIde", "none"),
        SdkControl { .. } => ("sdkControl", "none"),
    }
}
```

```rust
        input.get("server_name").and_then(|v| v.as_str())

            .ok_or_else(|| ToolError::InvalidInput("McpAuthTool: missing or non-string server_name".into()))?
            .to_string();

        meta.insert("server".into(), pii(&server_name));
        self.bus.log_event(lingxi_telemetry::tengu::tool::MCP_AUTH_STARTED, meta.clone()).await;

        let cfg = match self.mcp_registry.get_config(&server_name).await {
            Some(c) => c,
            None => {
                self.bus.log_event(lingxi_telemetry::tengu::tool::MCP_AUTH_FAILED, meta.clone()).await;
                return Err(ToolError::ValidationError(format!(
                    "McpAuthTool: MCP server {server_name:?} is not registered"
                )));
            }
        };
        let (kind, auth) = auth_kind_from_spec(&cfg.spec);

        // Pull additional shape fields from the spec for the output JSON.
        let (client_id, callback_port, auth_meta_url, has_headers, has_helper) = match &cfg.spec {
            McpTransportSpec::Sse { oauth, headers, headers_helper, .. } |
            McpTransportSpec::Http { oauth, headers, headers_helper, .. } => {
                let (cid, port, url) = oauth.as_ref()
                    .map(|o| (o.client_id.clone(), o.callback_port, o.auth_server_metadata_url.clone()))
                    .unwrap_or_default();
                (cid, port, url, !headers.is_empty(), headers_helper.is_some())
            }
            _ => (None, None, None, false, false),
        };

        let mut done = meta.clone();
        done.insert("duration_ms".into(), verified_u64(started.elapsed().as_millis() as u64));
        done.insert("auth_kind".into(), pii(auth));
        self.bus.log_event(lingxi_telemetry::tengu::tool::MCP_AUTH_COMPLETED, done).await;

        Ok(ToolCallResult {
            data: json!({

                "transport_kind": kind,
                "auth_kind": auth,
                "client_id": client_id,
                "callback_port": callback_port,
                "auth_server_metadata_url": auth_meta_url,
                "has_static_headers": has_headers,
                "has_headers_helper": has_helper,
            }),
        })
    }
}
```

```rust
///
/// The request shape is `TextDocumentPositionParams` (URI + 0-based Position),
/// identical to `hover`. The result envelope is `CompletionResponse` per the
/// LSP spec but we deliberately return the raw JSON `result` so the caller
/// can decode into its preferred shape.
pub async fn completion(
    client: &LspClient,
    server_config: &LspServerConfig,
    tracker: &OpenFileTracker,
    file_path: &Path,
    position: Position,
) -> Result<LspOperationResult, LspOperationError> {
    let uri = uri_from_path(file_path)?;
    ensure_did_open(client, server_config, tracker, file_path, &uri).await?;
    let params = TextDocumentPositionParams {
        text_document: TextDocumentIdentifier { uri: uri.clone() },
        position,

        .call::<_, Value>("textDocument/completion", serde_json::to_value(params).unwrap())
        .await
        .map_err(LspOperationError::Lsp)?;
    Ok(LspOperationResult {
        operation: LspOperation::Completion,
        file_uri: uri.to_string(),
        raw,
    })
}
```

```rust
use std::collections::HashMap;

use std::time::Instant;

use lingxi_lsp::tool_operations as ops;
use lingxi_telemetry::pii::{PiiTagged, Verified};
use lingxi_telemetry::AnalyticsValue;
use lingxi_tools::tool_trait::{
    DescriptionOptions, InterruptBehavior, PermissionResult, PromptOptions, Tool,
    ToolCallResult, ToolError, ToolStaticContext, ToolUseContext, ValidationError,
};

static LSP_TOOL_INPUT_SCHEMA: Lazy<Value> = Lazy::new(|| json!({
    "type": "object",
    "properties": {
        "operation":   { "type": "string", "enum": ["hover", "completion", "definition", "references"] },
        "server_name": { "type": "string", "minLength": 1 },
        "file_path":   { "type": "string", "minLength": 1 },
        "line":        { "type": "integer", "minimum": 1 },
        "character":   { "type": "integer", "minimum": 1 }
    },
    "required": ["operation", "server_name", "file_path", "line", "character"]
}));

fn pii(s: &str) -> AnalyticsValue {
    AnalyticsValue::String(PiiTagged::assert_pii_tagged_column(s).into_inner())
}
fn verified_u64(n: u64) -> AnalyticsValue {
    AnalyticsValue::Integer(Verified::assert_safe(n as i64).into_inner())
}

#[async_trait]
impl Tool for LSPTool {
    fn name(&self) -> &str { LSP_TOOL_NAME }
    fn input_schema(&self) -> &Value { &LSP_TOOL_INPUT_SCHEMA }
    fn is_enabled(&self, _: &ToolStaticContext) -> bool { true }
    fn max_result_size_chars(&self) -> usize { 30_000 }
    fn is_concurrency_safe(&self, _: &Value) -> bool { true }
    fn is_read_only(&self, _: &Value) -> bool { true }
    fn is_destructive(&self, _: &Value) -> bool { false }
    fn is_open_world(&self, _: &Value) -> bool { false }
    fn interrupt_behavior(&self, _: &Value) -> InterruptBehavior { InterruptBehavior::Interrupt }

    async fn validate_input(&self, input: &Value, _: &ToolUseContext) -> Result<(), ValidationError> {
        let op = input.get("operation").and_then(|v| v.as_str())
            .ok_or_else(|| ValidationError::new("LSPTool: missing or non-string operation"))?;
        if !LSP_OPERATIONS_LOCKED.contains(&op) {
            return Err(ValidationError::new(format!(
                "LSPTool: unknown operation {op:?}; allowed: hover, completion, definition, references"
            )));
        }
        let line = input.get("line").and_then(|v| v.as_u64()).unwrap_or(0);
        let ch = input.get("character").and_then(|v| v.as_u64()).unwrap_or(0);
        if line < 1 || ch < 1 {
            return Err(ValidationError::new(LSP_POSITION_ERROR));
        }
        Ok(())
    }
    async fn check_permissions(&self, _: &Value, _: &ToolUseContext) -> PermissionResult { PermissionResult::Allow }
    async fn description(&self, _: &Value, _: &DescriptionOptions) -> String {
        "LSP-server operations (hover / completion / definition / references). 1-based positions.".into()
    }
    async fn prompt(&self, _: &PromptOptions) -> String {
        "Use LSPTool to query LSP servers at a 1-based (line, character) position.".into()
    }

    async fn call(&self, input: Value, _: &ToolUseContext) -> Result<ToolCallResult, ToolError> {
        let started = Instant::now();
        // Parse required fields with InvalidInput on missing/wrong type.
        let operation = input.get("operation").and_then(|v| v.as_str())
            .ok_or_else(|| ToolError::InvalidInput("LSPTool: missing or non-string operation".into()))?
            .to_string();
        let server_name = input.get("server_name").and_then(|v| v.as_str())
            .ok_or_else(|| ToolError::InvalidInput("LSPTool: missing or non-string server_name".into()))?
            .to_string();
        let file_path = input.get("file_path").and_then(|v| v.as_str())
            .ok_or_else(|| ToolError::InvalidInput("LSPTool: missing or non-string file_path".into()))?
            .to_string();
        let line = input.get("line").and_then(|v| v.as_u64()).ok_or_else(|| {
            ToolError::InvalidInput("LSPTool: missing or non-integer line".into())
        })? as u32;
        let character = input.get("character").and_then(|v| v.as_u64()).ok_or_else(|| {
            ToolError::InvalidInput("LSPTool: missing or non-integer character".into())
        })? as u32;

        // 1-based position guard — emits no STARTED to keep paired events.
        if line < 1 || character < 1 {
            return Err(ToolError::ValidationError(LSP_POSITION_ERROR.into()));
        }

        // Unknown-operation guard — also pre-STARTED.
        if !LSP_OPERATIONS_LOCKED.contains(&operation.as_str()) {
            return Err(ToolError::ValidationError(format!(
                "LSPTool: unknown operation {operation:?}; allowed: hover, completion, definition, references"
            )));
        }

        // STARTED.
        let mut meta = HashMap::new();
        meta.insert("operation".into(), pii(&operation));
        meta.insert("server".into(), pii(&server_name));
        meta.insert("file_path".into(), pii(&file_path));
        meta.insert("line".into(), verified_u64(line as u64));
        meta.insert("character".into(), verified_u64(character as u64));
        self.bus.log_event(lingxi_telemetry::tengu::tool::LSP_STARTED, meta.clone()).await;

        // Look up client.
        let client = match self.lsp_registry.get(&server_name).await {
            Some(c) => c,
            None => {
                self.bus.log_event(lingxi_telemetry::tengu::tool::LSP_FAILED, meta.clone()).await;
                return Err(ToolError::ValidationError(format!(
                    "LSP server '{server_name}' is not running"
                )));
            }
        };

        // 1-based → 0-based.
        let position = ops::position_from_one_based(line, character).map_err(|e| {
            // Map M2-03's error string to our locked one; this branch only
            // fires when line/character are 0 — already filtered above — so
            // it's defensive. Re-emit FAILED for visibility.
            let _ = e; // discard the M2-03 string
            ToolError::ValidationError(LSP_POSITION_ERROR.into())
        })?;

        // Look up server config (for `language_id_for` etc.).
        // The actual `server_config: &LspServerConfig` plumb-through depends
        // on how `LspRegistry::get` exposes the config — if it returns
        // `Option<(Arc<LspClient>, LspServerConfig)>` use that. Otherwise
        // call a parallel `get_config(name) -> Option<LspServerConfig>`
        // (add it to `LspRegistry` if absent, ~6 LOC).
        let server_config = match self.lsp_registry.get_config(&server_name).await {
            Some(c) => c,
            None => {
                self.bus.log_event(lingxi_telemetry::tengu::tool::LSP_FAILED, meta.clone()).await;
                return Err(ToolError::ValidationError(format!(
                    "LSP server '{server_name}' is not running"
                )));
            }
        };
        // OpenFileTracker — one per LspClient instance. If the registry
        // already owns one, use that; otherwise build a per-call tracker
        // (semantically equivalent for one-shot dispatch).
        let tracker = lingxi_lsp::open_file_tracker::OpenFileTracker::new();

        let path = Path::new(&file_path);
        let res = match operation.as_str() {
            "hover" => ops::hover(&client, &server_config, &tracker, path, position).await,
            "definition" => ops::go_to_definition(&client, &server_config, &tracker, path, position).await,
            "references" => ops::find_references(&client, &server_config, &tracker, path, position).await,
            "completion" => ops::completion(&client, &server_config, &tracker, path, position).await,
            _ => unreachable!("validated above"),
        };

        match res {
            Ok(r) => {
                let mut done = meta.clone();
                done.insert("duration_ms".into(), verified_u64(started.elapsed().as_millis() as u64));
                self.bus.log_event(lingxi_telemetry::tengu::tool::LSP_COMPLETED, done).await;
                Ok(ToolCallResult {
                    data: json!({
                        "operation": operation,
                        "server_name": server_name,
                        "file_path": file_path,
                        "result": r.raw,
                    }),
                })
            }
            Err(e) => {
                self.bus.log_event(lingxi_telemetry::tengu::tool::LSP_FAILED, meta.clone()).await;
                Err(ToolError::ValidationError(format!("LSPTool: {server_name} {operation}: {e}")))
            }
        }
    }
}
```
