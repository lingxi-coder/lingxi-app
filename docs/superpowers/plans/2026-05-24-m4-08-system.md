# LingXi Core M4 · Plan 08 · System tools (8 tools)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Multi-commit allowed** — every task ends with its own commit. The verification gate (final task) is the workspace-wide guard.

**Goal:** Ship 8 byte-aligned, hermetic, telemetry-bound builtin tools that surface system-side functionality to the agent loop:

1. `AskUserQuestionTool` — 4-option cap, 60-char label cap, 200-char question cap. Hermetic via injected `AskUserQuestionResolver` trait.
2. `BriefTool` — local stub that writes brief markdown to `~/.claude/brief/<task_id>.txt`.
3. `ConfigTool` — read/write 4 settings fields (`model`, `outputStyle`, `theme`, `verbose`) via `~/.claude/settings.json`.
4. `SkillTool` — loads a skill via `SkillLoader::load(name)`; validates 1024-char descriptor cap.
5. `ScheduleCronTool` — parses a 5-field cron expression via `lingxi_cron::parse`; persists `~/.claude/cron/<task_id>.json`; returns next-fire time.
6. `ToolSearchTool` — token-overlap scoring against the registry; top-20 results.
7. `RemoteTriggerTool` — local stub reading `~/.claude/.credentials.json`; emits `remote_trigger_started`; **no network**.
8. `SyntheticOutputTool` — echo-input stub for parity replay.

Tag `m4.8` at the end. All wire identifiers from spec §7 baked into both production code AND test assertions byte-for-byte. Multi-commit allowed; **28 TDD tasks** (spec §8 M4-08 phase list expanded).

**Architecture:** Eight isolated builtin modules under `lingxi-code/crates/tools/src/builtin/` — one tool per file. Each tool implements `lingxi_tools::tool_trait::Tool`, gets a `new(ctx: BuiltinToolContext) -> Self` constructor, and is registered into `register_all_builtin_tools` (Task 26). Both M4-07 (MCP+LSP) and M4-05 (Agent/Task) extended `BuiltinToolContext` with new fields; this plan extends it again in Task 1 with 6 new fields:

- `ask_user_question_resolver: Arc<dyn AskUserQuestionResolver>` — trait-injection point for AskUserQuestionTool (test uses a fixed-index mock).
- `skill_loader: Arc<dyn lingxi_skills::loader::SkillLoader>` — already exists from M1/M3; we add the field even if it was registered before this plan.
- `cron_parser: Arc<dyn CronParser>` — thin wrapper trait around `lingxi_cron::parse` (lets tests inject a fake clock-aware parser).
- `clock: Arc<dyn lingxi_platform_api::clock::Clock>` — already exists from M1; added if not present (used by ScheduleCronTool, BriefTool for task_id).
- `tool_registry_view: Arc<dyn ToolRegistryView>` — read-only view of `ToolRegistry` used by ToolSearchTool to enumerate tools without circular ownership (an `Arc<ToolRegistry>` would cycle; the view trait exposes only `iter_names() + describe(name)`).
- `home_dir_provider: Arc<dyn HomeDirProvider>` — already exists from M3; explicit injection lets tests use a temp dir.

All side effects flow through the existing `fs: Arc<dyn FileSystem>` field (M4-01 lock) — `BriefTool`, `ConfigTool`, `ScheduleCronTool`, `RemoteTriggerTool` use it.

Per spec §5: tools NEVER self-retry. Filesystem failures surface as `ToolError::Io(std::io::Error::new(ErrorKind::Other, ...))`. Validation failures surface as `ToolError::ValidationError(String)` / `ToolError::InvalidInput(String)`. Permission denials surface via `PermissionGate::check` upstream — NOT re-implemented in these tools (reuse pattern from M4-01..07).

**Tech Stack:** Rust 2021, `async-trait 0.1` (workspace), `serde 1` + `serde_json 1` (workspace, `serde_json` with `preserve_order` workspace feature), `tokio 1` (workspace; for tests via `#[tokio::test]`), `thiserror 1` (workspace), `once_cell 1` (workspace). **Critical fidelity notes (divergences from the user prompt, locked here):**

- **Brief task_id format**: the prompt says "uuid = lingxi-core's task-id format" with the parenthetical "(uuid = lingxi-core's task-id format)" but the locked wire-identifier table says **NOT** UUID v4 — it's the 9-char `[bartwmd][0-9a-z]{8}` format. M4-08 uses the 9-char format (matches `lingxi_tasks::id::TaskId::new` from M1). The function is `lingxi_tasks::id::TaskId::generate_with_prefix('b')` for brief; if absent, we call `TaskId::random()` and prepend `'b'` (Task 5 step 4 documents the choice).
- **ConfigTool field allowlist**: 4 fields — `model`, `outputStyle`, `theme`, `verbose`. The settings JSON uses camelCase wire keys but Rust uses snake_case via `#[serde(rename_all = "camelCase")]`. M4-08 accepts BOTH wire keys (`outputStyle` and `output_style`) on input but always emits camelCase on output (matches upstream claude-code).
- **Cron expression: 5-field only**. Quartz-style 6-field with seconds is REJECTED with `"ScheduleCron: 6-field cron (with seconds) is not supported; use 5-field cron (minute hour day month weekday)"`.
- **ToolSearchTool scoring**: token-overlap over both `name` and `description`. Normalized: lowercase, split on `[^a-z0-9]+`. Score = `|query_tokens ∩ tool_tokens|`. Ties broken by tool name lexicographic order. Top 20 results returned.
- **RemoteTriggerTool — explicit non-goal**: no network. The tool reads `~/.claude/.credentials.json` (legacy path), validates it's parseable JSON with at least an `oauth.access_token` string, and returns `{ "stub": true, "credentials_path": "<resolved>", "would_trigger": <input> }`. It emits `remote_trigger_started` and `remote_trigger_completed` but performs no HTTP.
- **SyntheticOutputTool**: input is `{ content: String }`; output is `{ content: String }` echoed verbatim. Maximum content length = `MAX_TOOL_OUTPUT_LENGTH` (30_000 chars); excess truncated with the M4-01 truncation suffix.
- **Tool event suffix**: M3-06 lock is `_completed` (matches M4-06/M4-07 precedent). Spec §1 shorthand `_succeeded` is NOT the wire string.
- **PermissionGate**: this plan does NOT modify `lingxi-permission`. All tools call `ctx.permission_gate.check(name, &input, ctx)` via the dispatch flow (M4-01 lock); tools themselves do not invoke the gate directly.

//! AskUserQuestionTool — prompts the user with up to 4 labeled options.
//!
//! Wire identifiers locked in spec §7:
//! - Max 4 options.
//! - Each label ≤ 60 chars.
//! - Question ≤ 200 chars.
//! - Returns `{ selected_index, selected_label }`.

use async_trait::async_trait;
use lingxi_telemetry::AnalyticsBus;
use lingxi_tools::tool_trait::ToolError;

pub const ASK_USER_QUESTION_TOOL_NAME: &str = "AskUserQuestion";
pub const MAX_ASK_OPTIONS: usize = 4;
pub const MAX_ASK_LABEL_LEN: usize = 60;
pub const MAX_ASK_QUESTION_LEN: usize = 200;

/// Injected resolver — production wraps a terminal prompt; tests use a fixed-index mock.
#[async_trait]
pub trait AskUserQuestionResolver: Send + Sync {
    async fn resolve(
        &self,
        question: &str,
        options: &[String],
    ) -> Result<usize, ToolError>;
}

pub struct AskUserQuestionTool {
    pub(crate) resolver: Arc<dyn AskUserQuestionResolver>,
    pub(crate) bus: Arc<AnalyticsBus>,
}

impl AskUserQuestionTool {
    pub fn new(ctx: super::BuiltinToolContext) -> Self {
        Self {
            resolver: ctx.ask_user_question_resolver,
            bus: ctx.bus,
        }
    }
}

use lingxi_telemetry::pii::{PiiTagged, Verified};
use lingxi_tools::tool_trait::{
    DescriptionOptions, InterruptBehavior, PermissionResult, PromptOptions, Tool,
    ToolCallResult, ToolStaticContext, ToolUseContext, ValidationError,
};
use serde_json::{json, Value};
use std::time::Instant;

#[async_trait::async_trait]
impl Tool for AskUserQuestionTool {
    fn name(&self) -> &'static str {
        ASK_USER_QUESTION_TOOL_NAME
    }

    fn input_schema(&self) -> Value {
        json!({
            "type": "object",
            "properties": {
                "question": {
                    "type": "string",
                    "minLength": 1,
                    "maxLength": MAX_ASK_QUESTION_LEN
                },
                "options": {
                    "type": "array",
                    "minItems": 1,
                    "maxItems": MAX_ASK_OPTIONS,
                    "items": { "type": "string", "minLength": 1, "maxLength": MAX_ASK_LABEL_LEN }
                }
            },
            "required": ["question", "options"]
        })
    }

    fn output_schema(&self) -> Value {
        json!({
            "type": "object",
            "properties": {
                "selected_index": { "type": "integer", "minimum": 0 },
                "selected_label": { "type": "string" }
            },
            "required": ["selected_index", "selected_label"]
        })
    }

    fn is_concurrency_safe(&self) -> bool { false }
    fn is_read_only(&self) -> bool { true }
    fn is_destructive(&self) -> bool { false }
    fn is_open_world(&self) -> bool { false }
    fn interrupt_behavior(&self) -> InterruptBehavior { InterruptBehavior::Block }
    fn max_result_size_chars(&self) -> usize { 4_096 }

    fn validate_input(&self, input: &Value) -> Result<(), ValidationError> {
        let q = input.get("question").and_then(|v| v.as_str()).ok_or_else(|| {
            ValidationError::new("AskUserQuestion: missing or non-string question")
        })?;
        validate_question(q).map_err(|e| ValidationError::new(&format!("{e}")))?;
        let opts_v = input.get("options").and_then(|v| v.as_array()).ok_or_else(|| {
            ValidationError::new("AskUserQuestion: missing or non-array options")
        })?;
        let opts: Vec<String> = opts_v
            .iter()
            .map(|v| v.as_str().unwrap_or("").to_string())
            .collect();
        validate_options(&opts).map_err(|e| ValidationError::new(&format!("{e}")))?;
        Ok(())
    }

    async fn check_permissions(
        &self,
        _input: &Value,
        _ctx: &ToolUseContext,
    ) -> PermissionResult {
        PermissionResult::Allow
    }

    fn description(&self, _opts: &DescriptionOptions) -> String {
        "Ask the user a multiple-choice question (max 4 options, 60-char labels).".into()
    }

    fn prompt(&self, _opts: &PromptOptions) -> String {
        "AskUserQuestion: prompts the user with up to 4 labeled options.".into()
    }

    async fn call(
        &self,
        input: Value,
        _ctx: &ToolUseContext,
    ) -> Result<ToolCallResult, ToolError> {
        let started = Instant::now();
        let q = input
            .get("question")
            .and_then(|v| v.as_str())
            .ok_or_else(|| ToolError::InvalidInput(
                "AskUserQuestion: missing or non-string question".into(),
            ))?;
        validate_question(q)?;
        let opts_v = input
            .get("options")
            .and_then(|v| v.as_array())
            .ok_or_else(|| ToolError::InvalidInput(
                "AskUserQuestion: missing or non-array options".into(),
            ))?;
        let opts: Vec<String> = opts_v
            .iter()
            .map(|v| v.as_str().unwrap_or("").to_string())
            .collect();
        validate_options(&opts)?;

        self.bus
            .log_event(
                "tengu_tool_ask_user_question_started",
                lingxi_telemetry::log_event_metadata! {
                    "question_len" => Verified::new(q.chars().count() as u64),
                    "option_count" => Verified::new(opts.len() as u64),
                },
            )
            .await;

        let idx = match self.resolver.resolve(q, &opts).await {
            Ok(i) => i,
            Err(e) => {
                self.bus
                    .log_event(
                        "tengu_tool_ask_user_question_failed",
                        lingxi_telemetry::log_event_metadata! {
                            "error_kind" => PiiTagged::new("ResolverError"),
                        },
                    )
                    .await;
                return Err(e);
            }
        };

        if idx >= opts.len() {
            self.bus
                .log_event(
                    "tengu_tool_ask_user_question_failed",
                    lingxi_telemetry::log_event_metadata! {
                        "error_kind" => PiiTagged::new("ResolverIndexOutOfRange"),
                    },
                )
                .await;
            return Err(ToolError::ValidationError(format!(
                "AskUserQuestion: resolver returned index {idx} but only {} options were provided",
                opts.len()
            )));
        }

        let label = opts[idx].clone();
        self.bus
            .log_event(
                "tengu_tool_ask_user_question_completed",
                lingxi_telemetry::log_event_metadata! {
                    "duration_ms" => Verified::new(started.elapsed().as_millis() as u64),
                    "selected_index" => Verified::new(idx as u64),
                },
            )
            .await;
        Ok(ToolCallResult {
            data: json!({ "selected_index": idx, "selected_label": label }),
        })
    }
}

/// Generate a `b`-prefixed 9-char task id `[b][0-9a-z]{8}`.
///
/// Matches `lingxi_tasks::id::TaskId::new_with_prefix('b')` semantics — we
/// inline the generation here to avoid a hard dep on `lingxi-tasks` for
/// this tool. The suffix is 8 random base-36 chars (lowercase alphanumeric).
pub(crate) fn generate_brief_task_id() -> String {
    use rand::Rng;
    let mut rng = rand::thread_rng();
    const ALPHABET: &[u8] = b"0123456789abcdefghijklmnopqrstuvwxyz";
    let mut s = String::with_capacity(9);

    for _ in 0..8 {
        let idx = rng.gen_range(0..ALPHABET.len());
        s.push(ALPHABET[idx] as char);
    }
    s
}

    home.join(".claude").join(BRIEF_SUBDIR).join(format!("{task_id}{BRIEF_FILE_SUFFIX}"))

            "Config: settings.json is not valid JSON ({e})"
        ))
    })?;
    match parsed {
        Value::Object(m) => Ok(m),
        _ => Err(ToolError::ValidationError(
            "Config: settings.json root must be a JSON object".into(),
        )),
    }
}

async fn write_settings(
    tool: &ConfigTool,
    map: &Map<String, Value>,
) -> Result<(), ToolError> {
    let home = tool.home.home_dir().ok_or_else(|| {
        ToolError::Internal("Config: HOME directory not available".into())
    })?;
    let dir = home.join(CONFIG_SUBDIR);
    let p = dir.join(CONFIG_FILE_NAME);
    tool.fs.create_dir_all(&dir).await.map_err(|e| {
        ToolError::Io(std::io::Error::new(
            std::io::ErrorKind::Other,
            format!("Config: io error creating {}: {e}", dir.display()),
        ))
    })?;
    let body = serde_json::to_vec_pretty(map).map_err(|e| {
        ToolError::Internal(format!("Config: serde error: {e}"))
    })?;
    tool.fs.write(&p, &body).await.map_err(|e| {
        ToolError::Io(std::io::Error::new(
            std::io::ErrorKind::Other,
            format!("Config: io error writing {}: {e}", p.display()),
        ))
    })
}

#[async_trait]
impl Tool for ConfigTool {
    fn name(&self) -> &'static str { CONFIG_TOOL_NAME }

    fn input_schema(&self) -> Value {
        json!({
            "type": "object",
            "properties": {
                "op": { "type": "string", "enum": ["get", "set"] },
                "field": { "type": "string", "minLength": 1 },
                "value": {}
            },
            "required": ["op", "field"]
        })
    }

    fn output_schema(&self) -> Value {
        json!({
            "type": "object",
            "properties": {
                "field": { "type": "string" },
                "value": {}
            },
            "required": ["field"]
        })
    }

    fn is_concurrency_safe(&self) -> bool { false }
    fn is_read_only(&self) -> bool { false }
    fn is_destructive(&self) -> bool { false }
    fn is_open_world(&self) -> bool { false }
    fn interrupt_behavior(&self) -> InterruptBehavior { InterruptBehavior::Block }
    fn max_result_size_chars(&self) -> usize { 4_096 }

    fn validate_input(&self, input: &Value) -> Result<(), ValidationError> {
        let op = input.get("op").and_then(|v| v.as_str()).ok_or_else(|| {
            ValidationError::new("Config: op must be 'get' or 'set'")
        })?;
        if op != "get" && op != "set" {
            return Err(ValidationError::new("Config: op must be 'get' or 'set'"));
        }
        let field = input.get("field").and_then(|v| v.as_str()).ok_or_else(|| {
            ValidationError::new("Config: missing or non-string field")
        })?;
        if normalize_field_name(field).is_none() {
            return Err(ValidationError::new(&format!(
                "Config: field {:?} is not in allowed list [model, outputStyle, theme, verbose]",
                field
            )));
        }
        if op == "set" && !input.get("value").is_some() {
            return Err(ValidationError::new("Config: set op requires a value"));
        }
        Ok(())
    }

    async fn check_permissions(
        &self,
        _input: &Value,
        _ctx: &ToolUseContext,
    ) -> PermissionResult {
        PermissionResult::Allow
    }

    fn description(&self, _opts: &DescriptionOptions) -> String {
        "Read or write user settings (model/outputStyle/theme/verbose) in ~/.claude/settings.json.".into()
    }

    fn prompt(&self, _opts: &PromptOptions) -> String {
        "Config: get or set one of 4 allowlisted settings fields.".into()
    }

    async fn call(
        &self,
        input: Value,
        _ctx: &ToolUseContext,
    ) -> Result<ToolCallResult, ToolError> {
        let started = Instant::now();
        let op = input.get("op").and_then(|v| v.as_str()).ok_or_else(|| {
            ToolError::InvalidInput("Config: op must be 'get' or 'set'".into())
        })?;
        if op != "get" && op != "set" {
            return Err(ToolError::InvalidInput("Config: op must be 'get' or 'set'".into()));
        }
        let field_in = input.get("field").and_then(|v| v.as_str()).ok_or_else(|| {
            ToolError::InvalidInput("Config: missing or non-string field".into())
        })?;
        let canonical = normalize_field_name(field_in).ok_or_else(|| {
            ToolError::ValidationError(format!(
                "Config: field {:?} is not in allowed list [model, outputStyle, theme, verbose]",
                field_in
            ))
        })?;
        self.bus
            .log_event(
                CONFIG_STARTED,
                lingxi_telemetry::log_event_metadata! {
                    "op" => PiiTagged::new(op),
                    "field" => PiiTagged::new(canonical),
                },
            )
            .await;

        let result = match op {
            "get" => {
                let map = read_settings(self).await?;
                let value = map.get(canonical).cloned().unwrap_or(Value::Null);
                Ok(json!({ "field": canonical, "value": value }))
            }
            "set" => {
                let value = input.get("value").cloned().unwrap_or(Value::Null);
                let mut map = read_settings(self).await.unwrap_or_default();
                map.insert(canonical.to_string(), value.clone());
                write_settings(self, &map).await?;
                Ok(json!({ "field": canonical, "value": value }))
            }
            _ => unreachable!(),
        };

        match &result {
            Ok(_) => {
                self.bus
                    .log_event(
                        CONFIG_COMPLETED,
                        lingxi_telemetry::log_event_metadata! {
                            "duration_ms" => Verified::new(started.elapsed().as_millis() as u64),
                            "op" => PiiTagged::new(op),
                        },
                    )
                    .await;
            }
            Err(_) => {
                self.bus
                    .log_event(
                        CONFIG_FAILED,
                        lingxi_telemetry::log_event_metadata! {
                            "op" => PiiTagged::new(op),
                        },
                    )
                    .await;
            }
        }
        Ok(ToolCallResult { data: result? })
    }
}

/// Validate that the expression has exactly 5 whitespace-separated fields.
/// 6-field (Quartz, with seconds) is rejected with a byte-locked error string.
pub(crate) fn validate_cron_field_count(expr: &str) -> Result<(), ToolError> {
    let trimmed = expr.trim();
    if trimmed.is_empty() {
        return Err(ToolError::ValidationError(
            "ScheduleCron: cron expression is empty".into(),
        ));
    }
    let count = trimmed.split_whitespace().count();
    if count == 6 {
        return Err(ToolError::ValidationError(
            "ScheduleCron: 6-field cron (with seconds) is not supported; use 5-field cron (minute hour day month weekday)".into(),
        ));
    }
    if count != 5 {
        return Err(ToolError::ValidationError(format!(
            "ScheduleCron: expected 5 fields, got {count}"
        )));
    }
    Ok(())
}

use std::collections::HashSet;

/// Lowercase + split on any non-ASCII-alphanumeric run.
pub(crate) fn tokenize(text: &str) -> Vec<String> {
    let lower = text.to_ascii_lowercase();
    lower
        .split(|c: char| !c.is_ascii_alphanumeric())
        .filter(|s| !s.is_empty())
        .map(|s| s.to_string())
        .collect()
}

/// Count of tokens shared between query and tool (set intersection size).
pub(crate) fn overlap_score(query_tokens: &[String], tool_tokens: &[String]) -> usize {
    let q: HashSet<&String> = query_tokens.iter().collect();
    let t: HashSet<&String> = tool_tokens.iter().collect();
    q.intersection(&t).count()
}

pub const TOOL_SEARCH_COMPLETED: &str = "tengu_tool_tool_search_completed";

impl Tool for ToolSearchTool {
    fn name(&self) -> &'static str { TOOL_SEARCH_TOOL_NAME }

    fn input_schema(&self) -> Value {

            "type": "object",
            "properties": { "query": { "type": "string", "minLength": 1 } },
            "required": ["query"]
        })

    fn output_schema(&self) -> Value {
        json!({
            "type": "object",
            "properties": {
                "results": {
                    "type": "array",
                    "items": {
                        "type": "object",
                        "properties": {
                            "name": { "type": "string" },
                            "description": { "type": "string" },
                            "score": { "type": "integer", "minimum": 1 }
                        }
                    }
                }
            },
            "required": ["results"]
        })
    }

    fn is_concurrency_safe(&self) -> bool { true }
    fn is_read_only(&self) -> bool { true }
    fn is_destructive(&self) -> bool { false }
    fn is_open_world(&self) -> bool { false }
    fn interrupt_behavior(&self) -> InterruptBehavior { InterruptBehavior::Interrupt }
    fn max_result_size_chars(&self) -> usize { 30_000 }

    fn validate_input(&self, input: &Value) -> Result<(), ValidationError> {
        let q = input.get("query").and_then(|v| v.as_str()).ok_or_else(|| {
            ValidationError::new("ToolSearch: missing or non-string query")
        })?;
        if q.is_empty() {
            return Err(ValidationError::new("ToolSearch: query is empty"));
        }
        Ok(())
    }

    async fn check_permissions(
        &self,
        _input: &Value,
        _ctx: &ToolUseContext,
    ) -> PermissionResult {
        PermissionResult::Allow
    }

    fn description(&self, _opts: &DescriptionOptions) -> String {
        "Search registered tools by token overlap. Returns top-20 matches.".into()
    }

    fn prompt(&self, _opts: &PromptOptions) -> String {
        "ToolSearch: find tools by overlap between query tokens and tool name/description.".into()
    }

    async fn call(
        &self,
        input: Value,
        _ctx: &ToolUseContext,
    ) -> Result<ToolCallResult, ToolError> {
        let started = Instant::now();
        let query = input.get("query").and_then(|v| v.as_str()).ok_or_else(|| {
            ToolError::InvalidInput("ToolSearch: missing or non-string query".into())
        })?;
        if query.is_empty() {
            return Err(ToolError::ValidationError("ToolSearch: query is empty".into()));
        }
        let qtoks = tokenize(query);

        self.bus

                TOOL_SEARCH_STARTED,
                lingxi_telemetry::log_event_metadata! {
                    "query" => PiiTagged::new(query),
                    "token_count" => Verified::new(qtoks.len() as u64),

            .iter_names()

                let score = overlap_score(&qtoks, &toks);
                if score == 0 {
                    None
                } else {
                    Some((score, name, desc))
                }
            })
            .collect();

        scored.sort_by(|a, b| b.0.cmp(&a.0).then(a.1.cmp(&b.1)));
        scored.truncate(TOOL_SEARCH_MAX_RESULTS);

        let results: Vec<Value> = scored
            .into_iter()
            .map(|(score, name, desc)| json!({ "name": name, "description": desc, "score": score }))
            .collect();
        let result_count = results.len();

        self.bus
            .log_event(
                TOOL_SEARCH_COMPLETED,
                lingxi_telemetry::log_event_metadata! {
                    "duration_ms" => Verified::new(started.elapsed().as_millis() as u64),
                    "result_count" => Verified::new(result_count as u64),
                },
            )
            .await;
        Ok(ToolCallResult { data: json!({ "results": results }) })
    }
}

/// Maximum echo length (matches M4-01 `MAX_TOOL_OUTPUT_LENGTH`).
pub const SYNTHETIC_OUTPUT_MAX_LEN: usize = 30_000;

/// Truncation suffix (matches M4-01 lock).
pub const SYNTHETIC_TRUNCATION_SUFFIX: &str = "\n\n[Output truncated due to length]";

/// Truncate input to `SYNTHETIC_OUTPUT_MAX_LEN` chars, appending the
/// truncation suffix if the cap is exceeded. Returns `(content, truncated)`.
pub(crate) fn truncate_synthetic(input: &str) -> (String, bool) {
    let count = input.chars().count();
    if count <= SYNTHETIC_OUTPUT_MAX_LEN {
        return (input.to_string(), false);
    }
    let prefix: String = input.chars().take(SYNTHETIC_OUTPUT_MAX_LEN).collect();
    (format!("{prefix}{SYNTHETIC_TRUNCATION_SUFFIX}"), true)
}
