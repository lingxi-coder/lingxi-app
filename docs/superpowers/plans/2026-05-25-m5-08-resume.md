> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the resume layer that takes an `Option<Uuid>` (None → interactive 5-row picker, Some → direct load), reads the matching JSONL via the byte-locked path resolver from M5-07, validates the `parentUuid` chain + `sessionId` consistency, replays the messages into a freshly-built `ConversationOrchestrator` (M5-02), and continues the turn loop while **re-using the same `sessionId`** so the next JSONL append chains off the last loaded `uuid`. **Tech stack:** Rust async (tokio), `lingxi-session::jsonl::{JsonlReader, JsonlMessage, session_path, project_dir_name}` (M5-07), `lingxi-orchestrator::{ConversationOrchestrator, OrchestratorConfig, SessionState}` (M5-02), `lingxi-telemetry::tengu::session` (M5-07 schema), `uuid = "1.10"` (already workspace), `tokio = "1"` (workspace), `tempfile = "3.13"` (dev), `tokio::io::duplex` for stdin-driven selection tests (mirrors M5-05 pattern).

- [ ] **Step 3: Confirm title extraction from `claude-code/src/utils/sessionStorage.ts::enrichLogs` + `firstPrompt` derivation.**

  In claude-code, `enrichLogs` walks the first ~16 KiB of a JSONL and runs `extractJsonStringField` (locked in M5-07 T0) for the `content` of the first `type: "user"` line where `message.role === "user"`. Multi-block content is collapsed to the text of the first `text`-typed block. The string is then `trim()`ed and Unicode-segmented to 50 graphemes.

  **Lock for M5-08:** the title is derived from the **already-deserialized** `Vec<JsonlMessage>` (we don't need a separate lite re-parse because `list_recent_sessions` uses `read_lite` anyway, see Task 4). The algorithm:

  1. Walk messages; find the first `m` where `m.message_type == "user"` and `m.message` is an object with `role == "user"`.
  2. Extract `content`:
     - If `content` is a JSON string → use it.
     - If `content` is a JSON array → find the first element whose `type == "text"`, use its `text` field; if no text block, return the empty string.
     - Any other shape → return the empty string.
  3. `trim()` the result.
  4. If the trimmed string has > 50 chars (Unicode `char_indices()` length — NOT byte length), truncate to the **byte index of the 50th `char`** and append `…` (U+2026, single grapheme).
  5. Return the result.

  **Edge cases (all byte-locked in T2 tests):**
  - empty `Vec<JsonlMessage>` → `""`
  - no `type: "user"` message → `""`
  - first user message has empty string content → `""`
  - first user message has 50-char content → returned as-is (no ellipsis)
  - first user message has 51-char content → truncated to 50 chars + `…`
  - first user message has multi-byte chars (e.g. CJK) → truncate by char count, not byte count
  - content is `[{type: "text", text: "hi"}, {type: "text", text: "bye"}]` → returns `"hi"`
  - content is `[{type: "image", source: ...}]` → returns `""`

/// Metadata for one resumable session row (uuid + title + mtime + line count).

pub struct SessionMetadata {

    pub uuid: Uuid,
    /// The session title (extracted via [`crate::jsonl::title::extract_title`]; ≤ 50 chars + ellipsis).

impl Ord for SessionMetadata {
    fn cmp(&self, other: &Self) -> Ordering {
        // Newest-first (mtime desc), tie-break by filename asc.
        other
            .modified
            .cmp(&self.modified)
            .then_with(|| self.path.cmp(&other.path))
    }
}

impl PartialOrd for SessionMetadata {
    fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
        Some(self.cmp(other))
    }
}

```rust
/// Returns the session title — the first user message's text content, trimmed and
/// truncated to [`TITLE_MAX_CHARS`] chars with [`TITLE_ELLIPSIS`] appended if longer.
///
/// Algorithm (locked against `claude-code` `enrichLogs::firstPrompt`):
/// 1. Find first `m` where `m.message_type == "user"` AND `m.message.role == "user"`.
/// 2. Extract `content`:
///    - JSON string → use directly.
///    - JSON array → first element with `type == "text"` → use its `text` field.
///    - Anything else → empty string.
/// 3. `trim()` the result.
/// 4. If > 50 `char`s, truncate to the 50th char boundary and append `…`.
#[must_use]
pub fn extract_title(messages: &[JsonlMessage]) -> String {
    for m in messages {
        if m.message_type != "user" {
            continue;
        }
        // `JsonlMessage::message` is `serde_json::Value` per M5-07 T1 step 5.
        let role = m.message.get("role").and_then(serde_json::Value::as_str);
        if role != Some("user") {
            continue;
        }
        let content = match m.message.get("content") {
            Some(c) => c,
            None => continue,
        };
        let raw = if let Some(s) = content.as_str() {
            s.to_string()
        } else if let Some(arr) = content.as_array() {
            let first_text = arr.iter().find_map(|block| {
                let ty = block.get("type").and_then(serde_json::Value::as_str)?;
                if ty == "text" {
                    block.get("text").and_then(serde_json::Value::as_str).map(str::to_string)
                } else {
                    None
                }
            });
            match first_text {
                Some(s) => s,
                None => String::new(),
            }
        } else {
            String::new()
        };
        return truncate_with_ellipsis(raw.trim());
    }
    String::new()
}

/// Truncate `s` to [`TITLE_MAX_CHARS`] `char`s, appending [`TITLE_ELLIPSIS`] if anything was cut.
#[must_use]
fn truncate_with_ellipsis(s: &str) -> String {
    let char_count = s.chars().count();
    if char_count <= TITLE_MAX_CHARS {
        return s.to_string();
    }
    // Find the byte index of the (TITLE_MAX_CHARS)th char so we slice on a valid UTF-8 boundary.
    let cutoff_byte = s
        .char_indices()
        .nth(TITLE_MAX_CHARS)
        .map_or_else(|| s.len(), |(idx, _)| idx);
    let mut out = String::with_capacity(cutoff_byte + TITLE_ELLIPSIS.len_utf8());
    out.push_str(&s[..cutoff_byte]);
    out.push(TITLE_ELLIPSIS);
    out
}
```

/// Resolve the project dir for `cwd` and return up to `limit` most-recently-modified
/// `.jsonl` files as [`SessionMetadata`] rows, sorted by mtime desc (filename asc on tie).
///
/// Errors:
/// - [`LoaderError::EmptyDirectory`] if the project dir doesn't exist OR contains no `.jsonl`.
/// - [`LoaderError::Io`] on any other I/O failure.
///
/// Each row's `title` is read via [`crate::jsonl::title::extract_title`] from the **full**
/// JSONL content (we open + parse every candidate, then sort + truncate). This is O(N * lines)
/// for N sessions; for the typical N ≤ 5 case (the picker limit) the cost is trivial.
///
/// Locked against `claude-code/src/utils/sessionStorage.ts::loadSameRepoMessageLogs` — except:
/// - claude-code uses a 16-KiB head-only `enrichLogs` scan for the first user message; we
///   open + fully-parse because our `JsonlReader::read_all` is already in hand from M5-07.
/// - claude-code includes worktrees; we list ONLY the exact cwd's project dir (cross-worktree
///   resume is deferred to a follow-up — spec §3 M5-08 row does not require it).
pub async fn list_recent_sessions(
    cwd: &Path,
    limit: usize,
) -> Result<Vec<SessionMetadata>, LoaderError> {
    let project_dir = project_dir_for_cwd(cwd);
    let mut entries = match tokio::fs::read_dir(&project_dir).await {
        Ok(rd) => rd,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            return Err(LoaderError::EmptyDirectory);
        }
        Err(source) => {
            return Err(LoaderError::Io {
                arg: cwd.display().to_string(),
                source,
            });
        }
    };

    let mut rows: Vec<SessionMetadata> = Vec::new();
    while let Some(entry) = entries
        .next_entry()
        .await
        .map_err(|source| LoaderError::Io {
            arg: cwd.display().to_string(),
            source,
        })?
    {
        let path = entry.path();
        if path.extension().and_then(|s| s.to_str()) != Some("jsonl") {
            continue;
        }
        let metadata = entry.metadata().await.map_err(|source| LoaderError::Io {
            arg: path.display().to_string(),
            source,
        })?;
        let modified = metadata.modified().map_err(|source| LoaderError::Io {
            arg: path.display().to_string(),
            source,
        })?;

        // Parse uuid from filename stem.
        let Some(stem) = path.file_stem().and_then(|s| s.to_str()) else {
            continue;
        };
        let Ok(uuid) = Uuid::parse_str(stem) else {
            // Non-UUID filename (e.g. crash dump) — skip silently.
            continue;
        };

        let reader = JsonlReader::new(&path);
        let messages = reader.read_all().await.map_err(|source| LoaderError::Io {
            arg: path.display().to_string(),
            source: std::io::Error::new(std::io::ErrorKind::InvalidData, source.to_string()),
        })?;
        let title = extract_title(&messages);
        rows.push(SessionMetadata {
            uuid,
            title,
            modified,
            message_count: messages.len(),
            path,
        });
    }

    if rows.is_empty() {
        return Err(LoaderError::EmptyDirectory);
    }

    rows.sort();
    rows.truncate(limit);
    Ok(rows)
}

/// Resolve `cwd` → `<claude_home>/projects/<sanitize(cwd)>[-djb2]` (M5-07 path lock).

}

```rust
/// Load a session by UUID, validate its `parentUuid` chain + `sessionId` consistency,
/// and return the deserialized `Vec<JsonlMessage>` in file order.
///
/// Validation rules (spec §4.x):
/// 1. The first message's `parent_uuid` is `None` (root of the chain).
/// 2. Every subsequent message's `parent_uuid` MUST equal the previous message's `uuid`.
/// 3. All messages MUST share the same `session_id` (matching the requested `session_id` arg).
///
/// Errors:
/// - [`LoaderError::SessionNotFound`] if the file doesn't exist.
/// - [`LoaderError::ChainBroken`] if rule 1 or 2 fails.
/// - [`LoaderError::SessionIdMismatch`] if rule 3 fails.
/// - [`LoaderError::Io`] / [`LoaderError::Parse`] on disk-or-format issues.
pub async fn load_session(
    session_id: Uuid,
    cwd: &Path,
) -> Result<Vec<JsonlMessage>, LoaderError> {
    let arg = session_id.to_string();
    let path = session_path(cwd, &session_id);
    if !tokio::fs::try_exists(&path).await.unwrap_or(false) {
        return Err(LoaderError::SessionNotFound { arg });
    }
    let reader = JsonlReader::new(&path);
    let messages = reader.read_all().await.map_err(|e| LoaderError::Io {
        arg: arg.clone(),
        source: std::io::Error::new(std::io::ErrorKind::InvalidData, e.to_string()),
    })?;
    validate_chain(&messages, session_id, &arg)?;
    Ok(messages)
}

fn validate_chain(
    messages: &[JsonlMessage],
    expected_session_id: Uuid,
    arg: &str,
) -> Result<(), LoaderError> {
    let mut prev_uuid: Option<Uuid> = None;
    for (i, m) in messages.iter().enumerate() {
        // (Rule 3) session_id consistency.
        let msg_session = Uuid::parse_str(&m.session_id).map_err(|_| LoaderError::SessionIdMismatch {
            arg: arg.to_string(),
            expected: expected_session_id,
            got: Uuid::nil(),
        })?;
        if msg_session != expected_session_id {
            return Err(LoaderError::SessionIdMismatch {
                arg: arg.to_string(),
                expected: expected_session_id,
                got: msg_session,
            });
        }
        // (Rule 1) first message must have parent_uuid == None.
        let msg_uuid = Uuid::parse_str(&m.uuid).map_err(|_| LoaderError::ChainBroken {
            arg: arg.to_string(),
            at_uuid: Uuid::nil(),
        })?;
        let msg_parent = m
            .parent_uuid
            .as_deref()
            .map(Uuid::parse_str)
            .transpose()
            .map_err(|_| LoaderError::ChainBroken {
                arg: arg.to_string(),
                at_uuid: msg_uuid,
            })?;
        if i == 0 {
            if msg_parent.is_some() {
                return Err(LoaderError::ChainBroken {
                    arg: arg.to_string(),
                    at_uuid: msg_uuid,
                });
            }
        } else {
            // (Rule 2) parent_uuid must equal previous message's uuid.
            if msg_parent != prev_uuid {
                return Err(LoaderError::ChainBroken {
                    arg: arg.to_string(),
                    at_uuid: msg_uuid,
                });
            }
        }
        prev_uuid = Some(msg_uuid);
    }
    Ok(())
}
```

```rust
/// Interactive line-based session picker (OQ-6 stdio fallback for the Ink TUI).
///
/// Renders:
/// ```text
/// Resume which session?
///   1. {title} [{modified}]
///   2. {title} [{modified}]
///   ...
/// >
/// ```
///
/// Behavior:
/// - Empty input line → `Ok(None)` (cancel).
/// - `1..=sessions.len()` (1-indexed) → `Ok(Some(uuid))`.
/// - Non-numeric, out-of-range, or > `sessions.len()` → print retry feedback,
///   try again up to **3 total attempts** (initial + 2 retries).
/// - After 3 failed attempts → `Err(LoaderError::InvalidSelection)`.
///
/// `stdin` is any `AsyncBufRead`, `stdout` is any `AsyncWrite` — both passed in
/// so tests can supply `tokio::io::duplex` pairs (mirrors M5-05 permission UX pattern).
pub async fn select_session_interactive<R, W>(
    sessions: &[SessionMetadata],
    stdin: &mut BufReader<R>,
    stdout: &mut W,
) -> Result<Option<Uuid>, LoaderError>
where
    R: tokio::io::AsyncRead + Unpin,
    W: tokio::io::AsyncWrite + Unpin,
{
    if sessions.is_empty() {
        return Err(LoaderError::EmptyDirectory);
    }
    let limit = sessions.len();

    // Render header + rows ONCE.
    let mut out_buf = String::from("Resume which session?\n");
    for (i, row) in sessions.iter().enumerate() {
        let modified_rfc3339 = format_rfc3339_seconds(row.modified);
        out_buf.push_str(&format!("  {}. {} [{}]\n", i + 1, row.title, modified_rfc3339));
    }
    stdout
        .write_all(out_buf.as_bytes())
        .await
        .map_err(|source| LoaderError::Io {
            arg: "stdout".into(),
            source,
        })?;

    for _attempt in 0..3 {
        stdout
            .write_all(b"> ")
            .await
            .map_err(|source| LoaderError::Io {
                arg: "stdout".into(),
                source,
            })?;
        stdout.flush().await.map_err(|source| LoaderError::Io {
            arg: "stdout".into(),
            source,
        })?;

        let mut line = String::new();
        let n = stdin
            .read_line(&mut line)
            .await
            .map_err(|source| LoaderError::Io {
                arg: "stdin".into(),
                source,
            })?;
        if n == 0 {
            // EOF — treat as cancel.
            return Ok(None);
        }
        let trimmed = line.trim();
        if trimmed.is_empty() {
            return Ok(None);
        }
        match trimmed.parse::<usize>() {
            Ok(n) if (1..=limit).contains(&n) => {
                return Ok(Some(sessions[n - 1].uuid));
            }
            _ => {
                let msg = format!(
                    "Please enter a number from 1 to {}, or empty to cancel.\n",
                    limit
                );
                stdout
                    .write_all(msg.as_bytes())
                    .await
                    .map_err(|source| LoaderError::Io {
                        arg: "stdout".into(),
                        source,
                    })?;
            }
        }
    }
    Err(LoaderError::InvalidSelection)
}

/// RFC 3339 with second precision and `Z` suffix — e.g. `2026-05-24T19:03:12Z`.
fn format_rfc3339_seconds(t: SystemTime) -> String {
    use std::time::UNIX_EPOCH;
    let secs = t.duration_since(UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0);
    // Convert to UTC components via the workspace `time` crate (already in lingxi-protocol).
    let odt = time::OffsetDateTime::from_unix_timestamp(secs as i64).unwrap_or(time::OffsetDateTime::UNIX_EPOCH);
    let fmt = time::format_description::parse("[year]-[month]-[day]T[hour]:[minute]:[second]Z")
        .expect("rfc3339 fmt");
    odt.format(&fmt).unwrap_or_else(|_| "1970-01-01T00:00:00Z".into())
}

//! messages into a fresh [`ConversationOrchestrator`], and continue the turn loop.

use lingxi_telemetry::pii::Verified;

};

/// Errors from the resume constructor: forwards loader errors verbatim,
/// plus orchestrator-construction failures (constructed by the caller).
#[derive(Debug, thiserror::Error)]
pub enum ResumeError {
    /// Bubbled up from [`load_session`].
    #[error(transparent)]
    Loader(#[from] LoaderError),
}

/// Replay the JSONL at `<claude_home>/projects/<sanitize(cwd)>/<session_id>.jsonl`
/// into a `SessionState` ready to be handed to a fresh `ConversationOrchestrator`.
///
/// Public so tests can verify the replay shape without driving the full constructor.
pub async fn replay_session_state(
    session_id: Uuid,
    cwd: &Path,
) -> Result<(SessionState, Vec<JsonlMessage>), ResumeError> {
    lingxi_telemetry::emit(
        RESUME_STARTED,
        &ResumeStartedPayload {
            session_id: Verified::new(session_id.to_string()),
        },
    );
    let messages = load_session(session_id, cwd).await?;
    let state = build_state_from_jsonl(session_id, &messages);
    lingxi_telemetry::emit(
        RESUME_COMPLETED,
        &ResumeCompletedPayload {
            session_id: Verified::new(session_id.to_string()),
            message_count: messages.len() as u64,
        },
    );
    Ok((state, messages))
}

/// Build a `SessionState` by walking the JSONL messages in order and converting
/// each into the orchestrator's in-memory `Message` type. The conversion is 1:1
/// for `type: "user" | "assistant"` (read `message.role` + `message.content`);
/// `type: "system"` / `compact_boundary` / sidechain entries are skipped — they
/// are reconstructed at runtime from settings + memory and are NOT replayed.
fn build_state_from_jsonl(session_id: Uuid, messages: &[JsonlMessage]) -> SessionState {
    let mut state = SessionState::new(session_id);
    // The last replayed message's uuid becomes the new state's `last_message_uuid`,
    // so the next JSONL append will set `parent_uuid = last_message_uuid` (chain continues).
    for m in messages {
        match m.message_type.as_str() {
            "user" | "assistant" => {
                let role = m
                    .message
                    .get("role")
                    .and_then(serde_json::Value::as_str)
                    .unwrap_or(m.message_type.as_str())
                    .to_string();
                let content = m.message.get("content").cloned().unwrap_or_default();
                let msg_uuid = Uuid::parse_str(&m.uuid).unwrap_or_else(|_| Uuid::nil());
                state.push_resumed_message(role, content, msg_uuid);
            }
            _ => {
                // system / compact_boundary / sidechain / agent-internal — skip.
            }
        }
    }
    state
}

```rust
//! T10 interop — exercise the byte-equivalent path:
//!  1. Write 2 messages via JsonlWriter (M5-07).
//!  2. Load via load_session (M5-08).
//!  3. Append a 3rd message via the writer using `state.last_message_uuid` as parent.
//!  4. Re-read with JsonlReader::read_all and confirm:
//!     - 3 lines present
//!     - parent_uuid chain intact (None → m1, m1 → m2, m2 → m3)
//!     - sessionId identical across all 3
//!     - File byte content == concatenation of `serde_json::to_string + "\n"` of each.

use lingxi_orchestrator::replay_session_state;
use lingxi_session::jsonl::{
    project_dir_name, session_path, JsonlMessage, JsonlReader, JsonlWriter,
};
use serde_json::json;
use std::sync::Arc;
use tempfile::TempDir;
use uuid::Uuid;

fn build_msg(
    type_str: &str,
    uuid: Uuid,
    parent: Option<Uuid>,
    sid: Uuid,
    cwd: &str,
    body: &str,
) -> JsonlMessage {
    serde_json::from_value(json!({
        "type": type_str,
        "uuid": uuid.to_string(),
        "parentUuid": parent.map(|p| p.to_string()),
        "sessionId": sid.to_string(),
        "timestamp": "2026-05-25T12:00:00.000Z",
        "cwd": cwd,
        "version": "0.6.0",
        "isSidechain": false,
        "userType": "external",
        "message": {"role": type_str, "content": body}
    }))
    .expect("jsonl message")
}

#[tokio::test]
#[serial_test::serial]
async fn write_then_resume_then_append_then_read_full_chain_intact() {
    let temp = TempDir::new().unwrap();
    let cwd = temp.path().join("proj");
    tokio::fs::create_dir(&cwd).await.unwrap();
    std::env::set_var("CLAUDE_CONFIG_DIR", temp.path().join("home"));
    let subdir = temp
        .path()
        .join("home")
        .join("projects")
        .join(project_dir_name(&cwd.to_string_lossy()));
    tokio::fs::create_dir_all(&subdir).await.unwrap();

    let sid = Uuid::new_v4();
    let m1 = Uuid::new_v4();
    let m2 = Uuid::new_v4();
    let path = session_path(&cwd, &sid);

    // (1) initial 2-turn write
    let writer = Arc::new(JsonlWriter::new(path.clone()));
    writer.append(&build_msg("user", m1, None, sid, &cwd.to_string_lossy(), "hi"))
        .await
        .unwrap();
    writer.append(&build_msg("assistant", m2, Some(m1), sid, &cwd.to_string_lossy(), "hello"))
        .await
        .unwrap();

    // (2) load via M5-08
    let (state, replayed) = replay_session_state(sid, &cwd).await.unwrap();
    assert_eq!(replayed.len(), 2);
    assert_eq!(state.last_message_uuid(), Some(m2));

    // (3) append 3rd message — parent must be m2
    let m3 = Uuid::new_v4();
    let next = build_msg(
        "user",
        m3,
        state.last_message_uuid(),
        state.session_id(),
        &cwd.to_string_lossy(),
        "next",
    );
    writer.append(&next).await.unwrap();

    // (4) re-read full file with M5-07 reader
    let reader = JsonlReader::new(&path);
    let all = reader.read_all().await.unwrap();
    assert_eq!(all.len(), 3);
    assert_eq!(all[0].uuid, m1.to_string());
    assert_eq!(all[0].parent_uuid, None);
    assert_eq!(all[1].parent_uuid.as_deref(), Some(m1.to_string().as_str()));
    assert_eq!(all[2].parent_uuid.as_deref(), Some(m2.to_string().as_str()));
    for m in &all {
        assert_eq!(m.session_id, sid.to_string());
    }
}
```

  **Field-name lock check:** if M5-07's `JsonlMessage` uses `parent_uuid: Option<String>` (with `#[serde(rename = "parentUuid")]`), the assertions work as written. If it instead uses `parent_uuid: Option<Uuid>` (typed), drop the `.as_deref()` and `.to_string()` calls — compare `Uuid` directly. Confirm by reading `lingxi-code/crates/session/src/jsonl/schema.rs` from M5-07.
