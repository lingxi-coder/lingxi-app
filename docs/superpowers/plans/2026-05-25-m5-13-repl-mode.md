# M5-13 Stdio REPL Mode — line-based read loop + SIGINT + EOF

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the M5-12 `lingxi-cli::repl::run_repl` stub with a real line-based REPL: print `"> "` to stderr, read a line from `tokio::io::stdin` via `BufReader::read_line`, dispatch the input (slash command → `RegistrySlashDispatcher`; plain text → a NEW `ConversationOrchestrator::run_turn` method that runs ONE turn without ending the session). On Ctrl+D (EOF, `read_line` returns `Ok(0)`) the REPL persists the session via the existing JSONL writer (M5-07) and exits 0. On SIGINT (Ctrl+C) the current turn's cancellation token fires, the orchestrator unwinds gracefully, control returns to the prompt — the REPL does NOT exit. Stream tokens from the orchestrator's `OutputStream` route to the same `OutputSink` the CLI built (so `--json` works in REPL too). Two new telemetry events `tengu_repl_session_started` + `tengu_repl_session_ended` go in a NEW `lingxi_telemetry::tengu::orchestrator` sub-module (also home for M5-02..M5-08's already-shipped orchestrator/streaming/permission/hooks/session/resume events per spec §6.4); the count grows `ALL_EVENT_NAMES.len()` from 312 → **314**.

**Architecture:** Most M5-13 code lives in the existing `lingxi-cli/src/repl.rs` file (M5-12 created the stub). Two new files: `lingxi-cli/src/sigint.rs` (cancellation-token bridge wired to `tokio::signal::ctrl_c`) and `lingxi-cli/src/repl_loop.rs` (the read-dispatch-print loop body, separated for unit-testability with an injected `AsyncBufRead`). Telemetry: `lingxi-telemetry/src/tengu/orchestrator.rs` is created if missing (M5-02 may have already created it — if so, just append the 2 new const + extend the slice). The orchestrator gains `pub async fn run_turn(&self, prompt: &str, cancel: CancellationToken) -> Result<TurnOutcome, OrchestratorError>` where `TurnOutcome` carries the stop_reason ("end_turn" / "max_turns" / "cancelled" / "interrupt"). `should_exit` field (already added in M5-10 Task 2 for `/exit`) is checked between turns. Persisted session state survives across turns inside the orchestrator's internal `Arc<RwLock<SessionState>>` — REPL does NOT manually wipe between turns. Cross-platform: macOS / Linux / Windows (`tokio::signal::ctrl_c` is portable; line reading uses `tokio::io::stdin` which is a pseudo-handle that works on all three).

**Tech stack:** Rust 2021, `tokio::io::{stdin, stderr, AsyncBufReadExt, AsyncWriteExt, BufReader}`, `tokio::signal::ctrl_c`, `tokio_util::sync::CancellationToken` (new dev-dep on `lingxi-orchestrator` if not already present — add `tokio-util = { version = "0.7", features = ["rt"] }` to its `Cargo.toml`), `lingxi-cli::{argv, exit_codes, init::Runtime, output::OutputSink}` (all M5-12), `lingxi-traits::OrchestratorHandle` (for `should_exit` query — added in this plan as a getter `current_should_exit() -> bool`).

- [ ] **Step 1: Confirm the REPL behaviour against the spec.**

  Spec §3 M5-13 row + §4.8 + §1 success criterion #2:
  - Prompt: `"> "` (2 chars: greater-than + space; flushed without trailing newline).
  - Ctrl+D (EOF) → "优雅退出": persist session JSONL, print `"\n"` (so the cursor goes to a new line), emit `tengu_repl_session_ended`, exit 0.
  - Ctrl+C (SIGINT) → "取消当前 turn 不退 REPL": fire `CancellationToken`, orchestrator unwinds turn, return to prompt. **Second** Ctrl+C while at the bare prompt (no turn in flight) → exit 130 (POSIX `128 + SIGINT`).
  - Slash command vs plain text: leading `/` → dispatcher; everything else → `run_turn(line)`.
  - Multi-line input: NOT supported in M5-13 (no backslash continuation, no heredoc). One physical line = one turn. Multi-line authoring deferred to M6 TUI.
  - Echo: input lines are NOT re-echoed to stdout (the terminal already does that). The orchestrator's text output IS written to stdout via the `OutputSink`.

- [ ] **Step 2: Lock the 7 user-visible byte-strings.**

  | # | Lock | Value | Source |
  |---|---|---|---|
  | L1 | REPL prompt | `"> "` (2 chars, NO trailing newline; flushed) | Spec §4.8 |
  | L2 | Prompt sink | **stderr** (NOT stdout) — so `--json` stdout stays parseable | LingXi UX lock |
  | L3 | EOF newline | single `"\n"` printed to stdout right before exit (so shell prompt lands on new line) | LingXi UX lock |

  **Why prompt to stderr (L2):** stdout is the conversation transcript; stdin is consumed by the REPL itself; stderr is the only sink reserved for "control plane" output. The user still sees `"> "` because most terminals interleave stdout+stderr identically. JSON mode (`--json`) writes structured events to stdout and leaves stderr for human-readable status.

- [ ] **Step 5: Lock the SIGINT contract.**

  | Event | REPL state | Action |
  |---|---|---|
  | First Ctrl+C **during turn** | turn in flight | Fire CancellationToken; orchestrator unwinds; print L5 to stderr; loop back to prompt |
  | First Ctrl+C **at idle prompt** | `read_line` blocking on stdin | Cancel the read; print `"\n"` (so prompt lands on new line); set `sigint_armed = true`; loop back to prompt |

  | `sigint_armed` timeout (2 sec elapsed without 2nd Ctrl+C) | `sigint_armed = true` | Clear `sigint_armed` back to false; no other side effects |

  The "2-second arming window" is a LingXi UX lock — mimics bash/zsh REPL convention.

```rust
use tokio_util::sync::CancellationToken;

impl ConversationOrchestrator {
    /// Run a single multi-turn-mode turn. Distinct from `run_one_shot`:
    ///
    /// - returns `TurnOutcome` so the REPL can distinguish normal end vs
    ///   `max_turns` vs cancellation
    /// - takes a `CancellationToken` that the REPL fires on Ctrl+C; the
    ///   orchestrator polls it between API calls + between tool dispatches
    ///   and unwinds gracefully when set
    /// - does NOT close the session — the session lives in `self.session`
    ///   and accumulates messages across turns
    pub async fn run_turn(
        &self,
        prompt: &str,
        cancel: CancellationToken,
    ) -> Result<TurnOutcome, OrchestratorError> {
        // 1. Append the user message to session state.
        {
            let mut s = self.session.write().await;
            s.append_user(prompt.to_string());
            // M5-07 jsonl writer: append the user line.
            if let Some(w) = &s.jsonl_writer {
                w.append_user(prompt).await
                    .map_err(|e| OrchestratorError::Io(e.to_string()))?;
            }
        }

        // 2. Inner turn loop (same body as run_one_shot's loop), but check
        //    `cancel.is_cancelled()` at each iteration.
        let mut iters = 0_u32;
        loop {
            if cancel.is_cancelled() {
                return Ok(TurnOutcome::Cancelled);
            }
            iters += 1;
            if iters > MAX_TURNS_PER_CONVERSATION {
                return Ok(TurnOutcome::MaxTurns);
            }

            // 2a. Build the API call.
            let messages = {
                let s = self.session.read().await;
                s.messages.clone()
            };
            // 2b. Issue the API call with cancellation-aware select.
            let response = tokio::select! {
                r = self.api_client.messages_create(&messages, &self.cfg) => r,
                _ = cancel.cancelled() => return Ok(TurnOutcome::Cancelled),
            }.map_err(OrchestratorError::Api)?;

            // 2c. Stream / batched delta processing — emit via OutputStream.
            //     M5-04 owns this; M5-13 just inherits it. Skip details.

            // 2d. If the model returned tool_use, dispatch the tools.
            if let Some(tool_calls) = response.tool_uses() {
                for tc in tool_calls {
                    if cancel.is_cancelled() {
                        return Ok(TurnOutcome::Cancelled);
                    }
                    let result = self.dispatch_tool(&tc).await?;
                    self.append_tool_result(&tc.id, result).await;
                }
                // Loop again: model sees the tool result and continues.
                continue;
            }

            // 2e. No tool use → end of turn.
            return Ok(TurnOutcome::EndTurn);
        }
    }

    /// Read the `should_exit` flag (M5-10 added it for `/exit`). Public so
    /// the REPL can check it between turns.
    pub async fn current_should_exit(&self) -> bool {
        self.should_exit.load(std::sync::atomic::Ordering::SeqCst)
    }
}
```

//! Bridge `tokio::signal::ctrl_c` → REPL state machine.
//!
//! The REPL needs to react to Ctrl+C in two modes:
//!   - Turn in flight: cancel the turn via `CancellationToken`
//!   - Idle prompt: arm a flag, exit on second Ctrl+C within 2 seconds
//!
//! See plan M5-13 Task 0 step 5 for the SIGINT state machine.

use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use tokio::sync::Notify;
use tokio_util::sync::CancellationToken;

pub struct SigintSource {
    /// Fires once per Ctrl+C received.
    notify: Arc<Notify>,
    /// Set to true while the REPL is at the idle prompt + the first Ctrl+C
    /// fired. Cleared by the 2-second timeout or by exit.
    pub idle_armed: Arc<AtomicBool>,
}

impl SigintSource {
    /// Spawn the SIGINT listener task. Returns a handle that REPL components
    /// can subscribe to.
    pub fn spawn() -> Self {
        let notify = Arc::new(Notify::new());
        let notify_c = notify.clone();
        tokio::spawn(async move {
            loop {
                if tokio::signal::ctrl_c().await.is_ok() {
                    notify_c.notify_waiters();
                }
            }
        });
        Self {
            notify,
            idle_armed: Arc::new(AtomicBool::new(false)),
        }
    }

    /// Await the next Ctrl+C.
    pub async fn wait(&self) {
        self.notify.notified().await;
    }

    /// Spawn a background task that fires `token.cancel()` on the next Ctrl+C,
    /// then exits. Returns a `JoinHandle` so the REPL can abort the task when
    /// the turn ends naturally (the unfired SIGINT listener must be cancelled
    /// so the next iteration sees a fresh `wait()`).
    pub fn arm_for_turn(&self, token: CancellationToken) -> tokio::task::JoinHandle<()> {
        let notify = self.notify.clone();
        tokio::spawn(async move {
            notify.notified().await;
            token.cancel();
        })
    }

    /// Returns true iff the idle flag was set; clear it.
    pub fn take_idle_armed(&self) -> bool {
        self.idle_armed.swap(false, Ordering::SeqCst)
    }

    pub fn arm_idle(&self) {
        self.idle_armed.store(true, Ordering::SeqCst);
    }

    pub fn disarm_idle(&self) {
        self.idle_armed.store(false, Ordering::SeqCst);
    }
}

//! Testable REPL loop body. Decoupled from real stdin/stderr so unit
//! tests can drive it with `tokio::io::duplex` pipes.
//!
//! See plan `docs/superpowers/plans/2026-05-25-m5-13-repl-mode.md` Task 4.

use crate::output::OutputSink;
use crate::sigint::SigintSource;
use lingxi_traits::{OrchestratorHandle, SlashCommandDispatcher, SlashDispatchResult};
use std::sync::Arc;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio_util::sync::CancellationToken;

/// One loop body: print prompt, read a line, dispatch, return whether the
/// REPL should continue.
pub async fn step<R, W>(
    stdin: &mut BufReader<R>,
    stderr: &mut W,
    dispatcher: &dyn SlashCommandDispatcher,
    handle: Arc<dyn OrchestratorHandle>,
    sink: Arc<dyn OutputSink>,
    sigint: &SigintSource,
    run_turn_fn: impl Fn(&str, CancellationToken) -> futures::future::BoxFuture<'_, Result<lingxi_orchestrator::TurnOutcome, lingxi_orchestrator::OrchestratorError>>,
) -> StepOutcome
where
    R: tokio::io::AsyncRead + Unpin,
    W: tokio::io::AsyncWrite + Unpin,
{
    // 1. Print the prompt.
    let _ = stderr.write_all(b"> ").await;
    let _ = stderr.flush().await;

    // 2. Read a line, racing against SIGINT.
    let mut line = String::new();
    let read = stdin.read_line(&mut line);
    tokio::pin!(read);

    let read_result = tokio::select! {
        r = &mut read => Ok(r),
        _ = sigint.wait() => {
            // SIGINT at idle prompt. Arm the flag; print `\n` to stderr; loop.
            if sigint.take_idle_armed() {
                // Second SIGINT within window → exit 130.
                return StepOutcome::DoubleSigintExit;
            }
            sigint.arm_idle();
            let _ = stderr.write_all(b"\n").await;
            // Start the 2-second disarm timer.
            let sig = sigint.idle_armed.clone();
            tokio::spawn(async move {
                tokio::time::sleep(std::time::Duration::from_secs(2)).await;
                sig.store(false, std::sync::atomic::Ordering::SeqCst);
            });
            Err(())
        }
    };

    let Ok(n_or_err) = read_result else { return StepOutcome::Continue; };
    let n = match n_or_err {
        Ok(n) => n,
        Err(_) => return StepOutcome::Continue, // io error — try again
    };
    if n == 0 {
        // EOF (Ctrl+D)
        let _ = tokio::io::stdout().write_all(b"\n").await;
        return StepOutcome::Eof;
    }

    let input = line.trim_end_matches('\n').trim_end_matches('\r');
    if input.is_empty() {
        return StepOutcome::Continue;
    }

    // SIGINT received a normal line — disarm.
    sigint.disarm_idle();

    // 3. Dispatch.
    if input.starts_with('/') {
        let res = dispatcher.dispatch(input).await;
        match res {
            SlashDispatchResult::Handled { display } |
            SlashDispatchResult::Unknown { display, .. } => {
                sink.text(&display).await;
                sink.text("\n").await;
            }
            SlashDispatchResult::NotASlashCommand => unreachable!("starts with /"),
        }
        if handle.current_should_exit().await {
            return StepOutcome::ExitCommand;
        }
        return StepOutcome::Continue;
    }

    // 4. Plain text → orchestrator turn.
    let token = CancellationToken::new();
    let _sigint_task = sigint.arm_for_turn(token.clone());
    sink.turn_start().await;
    let outcome = run_turn_fn(input, token.clone()).await;
    // (After turn completes, drop the spawn handle so the SIGINT listener
    // is replaced on the next iteration. The handle aborts on Drop in
    // tokio 1.21+; older releases leak — for v0.6.0 we depend on Drop.)
    match outcome {
        Ok(lingxi_orchestrator::TurnOutcome::EndTurn) => {}
        Ok(lingxi_orchestrator::TurnOutcome::MaxTurns) => {
            sink.text("[turn ended: reached MAX_TURNS_PER_CONVERSATION]\n").await;
        }
        Ok(lingxi_orchestrator::TurnOutcome::Cancelled) => {
            let _ = stderr.write_all(b"^C (turn cancelled; press Ctrl+C again or Ctrl+D to exit)\n").await;
        }
        Err(e) => {
            sink.error("runtime", &e.to_string()).await;
        }
    }
    StepOutcome::Continue
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum StepOutcome {
    Continue,
    Eof,
    DoubleSigintExit,
    ExitCommand,
}

//! REPL entry point — wraps `repl_loop::step` in a real `tokio::io::stdin`
//! / `tokio::io::stderr` driver + lifecycle telemetry.
//!

use crate::argv::Argv;
use crate::exit_codes;
use crate::init::Runtime;
use crate::output::{OutputSink, PlainSink, JsonSink};
use crate::repl_loop::{step, StepOutcome};
use crate::sigint::SigintSource;
use lingxi_telemetry::tengu::orchestrator as repl_evt;
use lingxi_traits::OrchestratorHandle;
use std::sync::Arc;
use std::time::Instant;
use tokio::io::{stdin, stderr, BufReader};

pub async fn run_repl(argv: &Argv) -> i32 {
    // Build the orchestrator runtime (same as the one-shot path).
    let runtime = match crate::init::build_runtime(argv).await {
        Ok(r) => r,
        Err(e) => { eprintln!("lingxi-cli: {e}"); return exit_codes::RUNTIME_ERROR; }
    };

    let session_id = runtime.orchestrator.current_session_id().await;
    let started = Instant::now();
    let mut turn_count: u32 = 0;

    lingxi_telemetry::emit(repl_evt::REPL_SESSION_STARTED, serde_json::json!({
        "session_id": session_id.to_string(),
        "started_at": chrono::Utc::now().to_rfc3339_opts(chrono::SecondsFormat::Secs, true),
    }));

    // Build the OutputSink. JSON in REPL is also supported.
    let sink: Arc<dyn OutputSink> = if argv.json {
        Arc::new(JsonSink::new(session_id.clone()))
    } else {
        Arc::new(PlainSink::new())
    };

    // Wire the OutputSink to the orchestrator's OutputStream slot (M5-09
    // also did this for one-shot; we redo here in case build_runtime
    // didn't set it).
    let adapter: Arc<dyn lingxi_traits::OutputStream> =
        Arc::new(crate::output_adapter::SinkAdapter::new(sink.clone()));
    runtime.orchestrator.set_output_stream(adapter).await;

    let sigint = SigintSource::spawn();
    let mut stdin = BufReader::new(stdin());
    let mut stderr = stderr();

    let handle: Arc<dyn OrchestratorHandle> =
        runtime.orchestrator.clone() as Arc<dyn OrchestratorHandle>;

    // Capture orchestrator handle for run_turn callback.
    let orch = runtime.orchestrator.clone();

    let ended_via;
    let exit_code;
    loop {
        let orch_for_turn = orch.clone();
        let run_turn_fn = move |prompt: &str, token: tokio_util::sync::CancellationToken|
            -> futures::future::BoxFuture<'_, Result<lingxi_orchestrator::TurnOutcome, lingxi_orchestrator::OrchestratorError>> {
            let o = orch_for_turn.clone();
            let p = prompt.to_string();
            Box::pin(async move { o.run_turn(&p, token).await })
        };

        let outcome = step(
            &mut stdin,
            &mut stderr,
            &runtime.dispatcher,
            handle.clone(),
            sink.clone(),
            &sigint,
            run_turn_fn,
        ).await;

        turn_count += 1; // count every step iteration; refined below
        match outcome {
            StepOutcome::Continue => continue,
            StepOutcome::Eof => { ended_via = "eof"; exit_code = exit_codes::SUCCESS; break; }
            StepOutcome::DoubleSigintExit => { ended_via = "double_sigint"; exit_code = exit_codes::SIGINT; break; }
            StepOutcome::ExitCommand => { ended_via = "exit_command"; exit_code = exit_codes::SUCCESS; break; }
        }
    }

    lingxi_telemetry::emit(repl_evt::REPL_SESSION_ENDED, serde_json::json!({
        "session_id": session_id.to_string(),
        "duration_secs": started.elapsed().as_secs(),
        "turn_count": turn_count,
        "ended_via": ended_via,
    }));

    exit_code
}
