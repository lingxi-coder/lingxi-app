## What landed

40 concrete `impl Tool for XxxTool` implementations across 9 categories,
covering every entry under claude-code's `src/tools/` directory:

| Category | Count | Tools |
|---|---|---|
| File ops | 5 | `Read`, `Write`, `Edit`, `NotebookEdit`, `Glob` |
| Search | 1 | `Grep` |
| Shell | 4 | `Bash`, `PowerShell`, `REPL`, `Sleep` |
| Web | 2 | `WebFetch`, `WebSearch` |
| Workflow | 5 | `TodoWrite`, `EnterPlanMode`, `ExitPlanMode`, `EnterWorktree`, `ExitWorktree` |
| Agent + Task | 8 | `Agent`, `TaskCreate`, `TaskGet`, `TaskList`, `TaskUpdate`, `TaskStop`, `TaskOutput`, `SendMessage` |
| Team | 2 | `TeamCreate`, `TeamDelete` |
| MCP + LSP | 5 | `MCP`, `McpAuth`, `ListMcpResources`, `ReadMcpResource`, `LSP` |
| System | 8 | `AskUserQuestion`, `Brief`, `Config`, `Skill`, `ScheduleCron`, `ToolSearch`, `RemoteTrigger`, `SyntheticOutput` |

Every tool ships with:

- byte-aligned input/output schemas (`#[serde(deny_unknown_fields)]`),
- byte-aligned error strings (locked literals from spec §7),
- hermetic test coverage via M1 trait injection,
- a `tengu_tool_<snake>_{started,completed,failed}` event triple
  (134 tool events total — registered in
  `lingxi_telemetry::tengu::tool::NAMES`, surfaced via
  `lingxi_telemetry::tengu::ALL_EVENT_NAMES`).

## Cross-cutting locks (M4-09)

- **Registry**: `register_all_builtin_tools(reg, ctx)` produces exactly
  40 builtins. Fixture:
  `crates/test-harness/src/parity/fixtures/registry_40_tools.json`.
- **Telemetry**: `parity_telemetry_coverage.rs` asserts every tool's
  3 lifecycle events are registered in `ALL_EVENT_NAMES` AND the
  `tengu_tool_*` filter holds 134 entries.
- **Output truncation**: `parity_output_truncation.rs` asserts every
  tool source file either references the
  `lingxi_tools::shared::truncate` surface
  (`MAX_TOOL_OUTPUT_LENGTH = 30_000` chars; suffix
  `"\n\n[Output truncated due to length]"`) OR carries a documented
  `// no-truncation:` / `//! no-truncation:` opt-out comment.
- **Permission**: `parity_permission_denial.rs` asserts every tool
  source file declares a `PermissionResult` variant
  (`Allow` / `Deny` / `Ask`) in its `permission_required` body. Default
  gate `AllowAllGate` (real `PromptingGate` ships in M5).
- **Release marker**: new top-level event
  `lingxi_core_v0_5_0_released` registered in
  `lingxi_telemetry::tengu::release::NAMES` (1 entry). `ALL_EVENT_NAMES`
  count: 237 → 238.
