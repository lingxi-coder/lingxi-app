## Cross-cutting locks (M5-14)

### Turn loop

- `run_turn("prompt")` → `ConversationOutcome::EndTurn { turn_count: 1, .. }` for
  single-turn no-tools scenario.
- `run_turn(...)` with `max_turns = 0` → `Err(OrchestratorError::MaxTurnsReached)`.
- `run_turn_with_cancel(prompt, pre_cancelled_token)` → `Ok(TurnOutcome::Cancelled)`.
- Parity fixture: `parity_orchestrator_turn_loop.json` +
  `parity_orchestrator.rs`.

### Slash commands

- `register_all_builtin_commands(reg)` produces exactly **99** commands.
- `register_core_batch_1(reg, handle)` + `register_core_batch_2(reg, handle, auth)`
  overwrite **18** entries with real implementations.
- Stubs return `"{name}: not implemented in v0.6.0 (M5)"`.
- Unknown commands return `"Unknown command: /{name}"`.
- Parity fixture: `parity_slash_commands_102.json` (with `implemented` field) +
  `parity_slash_commands.rs` (13 tests).

### Session JSONL byte-equivalence

- `JsonlWriter.append(msg)` emits compact JSON + single LF (`\n`). No CRLF.
- First line: `type = "user"`, `userType = "external"`, `isSidechain = false`,
  `parentUuid = null`.
- Second line: `type = "assistant"`, `parentUuid = uuid_of_line_1`.
- All lines share the same `sessionId`.
- Parity fixture: `parity_session_jsonl.json` + `parity_session_jsonl.rs` (8 tests).

### Hooks 4-arm matrix

- **Builtin**: in-process handler registered via `register_builtin()` → `HookOutcome::Success`.
- **Http**: SSRF guard rejects loopback + RFC-1918 + link-local before dispatch;
  200 OK → `HookOutcome::Success`.
- **Command**: documented stub → `HookOutcome::Error` with
  `"command executor not yet wired"` in stderr (deferred gap from M5-06).
- **Agent**: without `SubagentSpawner` → `HookOutcome::Error` with
  `"agent executor not wired"` in stderr.
- Parity fixture: `parity_hooks_runtime.json` + `parity_hooks_runtime.rs` (9 tests).
