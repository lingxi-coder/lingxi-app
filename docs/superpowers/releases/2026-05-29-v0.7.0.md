## What landed

The first iocraft-based terminal UI for LingXi, on top of the M5 execution
engine:

```text
$ lingxi-cli                 # TTY → full TUI (3-zone)
$ lingxi-cli --no-tui        # falls back to v0.6.0 stdio REPL
$ lingxi-cli -p "..."        # one-shot, byte-for-byte v0.6.0 behavior
```

| Component | Crate | Key API |
|---|---|---|
| iocraft App shell | `lingxi-tui` | `run_tui_session(runtime, cancel)` |
| 3-zone REPL screen | `lingxi-tui` | `ReplScreen` (StatusLine / Scrollback / PromptInput) |
| StatusLine | `lingxi-tui` | `format_status_line` (model / cwd / cost / ctx% / mode) |
| Scrollback | `lingxi-tui` | cap 500, `j`/`k`/PgUp/PgDn/`g`/`G` nav |
| PromptInput | `lingxi-tui` | line editor + history + slash routing |
| SpinnerWithVerb | `lingxi-tui` | 12-frame braille spinner |
| Message renderers (4) | `lingxi-tui` | `render_entry_to_string` (UserText / AssistantText / AssistantToolUse / UserToolResult) |
| 3 Permission dialogs | `lingxi-tui` | tool_use / exit_plan_mode / bypass_permissions + focus-trap |
| Engine wiring (cost) | `lingxi-tui` ⇔ `lingxi-orchestrator` | real `CostSnapshot` → StatusLine |
| Engine wiring (lists) | `lingxi-tui` ⇔ `lingxi-mcp` / `lingxi-hooks` / `lingxi-agent` | real `/mcp` / `/hooks` / `/agents` |
| Engine wiring (compact) | `lingxi-tui` ⇔ `lingxi-compaction` | real `force_compact` (stub summary) |

## Cross-cutting locks (M6-09)

### Literal lock catalog

- `docs/superpowers/literals/m6-tui-literals.md` — every user-visible TUI
  string indexed against its claude-code TSX source and the LingXi adoption
  site at `file:line` precision (Spec §2.8 compliance). The `claude-code/`
  submodule is not checked out in this worktree, so claude-code references
  use the `2026-05-28-snapshot` reference the M6-05/07 fixtures established;
  LingXi sites carry real `file:line`.

#### Telemetry count reconciliation — 330 → 326

The M6 design spec §2.6 *estimated* ~15 new events → `ALL_EVENT_NAMES == 330`.
The actual M6 total is **326**. Reconciliation:

| Source | Add | Cumulative |
|---|---|---|
| v0.6.0 baseline (M5-14) | — | 315 |
| M6-01 (session_started/ended, first_render, resize) | +4 | 319 |
| M6-02 (no new events — engine wiring reused M3/M4/M5 names) | 0 | 319 |
| M6-03 (streaming_render_started/ended) | +2 | 321 |
| M6-04 (no new events) | 0 | 321 |
| M6-05 (permission_dialog_shown/resolved) | +2 | 323 |
| M6-06 / M6-07 / M6-08 (engine wiring — no new events) | 0 | 323 |
| M6-09 `lingxi_core_v0_7_0_released` | +1 | 324 |
| M6-09 `tengu_tui_scroll_started` / `_ended` | +2 | **326** |

The original 330 target was reconciled to **326** because (a) M6-02/04/06/07/08
wiring reused existing M3/M4/M5 event names rather than registering new ones,
and (b) `tengu_tui_key_pressed` (spec'd as an aggregated once-per-second
counter) was **deferred to M7** — the windowed-aggregator + timer-flush
infrastructure does not exist, and a raw per-key emit would violate the
aggregation contract and the project's "every registered name has a call
site" discipline.

## Upgrade notes

- **New default mode**: TTY launches into TUI. Use `--no-tui` to retain
  v0.6.0 stdio behavior. Non-TTY (pipes, CI) auto-detects and falls back.
- **42 `Cargo.toml`** files bumped to `0.7.0` (added since v0.6.0:
  `lingxi-core/crates/tui/Cargo.toml`).
- **No new env vars** (TUI consumes existing config dirs / API base URL).
- **3 new telemetry events** (2 TUI scroll + 1 release marker). Downstream
  Statsig sinks should pre-register the names from
  `lingxi_telemetry::tengu::ALL_EVENT_NAMES`.
- **No breaking changes** to the `OrchestratorHandle` trait surface
  (M6-06/07/08 only changed the impl).
- **`-p` print mode** byte-for-byte identical to v0.6.0 output.
- **`/cost`, `/mcp`, `/hooks`, `/agents`, `/compact`** report real values in
  the TUI (previously stubs in v0.6.0).
