# LingXi Code v0.8.0 — TUI Surface

- **Date:** 2026-05-30
- **Milestone:** M7 (TUI Surface) — final sub-plan **M7-16**
- **Tags:** `m7.16` + `v0.8.0` (created by the controller after the independent
  final holistic review)
- **Predecessor:** v0.7.0 (M6 TUI Foundation, 326 telemetry events)
- **Successor:** v0.9.0 (M8 — advanced TUI + deferred engine wiring)

The full single-user TUI surface. v0.7.0 shipped the iocraft foundation (3-zone
layout, streaming, 4 renderers, 3 dialogs). v0.8.0 builds the rich surface on
top: full rendering primitives, ~22 message renderers, a windowed scrollback,
an advanced multi-line PromptInput with vim, four full-page screens, a message
selector, and a theme picker. Non-TTY and `--no-tui` continue to fall back
byte-for-byte to the v0.6.0 stdio REPL.

## Cross-cutting locks (M7-16)

  4 M7-04/05 renderer markers + 6 markdown element structures + 3 syntax cases

  resume list→select, settings tab nav, memory open/close, search→jump→export.

### Cross-state-seam review (the M6-lesson safety net)

`cross_state_seam_test.rs` — **7 tests** against the single `handle_live_key`
dispatcher. **Finding: no ship-blocker.** There is exactly ONE live key path
(`root::handle_live_key`, invoked only from `use_terminal_events`); `app::dispatch`
is the pure action-applier it calls after the priority chain, and
`keymap::handle_key` is dead in the live binary. The §2.5 priority order holds:
permission(1) > screen(2: Doctor/Resume/Settings/Memory/Theme) > overlays(3:
history-search / message-selector / palette / completion) > vim-toggle(3.5) >
vim(4) > default-edit/scroll(5). Verified: a pending permission wins over every
screen + overlay; only one screen and one overlay can be active at once
(mutual exclusion); opening a screen over an overlay (and vice versa) is sane;
vim fires only when no screen/overlay owns keys and `vim_enabled`. The async
Settings open pump re-checks the permission/screen guard on both sides of its
snapshot `.await`.

> **Manual real-terminal companion check** (documentation, not a code gate —
> the headless agent env cannot drive a real TTY; carries v0.7.0 gap #5
> forward): on tmux + a truecolor terminal, a human should interactively confirm
> the same three seams — open a screen mid-permission; press `/` in vim Normal;
> paste over an open screen — before the final merge.
