# 本地应用对话式设计 —— 真机 QA 清单

日期：2026-08-07
对应实现：`main` `c1ccea37e`（20 任务 + 3 修复轮）
为什么需要人来跑：**没有任何平台有覆盖全链路的自动化测试**。最终评审里最严重的缺陷
（确认过的方案根本没写进 manifest）就藏在这条缝里 —— 单元测试全绿，app 第一次保存就挂。

每一条都写明「怎么算过」和「失败长什么样」。失败长什么样这一列比通过条件更重要：
本次实现里多个缺陷的表现是**界面看起来正常，错误以英文内部字符串弹出**。

## A. 主链路（必须一次走通）

| # | 操作 | 通过 | 失败长什么样 |
|---|---|---|---|
| A1 | App 库点「+」，输入一句话，例如「一个记事本，能加标签」 | 只有一个描述输入框；空输入无法提交 | 还能看到模版选择/名字输入 = 有旧界面残留 |
| A2 | 提交后等待 | 出现「正在准备问题…」之类的进行态 | 永远转圈不动 = 出题任务没起来或失败没落态 |
| A3 | 问卷出现 | 题目明显是**针对这句描述**的，不是通用模版；步骤数不固定为 5 | 题目通用/固定五步 = 走到了旧路径 |
| A4 | 答题，其中至少一题选「由你决定」 | 该题显示为已回答 | 显示为未答 = `Deferred` 被当成了空值 |
| A5 | 至少一题用「Other…」自由输入 | 输入被接受 | **重点**：输入完再回看该题，内容应完整，不能变成首字母或碎片列表 |
| A6 | 走到最后一步，点「生成方案」 | 出现出计划的等待态 | 报 `field \`xxx\` is required`，但那题界面上明明有答案 = 默认值未落库（F4 回归） |
| A7 | 方案确认页 | 只读；列出数据表+字段、权限、外部域名；**无网络需求时明写「不访问网络」**；只有「返回修改」「确认并生成」两个出口 | 空白分区 = 沉默会被读成遗漏；能滑动关闭 = 人工门被绕过 |
| A8 | 点「确认并生成」 | **画面上有进度**，并且能走到预览 | 停在「设计器未就绪」死屏 = F2 回归 |
| A9 | 预览出现，点「批准」 | app 进入 ready | — |
| A10 | **打开这个 app，新建一条数据并保存** | 保存成功 | `collection "xxx" is not declared by the app manifest` = **F1 回归，最严重**，说明确认过的方案没写进 manifest |

## B. 迭代（这是这次改造的核心承诺）

| # | 操作 | 通过 | 失败长什么样 |
|---|---|---|---|
| B1 | 在详情页底部输入「把搜索框挪到顶部」 | 触发重建并回到预览门 | 输入条不显示 = 状态门控错 |
| B2 | 再改一轮「加一个回收站」 | 同上，可无限重复 | — |
| B3 | 改动落地后检查**未提及的文件还在** | 之前的功能没丢 | 上一轮的界面/功能消失 = 覆盖写变成了清空重写 |
| B4 | 迭代中途快速连点提交 | 第二次点击被禁用 | 触发两次 LLM 往返 = 白烧一次生成 |

## C. 失败与恢复（最容易留死路的地方）

| # | 场景 | 通过 | 失败长什么样 |
|---|---|---|---|
| C1 | 断网后新建 app | 明确提示需要联网/配置模型，落到「出题失败」并可重试 | 永远转圈 = 没有 fail-closed |
| C2 | 出题失败后改描述重来 | 能改、能重新出题 | 只能重试同一句 = 用户被困 |
| C3 | 方案确认页点「返回修改」 | 回到问卷，**看到自己之前填的答案**，不是重置为默认值 | 答案被清空 = cancel 后没刷新 |
| C4 | 生成失败后（可断网制造） | 有「重试生成」入口 | 无任何出口 = 只能删 app |
| C5 | 停在预览门时**重启 App** | 正常回到该 app，不被强制跳转 | 一启动就被全屏盖住并重置导航 = NEW-1 回归 |
| C6 | 停在预览门时**切换项目/切换模型** | 不被劫持 | 同上 |

## D. 权限与安全（人工必看）

| # | 场景 | 通过 |
|---|---|---|
| D1 | 让 app 声明一个外部域名，走到确认页 | 域名逐条列出，不折叠不去重丢行 |
| D2 | 首次访问该域名 | 仍然弹出首次授权提示 |
| D3 | 确认页显示的数据表 | 与 app 实际能读写的集合一致 |
| D4 | 尝试在生成的 app 里做被禁止的事（如直接 fetch） | 被拦下 |

## E. 跨端一致（两端都要跑 A 段）

| # | 检查 |
|---|---|
| E1 | iOS 与 Android 走完 A 段，行为一致 |
| E2 | 两端「由你决定」「Other…」表现一致 |
| E3 | Android 创建入口只要一句描述（不是名字） |

## 已知的、不需要报告的现象

- 生成结果**不保证一次成型**。这是覆盖式迭代的固有代价，spec §10 已确认接受。第一版不满意
  属正常，用 B 段继续改即可。
- 旧版本（模版时代）的 app 打不开，会给出可读的中英文错误。这是已确认的 breaking，无迁移。
