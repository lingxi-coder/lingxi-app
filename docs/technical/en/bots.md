# Personal and shared Bots

Create a persistent assistant, choose who can use it and check a missing reply.

<a id="create"></a>

## Create a personal Bot

In Chat or Code enter /create-bot followed by what the assistant should do. Review its proposed name, description and role. On Mac choose Review & create, check the model and permissions and confirm Create Bot. On clients without that card, copy the draft into the manual form in Desktop → Bots → New Bot.

<a id="audience"></a>

## Choose who uses the Bot

- Your own second device: enable remote access for the personal Bot on the Mac and open it from a paired device.
- One friend or one team: use Shared Bots in the friend chat or publish to the team’s Bot directory. The Bot runs on the maintainer’s Mac.
- For people using a hosted service, set its audience in Bot services. For someone who wants their own copy and model, share the Bot Market listing.

- [Publish to a team](teams.md#share-bot)
- [Open Bot services](/services)

<a id="no-reply"></a>

## When a Bot does not reply

Check the conversation first. In a team, check the published Bot’s availability, your access, remaining quota and any waiting task card. For an unaddressed group message, check this Bot’s auto-reply publication option and then the conversation switch. Even with both enabled it may choose silence. For a personal Bot opened remotely, check the Mac and the Bot’s remote access.

- [Auto-reply settings](teams.md#auto-reply)
- [Remote connection checks](remote-control.md#direct)
