# CLI flags

Flags for everyday launches. lingxi --help lists everything this build accepts, including flags this page leaves out.

<a id="launch"></a>

## Launch

| Flag | Effect |
| --- | --- |
| (no flag) | Open an interactive session. A positional prompt runs one turn. |
| -p, --print | Print that turn and exit. |
| -c, --continue | Continue the latest session in this directory. |
| -r, --resume [ID] | Pick a session, or open the id you pass. |
| --fork-session | Resume into a new session id. |
| --model NAME | Model for this launch. |
| --effort LEVEL | low, medium, high, xhigh, or max. An unknown value is ignored. |
| --cwd DIR | Working directory for this launch. |
| -n, --name NAME | Name for this session. |
| --session-id UUID | Session id to use. |
| -w, --worktree [NAME] | Create a git worktree for this session. |
| --bg, --background | Start a background session and return. Cannot be combined with --print. |

- [Sessions](sessions.md)

<a id="permission"></a>

## Permissions and settings

| Flag | Effect |
| --- | --- |
| --permission-mode MODE | manual, acceptEdits, plan, dontAsk, bypassPermissions, or auto. default is a hidden alias of manual. |
| --dangerously-skip-permissions | Select bypassPermissions for this launch. |
| --allow-dangerously-skip-permissions | Offer bypass as a choice without selecting it now. |
| --settings FILE_OR_JSON | Settings applied after the user and project files. |
| --setting-sources LIST | Which of user, project, and local this launch consults. |
| --restricted | Do not read user or project settings files. |
| --safe-mode | Disable hooks, plugins, skills, custom agents, discovered .mcp.json servers, and the LINGXI.md hierarchy. --mcp-config servers remain. |
| --bare | Skip hooks, plugin sync, auto-memory, background prefetches, and LINGXI.md auto-discovery. |

- [Settings files](settings.md#permission-mode)

<a id="tools"></a>

## Tools, MCP, and output

| Flag | Effect |
| --- | --- |
| --tools LIST | Tools available for this launch. |
| --allowedTools, --allowed-tools | Tools that may run without an extra ask. |
| --disallowedTools, --disallowed-tools | Tools this launch must not use. |
| --add-dir DIR | Add a working directory. |
| --agent NAME | Agent for this launch. |
| --agents JSON | One JSON object of agent definitions for this launch. |
| --mcp-config FILE | MCP config for this launch. |
| --strict-mcp-config | Use the MCP config you passed, without the discovered servers. |
| --plugin-dir PATH | Load a plugin directory for this launch. |
| --plugin-url URL | Load a plugin URL for this launch. |
| --output-format FORMAT | text, json, or stream-json. |
| --input-format FORMAT | text or stream-json. |
| --json | JSON output. |
| --no-session-persistence | Do not save the session. Only works with --print. |
| -d, --debug [FILTER] | Debug logging. This replaces --mcp-debug. |

<a id="commands"></a>

## Subcommands

lingxi provider manages model accounts. lingxi mcp manages MCP servers. lingxi plugin manages plugins. lingxi doctor checks the installation without a trust prompt. lingxi agents lists background sessions. lingxi attach, logs, stop, and rm manage a background session: stop keeps the conversation, and rm deletes the session and its worktree. lingxi update checks for an update.

The signed-in remote page is how you open a session on your computer from a browser. lingxi remote-control exits unimplemented, and the --remote-control flag does not open that page.
