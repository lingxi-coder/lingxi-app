# Environment variables

A short list of variables you set yourself. LingXi also sets variables for a plugin or a background session; leave those alone.

<a id="config"></a>

## Config and effort

| Variable | Effect |
| --- | --- |
| LINGXI_CONFIG_DIR | Config directory for this process. See the settings page for the empty-value rule. |
| LINGXI_EFFORT_LEVEL | Effort level for the process. --effort sets it for one launch. Accepted levels are low, medium, high, xhigh, and max. |

- [Settings files](settings.md#files)

<a id="switches"></a>

## Switches

For LINGXI_DISABLE_AGENT_VIEW, the values 1, true, yes, and on turn agent view off. The same setting in settings.json is disableAgentView set to true. Either one is enough. The other variables in this table are opt-outs: export them as 1 before you start LingXi.

| Variable | Effect |
| --- | --- |
| LINGXI_DISABLE_AGENT_VIEW | Turn off agent view, so /fork spawns a subagent in this session. |
| LINGXI_DISABLE_BACKGROUND_TASKS | Turn off background task execution. |
| LINGXI_DISABLE_GIT_INSTRUCTIONS | Turn off the Git instructions supplied to shell tools. |
| LINGXI_DISABLE_ATTACHMENTS | Turn off automatic attachment handling. |
| LINGXI_DISABLE_EXPLORE_PLAN_AGENTS | Remove the Explore and Plan agents from the catalog. |
| LINGXI_ENABLE_SKILL_DOCTOR | Enable /skill-doctor when that command is switched off in this build. |

<a id="subagents"></a>

## Subagent limits

| Variable | Effect |
| --- | --- |
| LINGXI_MAX_CONCURRENT_SUBAGENTS | How many subagents may run at once in one session. |
| LINGXI_MAX_SUBAGENT_SPAWN_DEPTH | How deep subagents may spawn further subagents. |
| LINGXI_MAX_SUBAGENTS_PER_SESSION | How many subagent launches one session may make in total. |
| LINGXI_SUBAGENT_MODEL | Default model when a subagent call does not name one. |
| LINGXI_SUBAGENT_MODEL_FORCE | Stop a subagent call from overriding the model. |

- [Subagents](subagents.md#launch)
