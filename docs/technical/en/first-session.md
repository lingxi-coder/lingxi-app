# Your first session

Open LingXi in a project, confirm the folder, and see where instructions and settings are stored.

<a id="open"></a>

## Open a project

1. Go to a project folder you created or otherwise trust.
2. Run lingxi. From a source checkout, run lingxi-cli.
3. If LingXi asks whether you trust the folder, confirm only when you do. After you confirm, it can read, edit, and run files there.

### Start an interactive session

```shell
lingxi
```

<a id="one-turn"></a>

## Ask for one result

Pass the request as an argument to run one turn. Add -p or --print to print the result and exit. With no argument, LingXi stays in the interactive session.

### One printed turn

```shell
lingxi -p "Summarize this repository"
```

<a id="instructions"></a>

## Project instructions

LingXi reads LINGXI.md at the project root, .lingxi/LINGXI.md, and LINGXI.local.md. Your personal copy lives at ~/.lingxi/LINGXI.md. Type /init in a session to create a project LINGXI.md.

When the project has none of those files, the default setting reads AGENTS.md or .lingxi/AGENTS.md instead. A project that already has a LINGXI.md file does not also load AGENTS.md under that default.

If a LINGXI.md file imports something outside the project, LingXi asks before reading it.

<a id="resume"></a>

## Come back to a session

Use --continue for the latest session in this directory. Use --resume to pick one, or pass its id. Add --fork-session to continue from that history under a new session id.

### Continue or resume

```shell
lingxi --continue
lingxi --resume
lingxi --resume SESSION_ID
```

<a id="config-home"></a>

## Where settings live

The config directory is $LINGXI_CONFIG_DIR when that variable is set, including when it is set to an empty value. Otherwise it is ~/.lingxi. Session settings are in settings.json inside that directory. /doctor prints the config directory it is using.
