# Help

Check the local setup, then write to LingXi support. Privacy requests use the same address.

<a id="doctor"></a>

## Look at this computer first

1. In a session, run /doctor. It prints the CLI version, the config directory, the working directory, and how many MCP servers are configured and connected.
2. If the config directory is not the one you expect, check whether LINGXI_CONFIG_DIR is set in the environment that launched LingXi.
3. If a model request fails before any work starts, check the provider account and the selected model.

- [Install](install.md)
- [API keys](accounts.md)
