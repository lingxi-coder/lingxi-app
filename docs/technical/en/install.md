## Run the CLI from a checkout

In a product checkout the Cargo binary is lingxi-cli. The npm package wraps that program as the lingxi command.

### Show CLI help

```shell
cargo run --locked -p cli --bin lingxi-cli -- --help
```

Build the CLI from the lingxi-app repository root. This command compiles the current checkout. It does not install a public release.
