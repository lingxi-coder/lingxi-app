# Project instructions

Tell LingXi how this repository works. The files are ordinary Markdown on disk.

<a id="files"></a>

## Which files are read

A project can keep LINGXI.md at the repository root, .lingxi/LINGXI.md, and LINGXI.local.md. Your own copy for every project is ~/.lingxi/LINGXI.md. /init creates a project LINGXI.md. /memory lists the instruction files loaded for this session.

- [First session](first-session.md#instructions)

<a id="agents-md"></a>

## When AGENTS.md is included

The default selection is lingxi-md-or-agents-md. If the project already has a LINGXI.md file, AGENTS.md is not also loaded. If it has none of the LINGXI.md files, LingXi reads AGENTS.md or .lingxi/AGENTS.md.

Trusted user, flag, and managed settings can change that selection. lingxi-md reads only the LINGXI.md files. lingxi-md-and-agents-md reads both. A project settings file is not the tier that selects this.

<a id="outside"></a>

## Imports outside the project

If a LINGXI.md file imports a file outside the project, LingXi asks before reading it. --bare skips LINGXI.md auto-discovery. --safe-mode turns off the LINGXI.md hierarchy for that launch.

- [CLI flags](cli-flags.md#launch)
