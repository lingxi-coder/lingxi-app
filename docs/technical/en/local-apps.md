# Publish and share Local Apps

Release to your Apps library, share an installable copy or use your running desktop app from a paired device.

<a id="publish-local"></a>

## Publish a local release

1. In Code mode open the source project on the host you want to use. Ask LingXi to build or update the Local App and publish it into Apps. The local-app skill guides the release through the available LocalApp tool.
2. Open the released revision from Apps and check that it runs. For an update, open Modify on the existing app so the new release uses the same app ID. If the revision changed elsewhere, review the newer source before publishing.

<a id="share-options"></a>

## Choose how to share a Local App

To give someone a copy, share the accessible market listing. To continue using your own running app and its existing data from another device, use Remote Control. A listing pasted into a team or DM lets the recipient review the installable release. Team membership alone does not give access to your running desktop app.

- [Share an installable release](local-apps.md#market)
- [Open the running app](local-apps.md#paired-devices)

<a id="market"></a>

## Publish to the market and send the listing

1. On Desktop in Code mode, sign in and open Apps → the app’s ••• menu → Publish to market. Fill in the listing and release notes, then choose Review source and publish. Inspect the files in the release before confirming the upload.
2. Check the returned status in Manage publications. Once the listing is available to the recipient, copy the market page link into the intended DM or group and send. The recipient opens the listing on a supported device, reviews the release and confirms installation with their own permissions and data.

- [Send a team message](teams.md#send-message)

<a id="paired-devices"></a>

## Open the same running app on your own device

1. On Desktop configure the remote app gateway and enable Remote Control. In Apps → •••, turn on Allow access from paired devices for this app.
2. With the same account, open Remote Control, pair with the computer and select the app under Apps. Its backend and business data stay on the computer. The launch link belongs to that opening and device. To stop sharing, turn off the app’s remote-access setting.

- [Pair a device](remote-control.md#same-account)
