# MCP

Connect LingXi to an MCP server with lingxi mcp. A project server waits until you approve it.

<a id="add"></a>

## Add a server

lingxi mcp add writes a server into the local, user, or project scope. The default transport for a command after -- is stdio. --transport http or --transport sse points at a URL. lingxi mcp add-json accepts stdio, SSE, HTTP, or WebSocket as one JSON value. lingxi mcp list prints the configured servers, and lingxi mcp remove deletes one.

### Add a local server and list them

```shell
lingxi mcp add my-server -- npx my-mcp-server
lingxi mcp list
lingxi mcp get my-server
```

On Mac and on WSL, lingxi mcp add-from-claude-desktop imports servers that desktop app already saved. The command above is the ordinary way to add a server.

<a id="project"></a>

## Project servers

A project-scoped server is stored in .mcp.json. Until you approve it, lingxi mcp get shows it as pending and LingXi does not connect. An approved server is health-checked unless this project has disabled it. lingxi mcp reset-project-choices clears the approved and rejected choices for project-scoped servers.

--mcp-config adds servers for this launch. --strict-mcp-config keeps the launch to that set. --mcp-debug is the old switch for MCP errors; --debug replaces it. /mcp manages servers from the session, and /doctor counts how many are configured and connected. --safe-mode skips .mcp.json servers discovered in the project. Servers passed with --mcp-config still apply.
