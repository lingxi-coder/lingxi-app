# Models

Pick a model for this session. LingXi keeps the choice in your config directory.

<a id="picker"></a>

## In a session

/model opens the list. The row you pick becomes the model setting, so the next launch starts there. Up to eight recent choices are stored, most recent first.

- [API keys](accounts.md)

<a id="saved"></a>

## The saved setting

The file is settings.json in the config directory. The model field is the selected model id, such as a provider prefix plus a model name. recentModels stores the provider and model of each recent choice. If the config directory cannot be found, the choice stays in the current session only.
