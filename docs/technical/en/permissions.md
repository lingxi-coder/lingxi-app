# Permissions

Choose whether LingXi asks before it uses a tool. The permission mode is separate from an operating-system sandbox.

<a id="ask-first"></a>

## Ask first

The starting mode is manual. LingXi asks you before a tool call that no allow rule matches. In the terminal this mode is also accepted under the name default. The manual mode does not print a mode line.

Press Shift+Tab in the terminal session to cycle the mode. The line above the input names the mode you are in.

<a id="modes"></a>

## Modes

| Mode | What LingXi does |
| --- | --- |
| manual | Ask before an unmatched tool call. |
| acceptEdits | Allow file edits without asking. |
| plan | Stay with read-only work and planning. Do not mutate the project. |
| dontAsk | Deny every action that lacks an explicit allow rule. |
| bypassPermissions | Allow actions without asking, unless the bypass kill switch is on. |
| auto | Let the classifier decide, with a fallback when it denies. You can select this for a launch. User settings may store auto, and the session stays in manual when auto mode is unavailable. A project settings file cannot grant auto. |

<a id="set-mode"></a>

## Set a mode

For one launch, pass --permission-mode. Help shows manual for the ask-first mode; default is a hidden alias. --dangerously-skip-permissions selects bypassPermissions. In settings.json, set permissions.defaultMode. A project settings file cannot grant auto or bypassPermissions.

### Plan mode for one launch

```shell
lingxi --permission-mode plan
```

A permission mode decides whether LingXi asks you. It does not by itself start an operating-system sandbox.
