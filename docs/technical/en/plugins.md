# Plugins

Install a plugin from a marketplace, or keep one in your skills directory.

<a id="install"></a>

## Install and update

lingxi plugin install PLUGIN@MARKETPLACE installs from that marketplace. lingxi plugin list shows what is installed. lingxi plugin enable and lingxi plugin disable take a scope of user, project, or local. lingxi plugin update fetches the latest version and asks you to restart before it applies. lingxi plugin uninstall removes one. The plugins alias is the same command.

In a session, /plugin manages plugins and /reload-plugins activates pending plugin changes. The marketplace alias opens the same plugin commands.

### Install from a marketplace

```shell
lingxi plugin install name@marketplace
lingxi plugin list
lingxi plugin update name
```

<a id="manifest"></a>

## The manifest

A plugin root carries .lingxi-plugin/plugin.json. A marketplace carries .lingxi-plugin/marketplace.json. When those versions disagree, the version in plugin.json is the one used at install time. lingxi plugin validate checks a plugin or marketplace manifest, and it can also check the skills, agents, and commands in a directory.

lingxi plugin init NAME creates a skills-directory plugin at ~/.lingxi/skills/NAME/. That form loads on the next session without a marketplace entry. --safe-mode disables plugins for that launch. --plugin-dir and --plugin-url add a plugin root or URL for one launch.
