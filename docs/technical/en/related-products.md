# Remote, bots, and apps

A signed-in browser can open a computer that is already running LingXi, including its bots, sessions, and local apps.

<a id="remote"></a>

## One signed-in remote page

Remote sign-in is /login/remote. After you sign in, /remote lists your computers. Pick one and confirm the pairing code on that computer the first time. The page then shows that computer’s bots and the sessions that have remote access turned on. Session controls on the open conversation change that session.

The website’s /login screen opens a console prototype. That prototype is separate from remote sign-in.

- [Remote control](remote-control.md)
- [Open remote control](/remote)

<a id="apps"></a>

## Apps on the computer

The Apps view lists local apps that run on the connected desktop and open in this browser. An app appears there after remote access is enabled for it on the desktop. The row says it runs on the desktop. Long-running work belongs on that computer; the phone apps also run work on the phone itself.
