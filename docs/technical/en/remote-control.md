# Remote control

Open a session on your own computer from a signed-in browser. The computer has to approve the browser first.

<a id="same-account"></a>

## Use the desktop account

1. On the computer, open LingXi Desktop, sign in, and turn on Remote control in settings.
2. On the phone or another computer, open the remote page and sign in with that same account.
3. Choose the computer. The first time, compare the pairing code in the browser with the code on that computer, then allow it there.

- [Open remote control](/remote)

<a id="direct"></a>

## The browser talks to your computer

Remote control lists your computers and opens one session at a time. The browser connects to the desktop app. The computer must be on, online, and running LingXi with remote control enabled.

Private browsing may be unable to keep the pairing. Forgetting a computer in the browser does not remove it from the desktop app. Remove it in the desktop settings as well.

This connects you to a computer where you already run LingXi. The browser page is the remote control documented here. lingxi remote-control exits unimplemented, and --remote-control does not open this page.
