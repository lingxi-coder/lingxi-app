# Skills

A skill is a directory with a SKILL.md file. LingXi lists it under the directory name.

<a id="layout"></a>

## Where to put one

Each skill is a directory that contains SKILL.md. The name you see is the directory name. The short text comes from the file’s description, and an optional when_to_use field can add a longer hint.

Project skills are every existing .lingxi/skills directory from the current directory up to the nearest git root. The walk stops at your home directory. The directory closest to the current folder is listed first. Your skills for every project live in ~/.lingxi/skills. When a managed directory is configured, LingXi also reads <managed>/.lingxi/skills. Extra roots passed into the session appear after those.

### A project skill

```text
.lingxi/skills/review/SKILL.md
```

<a id="list"></a>

## List and reload

/skills lists the skills it found. Empty sections are omitted. When nothing is found, the list tells you to create skills in .lingxi/skills/ or ~/.lingxi/skills/. The same directory is shown once, even if two roots reach it. /reload-skills walks the roots again. In safe mode that command adds that custom skills are disabled.

lingxi plugin init NAME scaffolds ~/.lingxi/skills/NAME/ and loads it on the next session as NAME@skills-dir. --safe-mode turns custom skills off for that launch. --disable-slash-commands empties the slash-command and skill registry for that launch.
