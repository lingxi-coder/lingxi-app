# Slash commands

Commands you type inside a session. /help lists the ones this build will run.

<a id="everyday"></a>

## Everyday commands

Type / to open the list. A command that opens a screen belongs to the interactive session. lingxi -p does not open that screen. If a name below is missing from /help, this build is not offering it.

| Command | What it does |
| --- | --- |
| /help | Show the commands available here. |
| /init | Create a project LINGXI.md. |
| /memory | Show the loaded instruction files. |
| /model | Choose the model. |
| /permissions | Manage allow and deny rules. |
| /plan | Use plan mode, or view the plan for this session. |
| /doctor | Check this setup from inside the session. |
| /resume | Open a previous conversation. continue is an alias. |
| /clear | Start a fresh context. The previous session stays on disk. |
| /compact | Summarize the conversation so far to free context. |
| /diff | Show uncommitted changes and this turn’s edits. |
| /config | Open settings. |
| /status | Show version, model, account, and tool status. |
| /context | Show how full the context is. |
| /export | Export this conversation. |
| /rename | Rename this conversation. |
| /theme | Change the theme. |
| /effort | Set the effort level. |
| /add-dir | Add a working directory. |

<a id="customize"></a>

## Customization commands

| Command | What it does |
| --- | --- |
| /skills | List skills. |
| /reload-skills | Read skill directories again. |
| /skill-doctor | Show loaded skills that are unused. Enable it with LINGXI_ENABLE_SKILL_DOCTOR when /help omits it. |
| /hooks | View hook configuration. |
| /mcp | Manage MCP servers. |
| /plugin | Manage plugins. plugins and marketplace are aliases. |
| /reload-plugins | Apply pending plugin changes in this session. |
| /agents | Print where subagent files live. It is not a manager. |
| /fork | Copy this conversation to a background session, or spawn a subagent when agent view is off. |
| /subtask | Send a subagent with this conversation. Available when agent view is on. |
| /tasks | Show background work. |
| /recap | Write a one-line recap of this session. |

- [Skills](skills.md)
- [Sessions](sessions.md#fork)

Names that install another product’s app, open an IDE bridge, or start a hosted review are not part of this guide. Use /help on your build before you rely on a name that is not in the tables.
