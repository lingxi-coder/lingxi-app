# Common tasks

Read a repository, change a bug, or run tests, and choose how much LingXi may do first.

<a id="read"></a>

## Read the code

Open the project and ask for an explanation of the path you care about. Plan mode keeps the turn on reading and planning. Pass it for one launch with --permission-mode plan, or switch with /plan and Shift+Tab.

### Read-only launch

```shell
lingxi --permission-mode plan "Explain how this repository starts a session"
```

- [Permission modes](permissions.md#modes)

<a id="fix"></a>

## Change a bug

1. Say which file or failing behavior to change, and what result you want to see.
2. Stay in manual mode when you want a question before each unmatched tool call. acceptEdits allows file edits without a prompt for those edits.
3. Use /diff to look at uncommitted changes and the edits from this turn.

- [Set a mode](permissions.md#set-mode)

<a id="test"></a>

## Run tests

Ask LingXi to run the project’s test command. In manual mode it asks before a shell command that no allow rule matches. When the run finishes, ask it to report the failing names and the files those failures point at.

lingxi doctor reads settings in the current directory without a trust prompt and does not connect MCP servers. For a checkup inside the session, use /doctor.

- [Help](help.md#doctor)
