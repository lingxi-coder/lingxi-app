# Command line

Talk to LingXi in the terminal, print one answer, or reopen a session.

<a id="names"></a>

## The command name

After the npm package is installed, the command is lingxi. The program’s own name in help and in /doctor is lingxi-cli. Both refer to the same CLI.

<a id="everyday"></a>

## Everyday commands

| You want | Command |
| --- | --- |
| Open an interactive session | lingxi |
| Run one turn and print it | lingxi -p "…" |
| Continue the latest session here | lingxi --continue |
| Pick or reopen a session | lingxi --resume [SESSION_ID] |
| Branch that history into a new id | lingxi --resume SESSION_ID --fork-session |
| Set the model for this launch | lingxi --model NAME |
| Check the setup | /doctor inside the session |

<a id="slash"></a>

## Inside the session

Type / to see commands. /init creates LINGXI.md. /model changes the model. /memory lists the instruction files loaded for this session. /doctor shows the version, config directory, working directory, and MCP connection counts.
