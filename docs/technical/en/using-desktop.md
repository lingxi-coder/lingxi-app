# Desktop

The Mac desktop app runs LingXi on that computer. Other desktop systems are not downloadable yet.

<a id="mac"></a>

## Mac

The current desktop beta is for Apple silicon Macs. It runs the local engine on that Mac. It does not include a cloud account or sync sessions across devices.

Intel Mac, Windows, and Linux desktop packages are not produced for download. On those systems, use the CLI when you have a build of it.

- [Download page](/download)

<a id="same-files"></a>

## Same project files

The desktop app uses the same config directory and LINGXI.md files as the CLI. Signing in on the desktop is what lets LingXi Remote see this computer.

- [Remote control](remote-control.md)
