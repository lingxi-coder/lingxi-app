<a id="on-device"></a>

## What the phone app is

The phone app is a LingXi client on that device. It is not a remote view of a cloud virtual machine. Embedding the on-device Linux environment into another app is covered by the Mobile Linux SDK.

- [On-device execution](mobile-execution.md)
- [Mobile Linux SDK](mobile-linux.md)
