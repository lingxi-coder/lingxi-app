# 模型与 API key

接入你要使用的模型服务。密钥保存在这台电脑的凭据存储里。

<a id="your-provider"></a>

## 由你选择服务商

灵犀通过这台电脑上的服务商账号发送请求。添加账号不会创建灵犀订阅，这个密钥也不是灵犀密码。

<a id="add-key"></a>

## 添加 API key

从标准输入传入密钥，或者指向这台电脑安全存储里已经存在的槽位。命令不接受把密钥写在参数里，也不会把密钥打印出来。

### 从标准输入添加密钥

```shell
printf %s "$API_KEY" | lingxi provider accounts add PROVIDER --name WORK --api-key-stdin
```

<a id="oauth"></a>

## 向服务商登录

支持 OAuth 的服务商使用 login。命令可以只打印地址而不打开浏览器；远程终端可以把回调地址从标准输入贴回来。

### 开始服务商登录

```shell
lingxi provider accounts login PROVIDER --name WORK
lingxi provider accounts list PROVIDER
```

<a id="choose-model"></a>

## 选择模型

在会话里，/model 列出可用模型。命令行用 --model 指定这一次使用的模型。选择会写入 ~/.lingxi/settings.json 的 model，最近的选择保存在 recentModels。

托管策略可以隐藏模型。普通安装没有这份名单，选择器显示各服务商提供的模型。

- [权限](permissions.md)
