# 运行第一个 Agent 轮次

从已组装 Harness 出发，完成提示词、终态结果、后续上下文与有序关闭。

<a id="prerequisites"></a>

## 准备真实运行时

本配方从宿主提供的 &Harness 开始。HarnessBuilder 包装注入服务，不会自行选择模型、发现工具或创建工作空间。桌面的 build_harness(config, output, permissions).await 组装既有桌面运行时并返回门面。

1. 使用完整消费者清单，并保持与宿主一致的 SDK 来源。
2. 构建组合前接通输出与权限服务。
3. 配置工作空间及可用供应商／模型。首次验证使用纯文本和空图像路径。

<a id="submit-and-inspect"></a>

## 提交提示词并读取状态

| 值 | 含义 |
| --- | --- |
| RunInput.prompt | 交给 Agent 执行路径的用户文本。 |
| RunInput.images | 由组合解析的宿主路径，不是 URL 或内联 base64。 |
| Result<TurnOutcome, HandleError> | 执行终态；流式文本与工具信息使用输出目标。 |
| session.transcript() | 已挂载对话的有序快照，可用于检查或重建视图。 |

### Rust · 已组装宿主中的函数

```rust
use harness_runtime::{CancellationToken, HandleError, Harness, RunInput, TurnOutcome};

async fn run_and_inspect(
    harness: &Harness,
    prompt: String,
) -> Result<(TurnOutcome, usize), HandleError> {
    let session = harness.session();
    let outcome = session.run(
        RunInput { prompt, images: Vec::new() },
        CancellationToken::new(),
    ).await?;
    let message_count = session.transcript().await.len();
    Ok((outcome, message_count))
}
```

验证方式: 需环境验证 (harness-guide-first-turn)

<a id="classify-completion"></a>

## 处理每种终态

| 结果 | 应用处理 |
| --- | --- |
| Ok(EndTurn) | 结束本次交互，保留会话以接收追问。 |
| Ok(MaxTurns) | 说明已达到配置的轮次预算，保留部分工作。 |
| Ok(Cancelled) | run 完成退出后清除忙碌状态，保留已经产生的输出。 |
| Err(ActionFailed(reason)) | 显示失败原因，而不是空的成功答案。 |
| Err(Unimplemented(reason)) | 重试前检查选定宿主能力与接线。 |

<a id="continue-context"></a>

## 顺序继续追问

上一轮 run 完成后，才在同一已挂载会话上再次调用 run。组合保留对话上下文。克隆 SessionHandle 只是共享同一会话访问权，不创建其他对话，也不保证重叠轮次安全。

### Rust · 顺序追问片段

```rust
let session = harness.session();
session.run(RunInput {
    prompt: "Explain the repository layout".into(),
    images: Vec::new(),
}, CancellationToken::new()).await?;

session.run(RunInput {
    prompt: "Which component owns persistence?".into(),
    images: Vec::new(),
}, CancellationToken::new()).await?;
```

验证方式: 接口摘录

<a id="close-the-host"></a>

## 完成宿主生命周期

应用需要继续对话时，不应在每个提示词后关闭运行时。真正退出时，先停止准入，完成或取消当前工作并等待结束，再调用 harness.shutdown()。不完整的 ShutdownReport 保留错误和发布回执，供顺序重试。

### Rust · 关闭报告片段

```rust
let report = harness.shutdown().await;
if !report.complete {
    // Retain report.errors and report.publications.
    // Resolve the outstanding barrier before a sequential shutdown retry.
}
```
