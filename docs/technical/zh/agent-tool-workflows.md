# 添加工具并处理审批

让工具从 schema 与宿主注册进入真实权限往返、结果呈现和清理流程。

<a id="design-a-small-tool"></a>

## 定义一个操作及其契约

自定义工具是注册到宿主的 Rust Tool 实现。先定义范围清晰的操作、规范名称、源码拥有的输入 schema 和明确结果。输入校验、授权与产生副作用的 call 应分开。

| Tool 接口 | 职责 |
| --- | --- |
| name／input_schema／input_repair_metadata | 声明规范标识、输入形状和流式输入修复所需事实。 |
| is_enabled／is_concurrency_safe | 声明能力是否可用，以及输入能否与其他工具工作重叠。 |
| validate_input | 副作用前检查操作特定条件。 |
| check_permissions | 根据输入／上下文计算权限结果；列入目录不代表已授权。 |
| call／ToolProgressSender | 结合 ToolUseContext、取消、进度与结构化结果完成执行。 |

<a id="register-with-owner"></a>

## 向生命周期负责人注册

宿主仍独占可变 ToolRegistry 时注册内置工具。MCP 工具属于 McpConnectionId 分区，插件工具属于 PluginId 分区。使用按归属的移除／替换路径，使断开服务或禁用插件后不会继续声明过期能力。

### Rust · 注册已实现的内置工具

```rust
use std::sync::Arc;
use tool_api::{Tool, ToolRegistry};

fn register_host_tool(registry: &mut ToolRegistry, tool: Arc<dyn Tool>) {
    registry.register_builtin(tool);
}
```

验证方式: 接口摘录

注册不会组装工具所需宿主依赖，也不会绕过会话能力过滤。

<a id="approval-round-trip"></a>

## 完成审批往返

1. 经 PermissionRequestSink 转发 PermissionRequest，显示真实工具／输入。
2. 回复中回传 request_id。轮次等待时，传输接收任务必须仍可响应。
3. 由 AdapterPermissionGate::resolve 查找等待请求；false 表示未知或已经完成。
4. 收到 PermissionRequestResolved 后移除提示，包括过期或取消终态。

### JSON · 输出的权限 DTO

```json
{
  "request_id": 17,
  "kind": {
    "type": "tool_use_confirm",
    "tool_name": "Bash",
    "tool_input_json": "{\"command\":\"git status --short\"}",
    "default_allow": true
  }
}
```

验证方式: 接口摘录

### JSON · 单次批准

```json
{"type":"approve_permission","request_id":17,"response":{"type":"allow_once"}}
```

验证方式: 接口摘录

### JSON · 拒绝

```json
{"type":"deny_permission","request_id":17}
```

验证方式: 接口摘录

<a id="allowed-choices"></a>

## 只提供宿主允许的选择

适配器默认请求超时为 300 秒，支持 with_timeout。宿主可取消已捕获归属的请求，也可在连接清理时排空全部请求。界面默认选择不代表用户已经决定。

| 选择／状态 | 应有行为 |
| --- | --- |
| AllowOnce | 批准一次等待调用，不创建持久规则。 |
| AllowAlways | 由 gate 从已捕获调用派生规则。持久化还要求配置路径并启用持久化。 |
| suppress_always_allow_rule | 隐藏持久允许操作；gate 也会降级不适用响应。 |
| auto_mode_prompt | 呈现引擎提供的可选动作，不按工具名自行推断资格。 |
| 超时／连接清理 | 通过 gate 结束等待工作，不能永久挂起。 |

<a id="test-the-call"></a>

## 验证调度、审批与清理

- 经真实调度器声明和调用；批准一次，核对同一工具调用 id 对应一条结果。
- 拒绝无效输入并拒绝一次有效调用，确认两条路径均未执行副作用。
- 审批等待时取消，再回答旧请求；不能使执行复活。
- 断开 MCP 或禁用所属插件，检查能力视图中工具已移除。
