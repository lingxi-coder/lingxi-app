# 把流式输出接到界面

接通一个事件目标，呈现文本、工具活动和交互请求，并区分消息完成与轮次完成。

<a id="wire-before-run"></a>

## 首次运行前安装输出目标

Harness 的 run 不返回流迭代器。宿主在组合阶段提供 OutputStream。采用 DTO 的界面可实现 ClientEventSink，并以 AdapterOutputStream::new 包装；轮次 emitter 与权限终态通知也应接到同一事件目标。

### ClientEventSink::emit

```text
async fn emit(&self, event: client::protocol::events::ClientEvent)
```

接收一个已转换且拥有自身数据的事件。将传输工作入队，避免在 Agent 任务内直接渲染或执行阻塞网络 I/O。

- [适配器接线](harness-client.md#output-adapter)

<a id="project-events"></a>

## 把事件投影为稳定条目

AdapterOutputStream 可在执行中发送消息边界；流式轮次成功后，TurnEventEmitter 还可合成完整消息快照。不能假定每个 MessageComplete 都代表 run 已结束，也不能将最终快照视为新的独立助手答案。应按宿主契约协调消息标识与快照。

| 事件 | 界面更新 | 关键区别 |
| --- | --- | --- |
| TurnStarted | 标记已准入动作为活动状态，保留可选 turn_id。 | 与提交的用户动作关联。 |
| TextDelta | 追加到当前助手消息，并批量更新视图。 | 增量不是完整消息。 |
| ToolUseStarted／ToolHeartbeat | 按工具调用 id 创建／更新活动。 | input_json 是 JSON 字符串，不是已解析对象。 |
| ToolUseResult | 按对应 id 关联 result_json、is_error 与 display。 | 单个工具失败不一定结束整个轮次。 |
| MessageComplete | 结束一条消息，并应用可选完整消息快照。 | Agent 可以继续下一次模型／工具迭代。 |
| TurnEnded | 应用轮次终态、停止原因与成本。 | 取消或预算耗尽时保留部分输出。 |
| Error | 呈现类型化 kind 与 message，并收敛失败交互。 | 轮次包装器在失败时发送 Error，不能永久等待只在成功路径出现的标记。 |

<a id="wire-shape"></a>

## 正确读取线协议形状

这里是事件对象，不是请求批次、传输帧或完整轮次。Client enum 使用 snake_case type 标记且为非穷尽类型。应为新增事件保留回退路径；原生绑定必须匹配宿主协议布局。

### JSON · 独立事件对象

```json
{"type":"turn_started","turn_id":12}
{"type":"text_delta","text":"I will inspect the project."}
{"type":"message_complete","stop_reason":"tool_use"}
```

验证方式: 接口摘录

<a id="interactive-output"></a>

## 让审批和问题保持可交互

工具权限请求是经 PermissionRequestSink 交付的独立 PermissionRequest DTO，不是 ClientEvent 的 PermissionRequest variant。配置后，gate 经事件 sink 发送 PermissionRequestResolved。AskUserQuestion 则有自己的事件和回答命令。每种交互都应按 request_id 与归属呈现，而非追加为普通助手文本。

1. 显示请求，不将轮次标记为完成。
2. 经活动宿主连接发送对应决定或回答。
3. 收到权威终态后移除请求，包括用户点击前发生的过期或取消。

- [审批往返](agent-tool-workflows.md#approval-round-trip)

<a id="reconnect-and-rebuild"></a>

## 实时投影前先恢复快照

新的输出适配器不会重放此前增量。先经宿主恢复／快照路径重建对话，再应用已挂载会话的实时事件。会话 id、turn id 与工具调用 id 应分开。传输提供 epoch／sequence 时，遵循它的重放规则，不要任意合并相同文本。

- 重连后不要用最后一段增量替换完整对话。
- 界面消失时通知生命周期负责人，不让无人消费的队列无限增长。
- 覆盖工具、等待审批、传输失败与正常轮次终态；只展示文本会漏掉这些转换。

- [会话恢复](agent-session-workflows.md)
