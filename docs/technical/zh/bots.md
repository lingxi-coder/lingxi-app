# 个人与共享 Bot

创建持久助手，选择谁能使用，排查 Bot 没回复的原因。

<a id="create"></a>

## 创建个人 Bot

在 Chat 或 Code 输入 /create-bot，再描述助手要做的事。核对草案里的名字、简介和角色。Mac 上打开审核创建卡片，检查模型与权限，再确认创建。当前客户端没有卡片时，可将草案复制到桌面版「Bot → 新建 Bot」的手动表单。

<a id="audience"></a>

## 选择 Bot 的使用对象

- 自己的另一台设备：在 Mac 上为个人 Bot 开启远程访问，从已配对设备打开。
- 一位好友或一个团队：在好友对话的共享 Bot 面板中分享，或发布到团队的 Bot 目录。Bot 运行在维护者的 Mac 上。
- 希望别人使用你托管的服务，可以在 Bot 服务里选受众。希望对方安装副本、使用自己的模型，可以分享 Bot 市场条目。

- [发布给团队](teams.md#share-bot)
- [打开 Bot 服务](https://lingxios.net/services)

<a id="no-reply"></a>

## Bot 不回消息时

先确认是哪种对话。团队里先看 Bot 的发布状态、宿主是否在线、自己的权限和剩余额度，再看任务卡是否在等人回答。若发的是未点名的群消息，先查这个 Bot 的自主回复发布选项，再查本对话的开关。两者都开启时它仍可能选择沉默。远程打开个人 Bot 时则检查 Mac 和该 Bot 的远程访问开关。

- [自主回复设置](teams.md#auto-reply)
- [检查远控连接](remote-control.md#direct)
