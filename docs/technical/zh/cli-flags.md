# 命令行参数

日常启动会用到的参数。lingxi --help 列出这个构建接受的全部参数，包括本页没有展开的那些。

<a id="launch"></a>

## 启动

| 参数 | 作用 |
| --- | --- |
| （无参数） | 打开交互会话。位置参数上的提示只跑一轮。 |
| -p、--print | 打印这一轮并退出。 |
| -c、--continue | 继续当前目录最近的会话。 |
| -r、--resume [ID] | 挑选会话，或打开你传入的 id。 |
| --fork-session | 把恢复的历史记到新的会话 id。 |
| --model NAME | 这一次启动使用的模型。 |
| --effort LEVEL | low、medium、high、xhigh 或 max。无法识别的值会被忽略。 |
| --cwd DIR | 这一次启动的工作目录。 |
| -n、--name NAME | 这次会话的名字。 |
| --session-id UUID | 要使用的会话 id。 |
| -w、--worktree [NAME] | 为这次会话创建一个 git 工作树。 |
| --bg、--background | 启动后台会话并返回。不能和 --print 一起用。 |

- [会话](sessions.md)

<a id="permission"></a>

## 权限和设置

| 参数 | 作用 |
| --- | --- |
| --permission-mode MODE | manual、acceptEdits、plan、dontAsk、bypassPermissions 或 auto。default 是 manual 的隐藏别名。 |
| --dangerously-skip-permissions | 这一次启动使用 bypassPermissions。 |
| --allow-dangerously-skip-permissions | 把绕过权限作为一个可选项，这一次并不直接选中。 |
| --settings FILE_OR_JSON | 在用户和项目文件之后再应用的设置。 |
| --setting-sources LIST | 这一次要查阅 user、project、local 中的哪些。 |
| --restricted | 不读取用户或项目设置文件。 |
| --safe-mode | 关闭 hooks、插件、skills、自定义 Agent、项目里发现的 .mcp.json 服务器，以及 LINGXI.md 层级。--mcp-config 传入的服务器仍然保留。 |
| --bare | 跳过 hooks、插件同步、自动记忆、后台预取，以及 LINGXI.md 自动发现。 |

- [设置文件](settings.md#permission-mode)

<a id="tools"></a>

## 工具、MCP 和输出

| 参数 | 作用 |
| --- | --- |
| --tools LIST | 这一次可用的工具。 |
| --allowedTools、--allowed-tools | 可以不再额外询问就运行的工具。 |
| --disallowedTools、--disallowed-tools | 这一次不得使用的工具。 |
| --add-dir DIR | 再加一个工作目录。 |
| --agent NAME | 这一次使用的 Agent。 |
| --agents JSON | 一份定义这次启动所用 Agent 的 JSON 对象。 |
| --mcp-config FILE | 这一次使用的 MCP 配置。 |
| --strict-mcp-config | 只使用你传入的 MCP 配置，不加入发现的服务器。 |
| --plugin-dir PATH | 这一次加载一个插件目录。 |
| --plugin-url URL | 这一次加载一个插件 URL。 |
| --output-format FORMAT | text、json 或 stream-json。 |
| --input-format FORMAT | text 或 stream-json。 |
| --json | 以 JSON 输出。 |
| --no-session-persistence | 不保存会话。只能和 --print 一起用。 |
| -d、--debug [FILTER] | 调试日志。用它代替 --mcp-debug。 |

<a id="commands"></a>

## 子命令

lingxi provider 管理模型账号。lingxi mcp 管理 MCP 服务器。lingxi plugin 管理插件。lingxi doctor 检查安装，不弹出信任询问。lingxi agents 列出后台会话。lingxi attach、logs、stop 和 rm 管理后台会话：stop 保留对话，rm 删除会话和工作树。lingxi update 检查更新。

从浏览器打开你电脑上的会话，用已登录的远控页面。lingxi remote-control 会以未实现退出，--remote-control 参数也不会打开那个页面。

- [远控](remote-control.md)
- [API key](accounts.md)
