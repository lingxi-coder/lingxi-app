# 数据集

创建数据集，以固定版本、最新数据或共同编辑的方式分享到会话，连接数据源，并把数据绑定到应用、页面、Bot 和任务。

<a id="personal-data"></a>

## 创建数据集并添加记录

在桌面端 Chat 顶栏打开「个人数据」，选择「用 JSON Schema 新建数据集」；「使用最近回复中的 Schema」可以直接采用助手刚起草的 Schema。选中数据集后可以「添加记录」或「选择与编辑」。在 Web Chat 中，打开输入框旁的「数据集」开关，或附加「我的数据集」中的一项；助手创建、写入和读取数据的请求都要等你批准。

<a id="share-data"></a>

## 把数据分享到会话

1. 在团队会话中点「添加数据」，选择数据位置：我的数据集、团队数据集或本会话中已共享的数据。
2. 选择访问方式：「使用固定版本」分享一份不可变快照，「查看最新」分享只读的当前记录，「共同编辑」允许对方读写。可以限制可见字段和分区。
3. 确认「分享给 …」的受众后点「分享数据」。要发布个人记录，可在「个人数据」里选择「发布到团队」，选好会话，预览发布受众后确认发布。

撤销权限或退出团队只影响之后的读取。对方已经看到或导出的内容由对方持有。

<a id="conversation-data"></a>

## 查看会话数据

在会话顶部打开「会话数据」，选择数据集，在表格和视图之间切换，查看历史，并把记录发到对话里。保存时提示记录已变化，请先加载最新版本再保存。

<a id="data-sources"></a>

## 连接数据库或文件

在桌面端打开「数据源」，选择宿主配置并「测试并预览」。在「私有预览许可」中设置谁可以请求预览以及哪些字段，再用「准备报表」把复核后的版本化报表发布到会话。MySQL、PostgreSQL、SQLite、MongoDB、Redis、CSV 和 JSON 在所有者的 Mac 上以钥匙串中的只读凭据读取，原始行和连接信息都留在本机。「停用并撤权」会停止之后的读取。

<a id="bindings"></a>

## 在应用、页面、Bot 和任务中使用数据集

- Local App：应用声明数据绑定。在桌面端打开「应用」→ 该应用的详情面板 →「数据绑定」，填写数据集 ID、共享授权；只读绑定还可以指定固定快照。
- 交互页面：在可视化中选择「发布交互页面」，选好会话和其中的数据分享，复核代码、资源和允许的操作后发布。
- 共享 Bot：维护者在会话中打开「Bot 数据集权限」，填写数据集 ID 和任务计划后复核。权限只适用于该会话中当前发布的 Bot，并可在同一处撤销。
- 定时任务：在「定时任务」中打开任务，选择「绑定数据集」，填写数据集 ID 和任务计划并复核。
