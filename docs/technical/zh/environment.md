# 环境变量

一份你自己会设置的变量清单。灵犀还会为插件或后台会话设置变量，那些不用自己导出。

<a id="config"></a>

## 配置和投入程度

| 变量 | 作用 |
| --- | --- |
| LINGXI_CONFIG_DIR | 这个进程的配置目录。空值规则见设置页。 |
| LINGXI_EFFORT_LEVEL | 这个进程的投入程度。--effort 只对这一次启动生效。可用级别是 low、medium、high、xhigh 和 max。 |

- [设置文件](settings.md#files)

<a id="switches"></a>

## 开关

LINGXI_DISABLE_AGENT_VIEW 为 1、true、yes 或 on 时关闭 Agent 视图。settings.json 里的对应项是 disableAgentView 设为 true。两边有一边即可。这张表里的其他变量是退出开关：启动灵犀前把它们导出为 1。

| 变量 | 作用 |
| --- | --- |
| LINGXI_DISABLE_AGENT_VIEW | 关闭 Agent 视图，于是 /fork 在当前会话里派子 Agent。 |
| LINGXI_DISABLE_BACKGROUND_TASKS | 关闭后台任务执行。 |
| LINGXI_DISABLE_GIT_INSTRUCTIONS | 关闭提供给 shell 工具的 Git 说明。 |
| LINGXI_DISABLE_ATTACHMENTS | 关闭自动附件处理。 |
| LINGXI_DISABLE_EXPLORE_PLAN_AGENTS | 从目录里撤下 Explore 和 Plan 这两个 Agent。 |
| LINGXI_ENABLE_SKILL_DOCTOR | 当这个构建关掉了 /skill-doctor 时，用它重新打开。 |

<a id="subagents"></a>

## 子 Agent 上限

| 变量 | 作用 |
| --- | --- |
| LINGXI_MAX_CONCURRENT_SUBAGENTS | 一个会话里同时运行的子 Agent 数量。 |
| LINGXI_MAX_SUBAGENT_SPAWN_DEPTH | 子 Agent 还能再派子 Agent 的层数。 |
| LINGXI_MAX_SUBAGENTS_PER_SESSION | 一个会话累计可以派发的子 Agent 次数。 |
| LINGXI_SUBAGENT_MODEL | 子 Agent 调用没有指定模型时的默认模型。 |
| LINGXI_SUBAGENT_MODEL_FORCE | 阻止子 Agent 的某一次调用改写模型。 |

- [子 Agent](subagents.md#launch)
