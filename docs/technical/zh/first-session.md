# 第一次会话

在项目里打开灵犀，确认文件夹，并查看说明与设置的保存位置。

<a id="open"></a>

## 打开一个项目

1. 进入一个你创建的、或者你信任的项目文件夹。
2. 运行 lingxi。从源码运行时用 lingxi-cli。
3. 如果灵犀询问你是否信任这个文件夹，只在你确实信任时确认。确认之后，它可以在这里读取、修改和运行文件。

### 开始交互会话

```shell
lingxi
```

<a id="one-turn"></a>

## 只要一次结果

把请求作为参数传入，就只跑一轮。加上 -p 或 --print 会打印结果并退出。不带参数时，灵犀留在交互会话里。

### 打印一轮结果

```shell
lingxi -p "Summarize this repository"
```

<a id="instructions"></a>

## 项目说明

灵犀读取项目根目录的 LINGXI.md、.lingxi/LINGXI.md 和 LINGXI.local.md。你自己的那份在 ~/.lingxi/LINGXI.md。在会话里输入 /init 可以创建项目的 LINGXI.md。

项目里没有这些文件时，默认改为读取 AGENTS.md 或 .lingxi/AGENTS.md。项目里已经有 LINGXI.md 时，这个默认设置不会再同时加载 AGENTS.md。

如果 LINGXI.md 引用了项目以外的文件，灵犀会先询问再读取。

<a id="resume"></a>

## 回到一个会话

用 --continue 打开当前目录里最近的会话。用 --resume 选择一个会话，也可以直接写上它的 id。加上 --fork-session 会沿用那段历史，但使用新的会话 id。

### 继续或恢复

```shell
lingxi --continue
lingxi --resume
lingxi --resume SESSION_ID
```

<a id="config-home"></a>

## 设置放在哪里

设置了 LINGXI_CONFIG_DIR 时，配置目录就是它的值，即使这个值是空的。否则配置目录是 ~/.lingxi。会话设置写在该目录的 settings.json 里。/doctor 会打印当前使用的配置目录。
