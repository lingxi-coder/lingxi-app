# 好友

添加好友，一对一聊天，把 Bot 分享给好友，或邀请好友加入团队。

<a id="add-friend"></a>

## 添加好友

1. 打开「好友 → 个人资料设置」，设置显示名称和可选的用户名，并选择是否允许别人通过用户名或邮箱找到你。
2. 点「添加好友」，输入准确的 @用户名、邮箱地址或好友链接后查找。可附上备注再发送请求。添加同一团队的成员时，在团队详情的「成员」里对该成员选择「添加好友」。

- [打开好友](https://lingxios.net/friends)

只有准确的用户名或已验证的邮箱才能找到你，邮箱地址不会显示给对方。找不到时的提示都一样。

<a id="friend-link"></a>

## 分享好友链接

在「添加好友 → 我的好友链接」里复制或分享链接。任何人打开并确认后会立即成为你的好友，无需你批准。「重置链接」会让旧链接立即失效；「关闭链接」后，在重新创建之前没人能用它添加你。

<a id="requests"></a>

## 处理好友请求

在「好友请求 → 收到的」里接受或拒绝；在「发出的」里可以取消请求。对方已经向你发出请求时，你再发送请求会直接成为好友。最多可同时有 50 个待处理的发出请求，好友上限为 500 人。

<a id="block"></a>

## 删除或拉黑好友

在好友菜单里选择「删除好友」或「拉黑」。两者都会结束好友关系，并为双方删除聊天。被拉黑的人在你从「已拉黑」中解除之前无法找到你或发送请求。解除拉黑不会恢复好友关系。

<a id="friend-bots"></a>

## 把 Bot 分享给好友

打开好友对话的「共享 Bot」。要分享自己的 Bot，在运行它的 Mac 上用灵犀桌面端选择「与好友分享 Bot」，复核后确认。好友对每个 Bot 有一个 Bot 私聊。Bot 运行在维护者的桌面端，维护者能看到与它的所有对话。「停止共享」会阻止新请求，保留历史记录。

- [其他 Bot 共享方式](bots.md#audience)

<a id="team-offer"></a>

## 邀请好友加入团队

团队所有者或管理员在团队详情里选择「邀请好友」，选中一位当前好友并发送邀请。好友会在「好友」的「团队邀请」中看到团队名称和你的名字，可以加入或忽略。加入前不会共享其他内容，加入后身份为成员。邀请 7 天后过期。

- [团队邀请链接](teams.md#invite)
