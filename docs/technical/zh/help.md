# 帮助

先检查本机环境，再写信给灵犀支持。隐私请求使用同一个地址。

<a id="doctor"></a>

## 先看这台电脑

1. 在会话里运行 /doctor。它会打印命令行版本、配置目录、工作目录，以及已配置和已连接的 MCP 服务器数量。
2. 如果配置目录不是你预期的那个，检查启动灵犀的环境里是否设置了 LINGXI_CONFIG_DIR。
3. 如果模型请求在开始工作前就失败，检查服务商账号和选中的模型。

- [安装](install.md)
- [API key](accounts.md)
