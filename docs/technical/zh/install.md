## 从源码运行命令行

在产品源码目录里，Cargo 二进制文件叫 lingxi-cli。npm 包把它包装成 lingxi 命令。

### 查看命令行帮助

```shell
cargo run --locked -p cli --bin lingxi-cli -- --help
```

在 lingxi-app 仓库根目录构建。这条命令编译当前检出的源码，不会安装一个公开发布版本。
