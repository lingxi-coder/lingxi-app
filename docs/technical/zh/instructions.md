# 项目说明

告诉灵犀这个仓库如何工作。这些文件就是磁盘上的普通 Markdown。

<a id="files"></a>

## 会读取哪些文件

项目可以把 LINGXI.md 放在仓库根目录，也可以使用 .lingxi/LINGXI.md 和 LINGXI.local.md。对所有项目生效的个人副本是 ~/.lingxi/LINGXI.md。/init 创建项目的 LINGXI.md。/memory 列出这次会话加载的说明文件。

- [第一次会话](first-session.md#instructions)

<a id="agents-md"></a>

## 何时会读到 AGENTS.md

默认选择是 lingxi-md-or-agents-md。项目里已经有 LINGXI.md 时，不会再同时加载 AGENTS.md。这些 LINGXI.md 都不存在时，灵犀读取 AGENTS.md 或 .lingxi/AGENTS.md。

受信任的用户设置、命令行设置和托管设置可以改变这个选择。lingxi-md 只读 LINGXI.md。lingxi-md-and-agents-md 两边都读。项目设置文件不负责做这个选择。

<a id="outside"></a>

## 引用项目以外的文件

如果 LINGXI.md 引用了项目以外的文件，灵犀会先询问再读取。--bare 会跳过 LINGXI.md 的自动发现。--safe-mode 会在这一次启动中关闭 LINGXI.md 层级。

- [命令行参数](cli-flags.md#launch)
