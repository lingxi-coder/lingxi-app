# MCP

用 lingxi mcp 把灵犀接到 MCP 服务器。项目里的服务器要等你批准后才会连接。

<a id="add"></a>

## 添加服务器

lingxi mcp add 把服务器写进 local、user 或 project 范围。-- 后面的命令默认使用 stdio。--transport http 或 --transport sse 指向一个 URL。lingxi mcp add-json 用一份 JSON 添加 stdio、SSE、HTTP 或 WebSocket。lingxi mcp list 打印已配置的服务器，lingxi mcp remove 删除一个。

### 添加本地服务器并列出

```shell
lingxi mcp add my-server -- npx my-mcp-server
lingxi mcp list
lingxi mcp get my-server
```

在 Mac 和 WSL 上，lingxi mcp add-from-claude-desktop 可以导入那个桌面应用已经保存的服务器。平时添加服务器用上面的命令。

<a id="project"></a>

## 项目里的服务器

项目范围的服务器写在 .mcp.json。你批准之前，lingxi mcp get 会把它显示为待批准，灵犀不会连接。批准后的服务器会做健康检查，除非这个项目把它禁用了。lingxi mcp reset-project-choices 清除项目范围服务器的批准和拒绝记录。

这一次启动可以用 --mcp-config 增加服务器。--strict-mcp-config 让这一次只使用那一组。--mcp-debug 是查看 MCP 错误的旧开关，改用 --debug。会话里用 /mcp 管理服务器，/doctor 会统计已配置和已连接的数量。--safe-mode 会跳过项目里发现的 .mcp.json 服务器。用 --mcp-config 传入的服务器仍然生效。
