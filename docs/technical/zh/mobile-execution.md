# 在手机上执行

在 iPhone 和 Android 上，命令运行在这台手机里的 Linux 环境中。

<a id="on-the-phone"></a>

## 工作在手机上运行

iPhone 版和 Android 版灵犀是内部测试版。本站没有公布 App Store、TestFlight 或公开 APK 链接。手机应用是这台设备上的客户端。它运行的命令就在这台设备上执行。

- [iPhone 与 Android](using-mobile.md)
- [下载页](/download)

<a id="guest-paths"></a>

## 命令看得到的路径

默认的 Linux 配置把 /home/lingxi 当作主目录。它的配置目录是 /home/lingxi/.lingxi，项目目录是 /home/lingxi/.lingxi/projects。命令的工作目录是这些 guest 路径之一。手机自己的文件浏览器里的文件夹路径是另一套坐标，不会自动变成命令看到的路径。

把这个环境嵌进另一个应用、选择挂载，以及把宿主路径传给运行时，见 Mobile Linux SDK。

- [SDK 里的 guest 路径](mobile-linux.md#guest-identity)
