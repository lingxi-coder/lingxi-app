# 模型

为这次会话选择模型。灵犀把选择记在你的配置目录里。

<a id="picker"></a>

## 在会话里

/model 打开列表。你选中的一行会写成模型设置，下次启动就从这里开始。最近的选择最多保留八个，最新的排在前面。

- [API key](accounts.md)

<a id="saved"></a>

## 保存的设置

文件是配置目录里的 settings.json。model 字段是选中的模型 id，例如服务商前缀加模型名。recentModels 保存每次最近选择的服务商和模型。如果找不到配置目录，这次选择只留在当前会话。
