# 权限

选择灵犀使用工具之前是否先询问你。权限模式和操作系统沙箱是两件事。

<a id="ask-first"></a>

## 先询问

初始模式是 manual。没有允许规则匹配时，灵犀会在调用工具前询问你。在终端里，这个模式也可以写成 default。manual 模式不显示模式提示行。

在终端会话里按 Shift+Tab 切换模式。输入框上方的一行会写明当前模式。

<a id="modes"></a>

## 模式

| 模式 | 灵犀会怎么做 |
| --- | --- |
| manual | 未匹配的工具调用前先询问。 |
| acceptEdits | 允许文件编辑而不再询问。 |
| plan | 只做只读查看和计划，不改动项目。 |
| dontAsk | 拒绝所有没有明确允许规则的操作。 |
| bypassPermissions | 不再询问就允许操作，除非绕过开关被关闭。 |
| auto | 由分类器决定，拒绝时有回退。你可以在这一次启动时选用。用户设置可以保存 auto；自动模式不可用时，会话仍从 manual 开始。项目设置文件不能授予 auto。 |

<a id="set-mode"></a>

## 设置模式

单次启动时传入 --permission-mode。帮助里先询问模式显示为 manual，default 是隐藏别名。--dangerously-skip-permissions 用来打开 bypassPermissions。在 settings.json 里设置 permissions.defaultMode。项目设置文件不能授予 auto 或 bypassPermissions。

### 这一次使用计划模式

```shell
lingxi --permission-mode plan
```

权限模式决定灵犀是否询问你。它本身不会因此开启操作系统沙箱。
