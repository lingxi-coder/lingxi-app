# 插件

从市场安装插件，或把插件放在 skills 目录里。

<a id="install"></a>

## 安装和更新

lingxi plugin install PLUGIN@MARKETPLACE 从该市场安装。lingxi plugin list 显示已安装的插件。lingxi plugin enable 和 lingxi plugin disable 的范围可以是 user、project 或 local。lingxi plugin update 获取最新版本，并要你重启后才会生效。lingxi plugin uninstall 移除一个。plugins 是同一条命令的别名。

会话里用 /plugin 管理插件，/reload-plugins 让待生效的插件变更在当前会话里生效。marketplace 这个别名进入同一组插件命令。

### 从市场安装

```shell
lingxi plugin install name@marketplace
lingxi plugin list
lingxi plugin update name
```

<a id="manifest"></a>

## 清单文件

插件根目录带有 .lingxi-plugin/plugin.json。市场带有 .lingxi-plugin/marketplace.json。两边的版本不一致时，安装时采用 plugin.json 里的版本。lingxi plugin validate 检查插件或市场清单，也可以检查一个目录里的 skills、agents 和 commands。

lingxi plugin init NAME 在 ~/.lingxi/skills/NAME/ 创建一个 skills 目录形式的插件。这种形式下次会话就会加载，不需要市场条目。--safe-mode 会在这一次启动中禁用插件。--plugin-dir 和 --plugin-url 为这一次启动增加一个插件目录或 URL。
