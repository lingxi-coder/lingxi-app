# 远控、Bot 和应用

已登录的浏览器可以打开一台已经在运行灵犀的电脑，包括它的 Bot、会话和本地应用。

<a id="remote"></a>

## 同一个已登录的远控页

远控登录在 /login/remote。登录之后，/remote 列出你的电脑。选一台，第一次要在那台电脑上确认配对码。页面随后显示这台电脑的 Bot，以及已经打开远程访问的会话。打开的对话里的会话控制，改的是这次会话。

网站的 /login 页面进入的是控制台原型。那个原型和远控登录是分开的。

- [远控](remote-control.md)
- [打开远控](/remote)

<a id="apps"></a>

## 电脑上的应用

应用视图列出在已连接的桌面电脑上运行、并在这个浏览器里打开的本地应用。在桌面版里为某个应用打开远程访问之后，它会出现在这里。这一行会标明它运行在桌面电脑上。长时间的工作适合放在那台电脑上；手机应用也会把工作放在手机自己上面运行。

- [在手机上执行](mobile-execution.md)
