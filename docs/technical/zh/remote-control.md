# 远控

用已登录的浏览器打开你自己电脑上的会话。电脑需要先允许这个浏览器。

<a id="same-account"></a>

## 使用桌面版账号

1. 在电脑上打开灵犀桌面版，登录，并在设置里打开远程控制。
2. 在手机或另一台电脑上打开远控页面，用同一个账号登录。
3. 选择这台电脑。第一次连接时，对照浏览器和电脑上的配对码，然后在电脑上允许。

- [打开远控](/remote)

<a id="direct"></a>

## 浏览器直接连接你的电脑

远控列出你的电脑，一次打开一个会话。浏览器连接的是桌面应用。电脑需要开机、在线，并且灵犀正在运行且已开启远程控制。

无痕浏览可能无法保留配对。在浏览器里忘记一台电脑，不会把它从桌面应用里删掉。还要在桌面版设置里移除。

这是连接到一台已经在运行灵犀的电脑。这里记录的远控是这个浏览器页面。lingxi remote-control 会以未实现退出，--remote-control 也不会打开这个页面。
