# 会话

继续最近的会话，挑选更早的一次，或从一份副本接着做。

<a id="continue"></a>

## 继续或挑选

lingxi --continue 打开当前目录里最近的会话。lingxi --resume 打开选择列表，lingxi --resume SESSION_ID 打开指定会话。会话里的 /resume 做同一件事。/clear 开始一段新的上下文，上一份会话仍留在磁盘上，之后还能用 /resume 打开。

### 继续、恢复或分出副本

```shell
lingxi --continue
lingxi --resume
lingxi --resume SESSION_ID --fork-session
```

- [第一次会话](first-session.md#resume)
- [命令行](using-cli.md#everyday)

<a id="fork"></a>

## 新 id 的副本

加上 --fork-session 会保留你恢复的历史，并把新的工作记在一个新的会话 id 下。Agent 视图默认开着：这时 /fork 把对话复制成一个后台会话，你仍留在当前会话。/subtask 派一个子 Agent 带走这段对话，再把结果带回来。它需要一段任务说明，而且要等第一轮对话发生之后才能用。

设置里 disableAgentView 为 true，或 LINGXI_DISABLE_AGENT_VIEW 为 1、true、yes、on 时，Agent 视图关闭。这时 /fork 在当前会话里启动子 Agent，/subtask 不再是启动子 Agent 的命令。

- [子 Agent](subagents.md)
- [环境变量](environment.md)

<a id="background"></a>

## 后台会话

lingxi --bg 把这次工作放到后台会话并回到 shell。它不能和 --print 一起用。lingxi agents 在终端里列出这些会话；标准输出不是终端时加上 --json。lingxi stop 会停掉会话并保留对话。lingxi attach 再次打开它，停掉之后 lingxi --resume 仍然可用。lingxi rm 删除该后台会话和它的工作树。

### 开始、停止、再打开

```shell
lingxi --bg "Run the test suite and summarize failures"
lingxi agents
lingxi stop SESSION_ID
lingxi attach SESSION_ID
```

帮助文字里的程序名是 lingxi-cli。安装 npm 包之后，同一个程序的命令是 lingxi。
