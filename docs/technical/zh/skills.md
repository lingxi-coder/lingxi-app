# Skills

一个 skill 是含有 SKILL.md 的目录。灵犀用目录名来显示它。

<a id="layout"></a>

## 放在哪里

每个 skill 是一个含有 SKILL.md 的目录。你看到的名字是目录名。简短说明来自文件里的 description，可选的 when_to_use 可以再加一段使用提示。

项目 skill 来自当前目录往上、直到最近的 git 根目录之间每一个存在的 .lingxi/skills。走到你的主目录就停止。离当前文件夹最近的目录排在前面。对所有项目生效的 skill 在 ~/.lingxi/skills。配置了托管目录时，灵犀还会读取 <managed>/.lingxi/skills。会话额外收到的根目录排在这些之后。

### 一个项目 skill

```text
.lingxi/skills/review/SKILL.md
```

<a id="list"></a>

## 查看和重新加载

/skills 列出找到的 skill，空的分组不会出现。一个都没有时，列表会提示你在 .lingxi/skills/ 或 ~/.lingxi/skills/ 里创建。两条路径指向同一目录时只显示一次。/reload-skills 会重新走一遍这些目录。安全模式下，这条命令会加上自定义 skill 已禁用的说明。

lingxi plugin init NAME 会在 ~/.lingxi/skills/NAME/ 生成一份骨架，下次会话以 NAME@skills-dir 加载。--safe-mode 会在这一次启动中关闭自定义 skill。--disable-slash-commands 会在这一次启动中清空斜杠命令和 skill 注册表。
