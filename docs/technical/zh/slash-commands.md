# 斜杠命令

在会话里输入的命令。/help 列出这个构建会运行的那些。

<a id="everyday"></a>

## 常用命令

输入 / 打开列表。会打开一个界面的命令属于交互会话。lingxi -p 不会打开那个界面。如果下面某个名字没有出现在 /help 里，说明这个构建没有提供它。

| 命令 | 作用 |
| --- | --- |
| /help | 显示这里可用的命令。 |
| /init | 创建项目的 LINGXI.md。 |
| /memory | 显示已加载的说明文件。 |
| /model | 选择模型。 |
| /permissions | 管理允许和拒绝规则。 |
| /plan | 使用计划模式，或查看这次会话的计划。 |
| /doctor | 在会话里检查当前环境。 |
| /resume | 打开之前的对话。continue 是别名。 |
| /clear | 开始新的上下文。上一份会话仍留在磁盘上。 |
| /compact | 总结到目前为止的对话，以腾出上下文。 |
| /diff | 显示未提交的改动和这一轮的编辑。 |
| /config | 打开设置。 |
| /status | 显示版本、模型、账号和工具状态。 |
| /context | 显示上下文占用了多少。 |
| /export | 导出这次对话。 |
| /rename | 重命名这次对话。 |
| /theme | 更换主题。 |
| /effort | 设置投入程度。 |
| /add-dir | 增加一个工作目录。 |

<a id="customize"></a>

## 定制相关的命令

| 命令 | 作用 |
| --- | --- |
| /skills | 列出 skills。 |
| /reload-skills | 重新读取 skill 目录。 |
| /skill-doctor | 显示已加载但未使用的 skill。/help 里没有它时，用 LINGXI_ENABLE_SKILL_DOCTOR 打开。 |
| /hooks | 查看 hook 配置。 |
| /mcp | 管理 MCP 服务器。 |
| /plugin | 管理插件。plugins 和 marketplace 是别名。 |
| /reload-plugins | 在这次会话里应用待生效的插件变更。 |
| /agents | 打印子 Agent 文件所在的目录。它不是管理界面。 |
| /fork | 把这次对话复制到后台会话；Agent 视图关闭时，改为派一个子 Agent。 |
| /subtask | 带着这次对话派一个子 Agent。Agent 视图开着时可用。 |
| /tasks | 显示后台工作。 |
| /recap | 为这次会话写一行摘要。 |

- [Skills](skills.md)
- [会话](sessions.md#fork)

安装其他产品的应用、打开 IDE 桥，或发起托管审查的那些名字，不在本指南里。表格以外的名字，先在你的构建里看 /help，再决定是否使用。
