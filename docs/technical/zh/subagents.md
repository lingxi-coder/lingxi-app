# 子 Agent

用 Markdown 文件定义子 Agent，或让灵犀写一份。/agents 不是管理界面。

<a id="files"></a>

## 定义文件

每个子 Agent 用一份 Markdown。项目里放在 .lingxi/agents/，所有项目通用的放在 ~/.lingxi/agents/。子目录里的文件也会被读到。灵犀从当前目录向项目根目录走，到你的主目录停止。同名时，更深的项目文件胜过更浅的，项目文件胜过用户文件。--add-dir 可以再加入项目目录，优先级低于这次向上查找。

/agents 只打印说明。它让你请灵犀创建或更新子 Agent，或者直接编辑这些目录。它不会打开管理界面。lingxi agents 是另一条命令，用来列后台会话。

- [会话](sessions.md#background)

<a id="launch"></a>

## 为这一次启动指定

--agent NAME 指定这一次启动使用的 Agent，并覆盖 agent 设置。--agents 接收一份 JSON 对象，为这一次启动定义 Agent。这些定义优先于磁盘上的文件。安全模式会警告并忽略这份 JSON。

Agent 视图开着时，用 /subtask 从会话里派子 Agent。关掉时，用 /fork 做这次会话内的派发。可以设置的上限有 LINGXI_MAX_CONCURRENT_SUBAGENTS、LINGXI_MAX_SUBAGENT_SPAWN_DEPTH 和 LINGXI_MAX_SUBAGENTS_PER_SESSION。调用没有指定模型时，LINGXI_SUBAGENT_MODEL 是默认模型。LINGXI_SUBAGENT_MODEL_FORCE 会阻止某一次调用改用别的模型。
