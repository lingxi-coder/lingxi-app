# 常见任务

阅读仓库、修改一个 bug 或运行测试，并先决定灵犀可以做到哪一步。

<a id="read"></a>

## 看代码

打开项目，让灵犀解释你关心的路径。计划模式把这一轮限制在阅读和计划。单次启动可以传 --permission-mode plan，会话里可以用 /plan 和 Shift+Tab 切换。

### 只读启动

```shell
lingxi --permission-mode plan "Explain how this repository starts a session"
```

- [权限模式](permissions.md#modes)

<a id="fix"></a>

## 改一个 bug

1. 说明要改哪个文件或哪种失败行为，以及你希望看到的结果。
2. 希望每次未匹配的工具调用都先问你时，留在 manual。acceptEdits 允许文件编辑不再为这些编辑询问。
3. 用 /diff 查看未提交的改动和这一轮的编辑。

- [设置模式](permissions.md#set-mode)

<a id="test"></a>

## 跑测试

让灵犀运行项目自己的测试命令。manual 模式下，没有允许规则匹配的 shell 命令会先询问你。跑完后，让它报告失败的名字，以及这些失败指向的文件。

lingxi doctor 读取当前目录的设置，不弹出信任询问，也不会连接 MCP 服务器。要在会话里做检查，用 /doctor。

- [帮助](help.md#doctor)
- [会话](sessions.md#background)
