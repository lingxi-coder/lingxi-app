# 命令行

在终端里和灵犀对话，打印一次回答，或重新打开会话。

<a id="names"></a>

## 命令名称

安装 npm 包之后，命令是 lingxi。帮助和 /doctor 里程序自己的名字是 lingxi-cli。两者是同一个命令行工具。

<a id="everyday"></a>

## 常用命令

| 你想 | 命令 |
| --- | --- |
| 打开交互会话 | lingxi |
| 跑一轮并打印 | lingxi -p "…" |
| 继续当前目录最近的会话 | lingxi --continue |
| 选择或重开一个会话 | lingxi --resume [SESSION_ID] |
| 把那段历史分到新 id | lingxi --resume SESSION_ID --fork-session |
| 指定这一次的模型 | lingxi --model NAME |
| 检查环境 | 在会话里输入 /doctor |

- [第一次会话](first-session.md)
- [权限](permissions.md)

<a id="slash"></a>

## 会话里

输入 / 查看命令。/init 创建 LINGXI.md。/model 切换模型。/memory 列出这次会话加载的说明文件。/doctor 显示版本、配置目录、工作目录和 MCP 连接数量。
