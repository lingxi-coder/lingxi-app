# 桌面

Mac 桌面应用在那台电脑上运行灵犀。其他桌面系统还不能下载。

<a id="mac"></a>

## Mac

当前桌面测试版面向 Apple 芯片的 Mac。它在这台 Mac 上运行本地引擎，不包含云账号，也不会把会话同步到其他设备。

没有可供下载的 Intel Mac、Windows 或 Linux 桌面安装包。在这些系统上，如果你已经有命令行构建，就使用命令行。

- [下载页](/download)

<a id="same-files"></a>

## 同一套项目文件

桌面应用和命令行使用同一个配置目录和同一批 LINGXI.md。在桌面版登录之后，灵犀远控才能看到这台电脑。

- [远控](remote-control.md)
