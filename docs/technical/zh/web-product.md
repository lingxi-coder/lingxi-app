# Web · SDK 官网与 UI 原型

当前浏览器应用发布 SDK 文档，并在未连接运行时后端的情况下展示账号／控制台 UI。

<a id="web-current-boundary"></a>

## 当前实现边界

apps/web 是 React／Vite 应用，包含公开页面、SDK 文档与开发者控制台 UI 原型。文档路由渲染本地人工维护数据及生成的源码声明索引。Login 明确展示原型说明：提交只设置 UI 状态并进入控制台，不发送验证消息，也不创建真实账号。

控制台账号用量、余额与密钥记录来自 mockData。API-key 操作通过原型辅助函数更新本地组件状态，不是生产授权服务。本站不是托管 LingXi 推理 API、WebSocket Bridge 宿主或远程 Agent 会话服务。实际桌面／原生执行由相应产品宿主提供。

<a id="web-route-and-state"></a>

## 路由、本地状态与文档数据

Router 规范路径大小写与分隔符，准入固定公开／控制台路由，并通过 docPages 检查 /docs/<id>。未知路径回到公开首页。App 在浏览器存储中保存语言、地区与主题，更新文档语言和主题，并在路由变更时恢复章节 hash。浏览器持久化属于偏好状态，不是持久运行时会话存储。

技术正文、双语结构表格、步骤、代码标签、SVG 描述与来源引用位于 src/data/docs。DocsPage 消费同一 schema 以生成导航、搜索、API 浏览和章节渲染；仓库 Markdown 也从这些记录生成。事实表格应保留在数据中，不应在 JSX 再维护一份副本。

| 路由 | 当前数据／来源 |
| --- | --- |
| /docs 与 /docs/<id> | 人工维护双语指南数据与生成 API／来源索引。 |
| /login | 使用本地状态及延迟导航的表单原型。 |
| /console/* | 模拟用量／账单／密钥记录及本地 UI 动作。 |
| /download /pricing | 公开产品信息及已配置原型记录。 |

<a id="web-build-and-hosting"></a>

## 构建、预览与静态托管

Build 运行 Vite 并写入 dist。仓库根目录 Firebase Hosting 配置提供 apps/web/dist，以 index.html 回退处理 SPA 路由，并将 /v1/** 转发到 catalogApi。模型管理页面为 /admin/models。静态页面响应成功只证明前端服务可用；目录／后端运行及运行时 Agent 执行需要各自验收。

刷新源码身份时，在完整本地工作区运行文档同步。纯文档 CI 可在没有相邻 SDK checkout 时检查保存内容／输出一致性。API 索引过期属于文档生成故障，不能解释成 provider／网络故障。Schema 新增期间保留当前语言／主题行为。

### 从产品根目录开发官网

```bash
npm --prefix apps/web ci
npm --prefix apps/web run docs:sync
npm --prefix apps/web run docs:check
npm --prefix apps/web run typecheck
npm --prefix apps/web test
npm --prefix apps/web run build
npm --prefix apps/web run dev -- --host 127.0.0.1
```

验证方式: 需环境验证

## 功能检查与开放集成

检查直接进入 /docs/<id>#section、语言切换、双语正文搜索、API 筛选、代码复制、SVG 无障碍文字、浅色／深色主题及窄屏表格。导出的 Markdown 须保留官网相同内容与链接。路由截图不能证明认证、provider 通信或 marketplace／后端运行。

未来真实控制台需要独立定义账号／会话／凭证后端及浏览器可用传输。Node BridgeClient 导入 ws 与 node:events，并通过本地 lockfile 认证头连接，因此不能直接导入当前浏览器 bundle。这些未来决定属于集成工作，不是本站已有能力。
