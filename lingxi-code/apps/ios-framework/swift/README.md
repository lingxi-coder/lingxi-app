# Historical Swift wrapper example

This package is an M8 scaffold retained as a historical example. It is not
maintained or used by the active iOS app, and its former `VoiceRecorder` /
`PlatformImpls` API is not the current FFI contract.

Use the active iOS application in [`clients/ios`](../../../../clients/ios).
Its Rust wrapper entry points live in [`ios-framework/src/lib.rs`](../src/lib.rs):
`build_ios_engine_with_config` accepts the app-scoped `IosAudioService`
callback. The callback provides `capabilities`, `execute(request:)`, and
targeted `cancel(identity:)`; its UniFFI types are generated by
`clients/ios/scripts/build-xcframework.sh`.

Do not copy or regenerate bindings from this scaffold. Edit the active client
and the corresponding Rust wrapper contract instead.
