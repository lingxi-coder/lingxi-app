# Reviewed third-party cargo-vet attestations

This selection preserves twelve exact full/delta audit records and one original violation from Embark Studios, ISRG/libprio-rs and Zcash. The original authors remain attributed. These are accepted third-party attestations, not new Codex source or cryptography reviews. `provenance.json` traces every field to an immutable upstream commit/blob; Zcash aggregation is additionally checked against its original projects. The independent cross-review is retained here.

Only the selected `audits` tables are published. No wildcard, publisher trust, exemption, custom criterion or criteria mapping is included. Ariel's litrs record is excluded because its full/delta review scope needs clarification. Future selections require separate source and trust review.

These snapshot files alone do not change current dependency coverage. A follow-up configuration will use their immutable HTTPS commit URLs through cargo-vet's normal import/regenerate path, with frozen before/after graph validation. Existing native/source audit gaps remain failures.
